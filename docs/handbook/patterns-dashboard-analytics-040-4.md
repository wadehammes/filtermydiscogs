- **Chart stack**: Shared [`TanstackChart`](../../src/components/TanstackChart/TanstackChart.component.tsx) wraps **`RendererChart`** from **`@tanstack/charts/react/tooltip`** — chart tooltips use a local **`z-index: 1`** inside **`.chart`** (**`isolation: isolate`**) so they do not compete with **`PlaybackPageShell`** release modals portaled at **`calc(var(--z-7-tooltip) + 1)`**. (**`RendererChartProps`**, **`DomChartDefinition`**) with the **`motion({ initial: 'always' })`** renderer (**`@tanstack/charts/motion`**) for entrance animation and **`renderTooltipBody`** delegating to TanStack's default tooltip body (required for formatted tooltip strings to render in React). By default **`animateOnView`** defers chart mount until **[`useScrollRevealInView`](../../src/hooks/useScrollRevealInView.hook.ts)** fires (**`triggerOnce`**, **`threshold: 0.5`**, **`root`** = **`usePlaybackPageScrollElement()`**, no **`rootMargin` inset**) so below-the-fold dashboard/admin charts animate once half visible on scroll, not on page load; a muted **placeholder** fills the slot until **`document.fonts.ready`** and the viewport **`width`/`height`** are measured, then **`RendererChart`** mounts with those dimensions so TanStack’s first paint is the real layout (avoids a follow-up resize or **`fonts.loadingdone`** re-render canceling enter motion while **`resize: false`**). Entrance animation is **TanStack motion only** — do not wrap **`RendererChart`** in scroll-reveal **`.enter`** opacity (it hides or replaces the SVG enter tracks and reads as a blink). **`RendererChart`** prerenders SVG before the motion host mounts — use **`initial: 'always'`** so adopted roots still replay entrance ( **`initial: true`** snaps in production). Pass **`animateOnView={false}`** to mount immediately (skips the font gate). When **`height`** is omitted, **`TanstackChart`** uses the flex viewport’s **`clientHeight`**; prefer an explicit **`height`** when the slot is fixed (e.g. **`GrowthChart`**). Data toggles after mount still use TanStack update motion. Chart definitions live in [`tanstackCharts.ts`](../../src/utils/tanstackCharts.ts) (`defineChart` + mark factories; compact scales from **`@tanstack/charts/scales/*`**; factories return **`DomChartDefinition`** for TanStack Charts **1.x**); shared chart tokens in [`chartConfig.ts`](../../src/utils/chartConfig.ts) (**`CHART_TOOLTIP_CLASS`**, **`THEME_PRIMARY_CHART_COLOR`** = **`var(--primary)`**). **Responsive** area charts (`defineChart({ chart: …, tooltip: … })`) must put **`tooltip` on the outer definition** — the renderer reads **`definition.tooltip`**, not the object returned from **`chart()`**. **Cartesian** charts hide axis lines/tick stubs (**`modernAxisPresentation`**) and rely on a light y-grid; **bars** are flat (**`radius: 0`**) with values in tooltips only (no inline count labels). **Cartesian** specs also set **`clip: true`** and a locked **`margin.left`** so mono y-axis ticks and area fills do not overlap in narrow grid columns; **horizontal bar** charts (**Top Artists** / **Top Labels** in [`ArtistLabelCharts`](../../src/components/Dashboard/ArtistLabelCharts.component.tsx)) compute **`margin.left`** from longest category labels and an **`assumedWidth`** preset (**`HORIZONTAL_BAR_ASSUMED_WIDTH`**: compact on mobile, default in two-column layout), with **`anchor: "end"`** tick labels and ellipsis truncation when space is tight (full names stay in tooltips). **Area** charts pair **`areaY`** (fill only) with **`lineY`** (top-edge stroke) via **`d3Curve(curveMonotoneX)`**, light fill, and **`THEME_PRIMARY_CHART_COLOR`** on **[`GrowthChart`](../../src/components/Dashboard/GrowthChart.component.tsx)** (collection growth) and **[`GrowthAreaChart`](../../src/components/GrowthAreaChart/GrowthAreaChart.component.tsx)** (admin growth); growth **x** axes use **`scalePoint`** with **dynamic `ticks.values`** (evenly spaced subset from chart width for **monthly** view — point scales otherwise label every month). **[`GrowthChart`](../../src/components/Dashboard/GrowthChart.component.tsx)** **yearly** view passes **`xTickStrategy: "all"`** so every acquisition year gets an x label (thin labels when there are more than ten years). **GrowthChart** tooltips show **cumulative total records** at the hovered period (`datum.cumulative`). **Pies** are **donuts** (**`innerRadius` ~56%**, **`padAngle`**, **`cornerRadius: 0`**) — no rounded slice corners. Per-bar/per-slice colors use datum fields (e.g. **`withBarColors()`** + **`fill: (datum) => datum.fill`**) — string **`fill`** values on marks are literal paint, not field names. **[`GrowthAreaChart`](../../src/components/GrowthAreaChart/GrowthAreaChart.component.tsx)** passes **`height`** through to **`TanstackChart`** (same as dashboard **`GrowthChart`**).
