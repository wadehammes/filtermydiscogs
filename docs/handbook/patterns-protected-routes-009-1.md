## Protected routes

Authenticated app routes use [`useRedirectIfUnauthenticated`](../../src/hooks/useRedirectIfUnauthenticated.hook.ts): while **`isCheckingAuth`**, render nothing briefly; when unauthenticated, **`router.replace("/")`**. **`/collection`** streams paginated collection pages into the grid as they arrive; [`StickyHeaderBar`](../../src/components/StickyHeaderBar/StickyHeaderBar.component.tsx) shows [`FiltersBarSkeleton`](../../src/components/StickyHeaderBar/FiltersBarSkeleton.component.tsx) until **`allReleasesLoaded`** and collection metadata is ready (**`!fetchingCollection`** in [`StickyHeaderBar`](../../src/components/StickyHeaderBar/StickyHeaderBar.component.tsx) — avoids a blank filter row when IndexedDB satisfies pagination before **`CollectionContext`** finishes), then swaps in the real [`FiltersBar`](../../src/components/StickyHeaderBar/FiltersBar.tsx) (skeleton mirrors the bar DOM: **Views** menu with bookmark icon and primary accent stripe, search, three **`styleFilterGroup`** slots for genre, format, and release year/Match, then sort — see [conventions.md → Mobile filter controls](conventions.md#css-and-styling)). Header page navigation stays enabled during pagination — [`CollectionDataSync`](../../src/components/CollectionDataSync/CollectionDataSync.component.tsx) keeps fetching in the background, and [`CollectionLoadingToast`](../../src/components/CollectionLoadingToast/CollectionLoadingToast.component.tsx) shows a bottom-center loading toast (with total size from Discogs **`pagination.items`**, or remembered size from **`localStorage`**) when the collection has more than **`COLLECTION_LARGE_MIN_ITEMS` (1000)** releases and pagination is still in progress. Persisted filter prefs from **`localStorage`** apply only after the full collection load via **`collectionFiltersActiveAtom`** in [`filters.atoms.ts`](../../src/atoms/filters.atoms.ts) (set by [`useCollectionData`](../../src/hooks/useCollectionData.hook.ts)). **`/dashboard`** and **`/mosaic`** block until the full collection finishes loading via [`useNeedsCollectionLoad`](../../src/hooks/useNeedsCollectionLoad.hook.ts) (`isLoading`, **`hasNextPage`**, or **`isFetchingNextPage`** from [`useCollectionLoadState`](../../src/hooks/useCollectionData.hook.ts)). Dashboard shows [`AppPageLoading`](../../src/components/AppPageLoading/AppPageLoading.component.tsx) with [`DashboardSkeleton`](../../src/components/Dashboard/DashboardSkeleton.component.tsx) while pages stream in; large-collection progress appears in [`CollectionLoadingToast`](../../src/components/CollectionLoadingToast/CollectionLoadingToast.component.tsx) ([`src/utils/toast.ts`](../../src/utils/toast.ts) + [`Spinner`](../../src/components/Spinner/Spinner.component.tsx)), not an inline status bar.

| Route                   | While `isCheckingAuth`                              | When unauthenticated | Collection loading                                 |
| ----------------------- | --------------------------------------------------- | -------------------- | -------------------------------------------------- |
| `/`                     | Landing + **`AuthCheckingToast`**                   | Landing              | —                                                  |
| `/collection`             | null while checking auth                            | Redirect to `/`      | Stream pages into grid; filter skeleton until done |
| `/dashboard`, `/mosaic` | Header + skeleton/loader until full collection load | Redirect to `/`      | Skip when collection pagination is complete        |
| `/admin`                | Server gate + brief null                            | Redirect to `/`      | —                                                  |
