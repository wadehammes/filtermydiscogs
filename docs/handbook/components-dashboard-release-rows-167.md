## Dashboard release rows

Dashboard sections that list releases (On this day, most crated, milestones, duplicates modal list, etc.) share one layout — do not invent per-section cover/title/meta markup or card chrome:

| Piece       | Location                                                                                                                                                                                                        |
| ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Card shell  | [`dashboard-card.module.css`](../../src/styles/modules/dashboard-card.module.css) — **`.releaseRow`** for bordered list rows (composes **`.card`**)                                                             |
| Row content | [`DashboardReleaseItem.component.tsx`](../../src/components/Dashboard/DashboardReleaseItem.component.tsx) + [`DashboardReleaseItem.module.css`](../../src/components/Dashboard/DashboardReleaseItem.module.css) |

Section modules may add layout wrappers around **`.releaseRow`**, but the inner release presentation stays in **`DashboardReleaseItem`**. Cover opens the modal via **`getReleaseActivateProps`** (**`aria-label`**: **`Open release details for {title}`**); the title **`<button>`** keeps the visible album name as its accessible name (no duplicate **`aria-label`**). Optional trailing slots (e.g. **[`OnThisDay`](../../src/components/Dashboard/OnThisDay.component.tsx)** year added, **[`MostCrated`](../../src/components/Dashboard/MostCrated.component.tsx)** crate count) use **`children`** — most crated exposes **`role="status"`** + **`aria-label`** (**`{n} crates`**) on the count block. Default title/meta lines single-line ellipsis; pass **`wrapText`** on **`DashboardReleaseItem`** when a section needs wrapped copy (On this day). **[`DashboardSection`](../../src/components/Dashboard/DashboardSection.component.tsx)** sections (e.g. **In your crates**) are **`region`**s via **`aria-labelledby`** on the section **`h2`** — scope Playwright queries under **`getByRole('region', { name: … })`** when the same release appears in multiple dashboard lists. **[`OnThisDay.module.css`](../../src/components/Dashboard/OnThisDay.module.css)** caps list width (~**`36rem`**) so rows do not span the full dashboard. See [patterns.md → Dashboard analytics → Card chrome](patterns.md#dashboard-analytics).
