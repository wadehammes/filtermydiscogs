# React Query

Keep **`useQuery` / `useMutation`** out of fat components—use dedicated hooks under **`src/hooks/queries/`** (reads) and **`src/hooks/mutations/`** (writes).
- **Dedicated hook file** per query ([`useDiscogsCollectionQuery.ts`](../../src/hooks/queries/useDiscogsCollectionQuery.ts)) or mutation bundle ([`useCrateMutations.ts`](../../src/hooks/mutations/useCrateMutations.ts)).
- **Query keys**: Centralized in [`querykeys.constants.ts`](../../src/hooks/queries/querykeys.constants.ts). Use key factories in hooks and in any **`invalidateQueries`** / **`setQueryData`** call sites.
- **Shared read options**: When a query is used from **`useQuery`** / **`useInfiniteQuery`** and imperatively (**`prefetchQuery`**, **`fetchQuery`**, **`ensureQueryData`**, optimistic **`getQueryData`** / **`setQueryData`**), export a **`*QueryOptions`** factory wrapped in TanStack **`queryOptions()`** or **`infiniteQueryOptions()`** from the same hook file (e.g. **`authQueryOptions`** in [`useAuthQuery.ts`](../../src/hooks/queries/useAuthQuery.ts), **`discogsReleaseQueryOptions`**, crate/collection factories). Prefer **`.queryKey`** from that factory over raw key constants for cache reads/writes on that payload so types stay tagged. Fire-and-forget prefetches that skip duplicate in-flight work use [`queryPrefetchIfIdle.ts`](../../src/utils/queryPrefetchIfIdle.ts).
- **Mutation invalidation tags**: For mutations that should only refetch a known set of queries, set **`meta: { invalidates: [SomeQueryKeys.all()] }`** — handled by the global **`MutationCache`** in [`Providers.tsx`](../../src/components/Providers.tsx). Do not use **`meta.invalidates`** for flows that rely on optimistic cache patches (crates, collection rating/notes).
- **Hook params: single object** (e.g. `useDiscogsCollectionQuery({ username, enabled })`) with a params interface in the same file.
- **Keep query hooks dumb**: `queryKey`, `queryFn`, `enabled`, `select`, etc. only—no `useEffect`, `onSuccess`, or `onError` inside query hook files. No `console.error` in `queryFn`.
- **Side effects at the call site**: Read `isError` / `error` in the component and react there (logging, toasts, etc.).
- **API layer**: Hooks call **`api.*`** from [`src/api/urls.ts`](../../src/api/urls.ts)—not raw `fetch` in hook files, not Discogs directly from the browser (see [patterns.md](patterns.md)). Implement **`fetch`** in [`src/api/endpoints/`](../../src/api/endpoints/) and add each method to the **`api`** object in the same PR. Admin dashboard client helpers (**`fetchAdminStats`**, **`fetchAdminUserLookup`**, **`fetchAdminWelcomeEmailPending`**, **`sendAdminWelcomeEmail`**) share [`dashboard.ts`](../../src/api/endpoints/dashboard.ts) with **`mostCratedReleases`** / **`topUserTracks`** — do not leave **`api.*`** entries without a matching import from an endpoint module (a missing binding crashes app bootstrap when **`urls.ts`** loads).
