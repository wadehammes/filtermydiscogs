## Public playlists

When **`private: false`**, [`public-playlist-query.server.ts`](../../src/lib/public-playlist-query.server.ts) and [`loadPublicPlaylist`](../../src/lib/public-playlist-load.server.ts) power **`/playlist/[id]`** SSR and **`GET /api/playlists/public/[id]`**. **`LoadPublicPlaylistOptions.discogsHydration`** is **`snapshotsOnly`** for cached page/OG loaders (**[`getPublicPlaylistForPage`](../../src/lib/public-playlist.server.ts)**, **`getPublicPlaylistForOg`**) and for **`GET /api/playlists/public/[id]`** by default ([**`publicPlaylistGetQuerySchema`](../../src/lib/validation/playlist.schemas.ts) — optional **`?discogsHydration=full`** for snapshot backfill). **`loadPublicPlaylist`** itself defaults to **`snapshotsOnly`** when **`discogsHydration`** is omitted (pass **`full`** explicitly for server-side hydrate + snapshot persist). On public loads it may call **`backfillMissingDisplayArtInSnapshotMap`** (capped by **`PUBLIC_PLAYLIST_MISSING_ART_BACKFILL_MAX_RELEASE_IDS`**) before building the release list, then **`persistPlaylistReleaseSnapshots`** for rows that gained art—legacy playlists with many missing covers may still rely on client **`POST /api/release/batch`** for the remainder. The GET handler calls **`findPublicPlaylistById`** once (**owner `username` backfill** via **`getReadOnlyVerifiedUserFromRequest`** when **`hasActiveDiscogsSession`** — not display cookies alone — plus voter attachment) and passes that row into **`loadPublicPlaylist`** via **`LoadPublicPlaylistOptions.playlist`** so the loader does not query the playlist again. Public payloads include **`shareStats`** (**`publicViewCount`**, **`publicPlayCount`**) from **`Playlist`** counters and optional owner **`publicDescription`** (**`Playlist.public_description`**, edited via **`PATCH /api/playlists/[id]`** / **`POST /api/playlists`** **`publicDescription`** and **[`CreatePlaylistDialog`](../../src/components/CreatePlaylistDialog/CreatePlaylistDialog.component.tsx)** (create + rename)). Non-empty descriptions feed **`buildPublicSharePageMetadata`** / Open Graph via **[`resolvePlaylistPublicShareMetaDescription`](../../src/utils/publicPlaylistDescription.ts)** (truncated to **`PLAYLIST_PUBLIC_DESCRIPTION_META_MAX_LENGTH`**); the full text renders on **`PublicPlaylistSummaryHero`**. Per-track **`upCount`** / **`downCount`** live on **`PlaylistTrack`**; anonymous and signed-in **visitors** vote via **`POST /api/playlists/public/[id]/tracks/vote`** (the playlist owner cannot vote and view/play engagement counters exclude the owner — [`playlist-engagement.server.ts`](../../src/lib/playlist-engagement.server.ts), [`playlist-track-vote.server.ts`](../../src/lib/playlist-track-vote.server.ts)) (HttpOnly **`fmd_plvv`** cookie for anonymous visitors — issued on **`GET /api/playlists/public/[id]`** and vote **`POST`** when missing). **`GET /api/playlists/public/[id]`** attaches **`viewerVote`** per track and uses **`Cache-Control: private, no-store`** (responses vary by session/cookie). Successful votes revalidate the public playlist cache tag and patch **[`usePublicPlaylistQuery`](../../src/hooks/queries/usePublicPlaylistQuery.ts)** via **[`usePublicPlaylistTrackVoteMutation`](../../src/hooks/mutations/usePublicPlaylistTrackVoteMutation.ts)** (optimistic + server reconcile). **[`useRecordPublicPlaylistView`](../../src/hooks/useRecordPublicPlaylistView.hook.ts)** fires **[`useRecordPublicPlaylistViewMutation`](../../src/hooks/mutations/usePublicPlaylistEngagementMutations.ts)** at most once per playlist per 24h (**[`publicPlaylistViewDedupe.client.ts`](../../src/utils/publicPlaylistViewDedupe.client.ts)** + in-memory guard); **`POST /view`** sets an HttpOnly **`fmd_plv_{playlistId}`** cookie so reloads do not increment **`public_view_count`**. Successful view/play mutations patch **`shareStats`** on **[`usePublicPlaylistQuery`](../../src/hooks/queries/usePublicPlaylistQuery.ts)** via **[`patchPublicPlaylistShareStatsInQueryCache`](../../src/utils/publicPlaylistShareStatsQueryCache.ts)**. **`usePlaylistPlayback`** with **`publicEngagementPlaylistId`** POSTs **`/play`** when **Play All** or row play starts transport (owner sessions skip increments — [`playlist-engagement.server.ts`](../../src/lib/playlist-engagement.server.ts)). Owner **`GET /api/playlists/[id]`** and **[`PlaylistShareControls`](../../src/components/PlaylistShareControls/PlaylistShareControls.component.tsx)** surface the same totals when the playlist is public. **`getPublicPlaylistMetadataForPage`** / **`getPublicPlaylistForPage`** / **`getPublicPlaylistForOg`** use **`use cache`** (5‑minute revalidate) for **`generateMetadata`** and the page payload; all three return **`null`** when no DB URL is configured (same as public crate helpers above). **`getPublicPlaylistIdsForStaticGeneration()`** (default limit 100) feeds **`/playlist/[id]`** URLs in [`sitemap.ts`](../../src/app/sitemap.ts); build placeholder id is excluded. **`generateStaticParams`** on [`/playlist/[id]/page.tsx`](../../src/app/playlist/[id]/page.tsx) uses **`PUBLIC_PLAYLIST_BUILD_PRERENDER_LIMIT`** (25). Share SEO metadata is built with [`buildPublicSharePageMetadata`](../../src/lib/public-share-metadata.server.ts). OG images: [`src/app/api/og/playlist/[id]/route.tsx`](../../src/app/api/og/playlist/[id]/route.tsx).
