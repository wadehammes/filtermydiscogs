## Settings

- **Page**: [`/settings`](../../src/app/settings/page.tsx) → [`SettingsClient`](../../src/components/Settings/SettingsClient.component.tsx) (authenticated; redirects home when signed out via **`useRedirectIfUnauthenticated`**).
- **Navigation**: Linked from the username dropdown ([`UserActions`](../../src/components/StickyHeaderBar/UserActions.tsx) — Settings, About, optional **Submit bug report** when Sentry is enabled, **Donate** via [`SupportProjectNavLink`](../../src/components/SupportProjectNavLink/SupportProjectNavLink.component.tsx) → **`/about#support`**, **Theme** submenu, Logout) and the mobile menu account section ([`MobileMenuDrawerFooter`](../../src/components/StickyHeaderBar/MobileMenuDrawerFooter.tsx) — username label, [`SegmentedControl`](../../src/components/SegmentedControl/SegmentedControl.component.tsx) with Settings, **[`DrawerFooterMoreMenu`](../../src/components/DrawerFooterMoreMenu/DrawerFooterMoreMenu.component.tsx)** About/Donate via [`MobileMenuFooterMoreMenu`](../../src/components/StickyHeaderBar/MobileMenuFooterMoreMenu.component.tsx), and Logout). Same-page **`/about`** clicks scroll to **`#support`** via [`hashNavigation.ts`](../../src/utils/hashNavigation.ts) (`navigateToPathHash`); other routes navigate to **`/about#support`**. About and Settings mount [`useHashScrollOnMount`](../../src/hooks/useHashScrollOnMount.hook.ts) for hash arrival (Settings: **`#settings-extend-queue-similar`** when linked from the playback queue drawer). Layout: sticky sidebar section nav (horizontal scroll on mobile) + single active panel ([`SettingsSectionPanels`](../../src/components/Settings/SettingsSectionPanels.component.tsx)).
- **Sections**: Account (Discogs username; optional **email** + **marketing emails** opt-in via **`GET`/`PATCH` [`/api/user/contact`](../../src/app/api/user/contact/route.ts)** — `useUserContactQuery`, **`useUpdateUserContactMutation`**; changing **email** requires **Save email** on a segmented control attached to the email field (no save on blur); a changed address sends a verification link (**`pendingEmail`** until **`GET /api/user/email-verification/confirm`**); **Account** shows verified / pending status beside the field; pending or unverified copy plus **Resend verification** live in a tinted notice card (**info** while **`pendingEmail`** is set, **warning** when saved email is unverified); **`PATCH { resendEmailVerification: true }`** rotates the token and resends mail; marketing toggle stays disabled until **`emailVerified`**; **Support the app** → [`SupportProjectNavLink`](../../src/components/SupportProjectNavLink/SupportProjectNavLink.component.tsx); **Complete logout** via **`logout({ preserveTokens: false })`**), appearance (**`ThemeSwitcher variant="dropdown"`** in Settings; header menu uses **`variant="menu"`**; **Square corners** toggle → **`preferences.squareCorners`** → [`applySquareCornersToDocument`](../../src/utils/applySquareCornersToDocument.ts) sets **`html[data-ui-radius="square"]`** via [`ui-radius.css`](../../src/styles/themes/ui-radius.css); default view select; default collection side panel), playback (**Play immediately when adding to an empty queue** → **`preferences.autoPlayOnQueueAdd`**; **Extend queue with similar releases** → **`preferences.extendQueueWithSimilarReleases`**, default **`false`**), filters (**Remember filter selections** → **`preferences.persistFilters`**; **Saved views** list with rename, delete, and a human-readable filter summary via [`formatFilterViewSummary`](../../src/utils/filterViews.ts)), collection sync (**`useCrateCollectionSync`** — **Sync collection** sends the in-memory collection instance-id list to **`POST /api/crates/sync`** for orphan crate cleanup; it does **not** re-fetch the Discogs folder or rewrite the IndexedDB collection cache; see [discogs.md → IndexedDB collection cache](discogs.md#client-side-collection-access)), Data (**Allow analytics cookies** toggle via **`useAnalyticsConsent`**; **Delete account** via **`useClearAllUserData`** + confirm dialog). Theme, default view, and filter-persistence changes show a **Preferences saved** toast (or **Failed to save preferences** on error) after **`PATCH`** via **`persistPreferences`** callbacks.
