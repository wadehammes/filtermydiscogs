## Dashboard analytics

- **Page**: [`/dashboard`](../../src/app/dashboard/page.tsx) → [`DashboardClient`](../../src/components/Dashboard/DashboardClient.component.tsx).
- **Narrative layout**: [`buildDashboardStory`](../../src/utils/dashboardStory.ts) owns hero copy (**`heroEyebrow`**, **`heroTagline`**, section **`title`** + **`lede`**) in `DashboardStorySections`. Section ledes for governed copy (e.g. **On repeat** **`sections.playback.lede`** → **`DASHBOARD_PLAYBACK_SECTION_LEDE`** in [`dashboardCopy.constants.ts`](../../src/constants/dashboardCopy.constants.ts)) stay in constants and are asserted in [`dashboardStory.spec.ts`](../../src/utils/dashboardStory.spec.ts). [`DashboardHero`](../../src/components/Dashboard/DashboardHero.component.tsx) uses a two-zone layout: count + tagline on the left, a compact two-stat panel (value, rating) on the right with dashed inner dividers — each stat is a **`<fieldset aria-label="…">`** (borderless in [`DashboardHero.module.css`](../../src/components/Dashboard/DashboardHero.module.css)). The hero **record count** wraps a per-digit **ticker** roll (**[`TickerNumber`](../../src/components/ScrollReveal/ScrollReveal.component.tsx)** in **`role="status"`** with a numeric **`aria-label`**, digits **`aria-hidden`** — digit strips in [`scroll-reveal.module.css`](../../src/styles/modules/scroll-reveal.module.css), segment builder + default start value in [`tickerNumber.helpers.ts`](../../src/utils/tickerNumber.helpers.ts)): ~2.4s staggered column rolls from ~78% of the total (never all zeros), plus a soft fade/scale entrance on **`.count`** (not scroll-gated). **[`AdminHero`](../../src/components/AdminDashboard/AdminHero.component.tsx)** uses the same **`TickerNumber`** for platform totals and inline stats. [`DashboardSection`](../../src/components/Dashboard/DashboardSection.component.tsx) wraps each chapter (on this day + this week → growth → what you collect → on repeat → who repeats → the path so far → in your crates / shelf check). **On this day** and **[`WeeklyRecap`](../../src/components/Dashboard/WeeklyRecap.component.tsx)** (**This week**) share a two-column **`storyPair`** row on desktop (≥1024px), stacked on mobile — weekly recap uses rolling 7-day stats from [`weeklyRecap.ts`](../../src/utils/weeklyRecap.ts) (`calculateYearInReview` week window, recent-add list, genre/artist highlight). Child blocks accept optional **`hideHeading`** when the section title replaces their internal **`h2`**. **[`OnThisDay`](../../src/components/Dashboard/OnThisDay.component.tsx)** lists past-year **`date_added`** matches in a capped-width single column of **`releaseRow`** cards (same pattern as most crated): **[`DashboardReleaseItem`](../../src/components/Dashboard/DashboardReleaseItem.component.tsx)** with **`wrapText`** so long titles wrap instead of ellipsizing, plus a trailing **year added** slot (**`children`**, e.g. **2022** / **4 yrs ago**). When **`hideHeading`** and there are no past-year matches, it renders nothing (section lede only). **[`CollectionMilestones`](../../src/components/Dashboard/CollectionMilestones.component.tsx)** (**The path so far**) reads **`useAllReleases()`** and builds cards with **`calculateMilestones`** in [`milestones.ts`](../../src/utils/milestones.ts). Acquisition-order milestones (**First release added**, **10th / 25th / … Release**) rank the collection with **`compareDiscogsReleasesByDateAdded`** — ascending **`date_added`**, then **`instance_id`** when Discogs timestamps tie — so nth slots stay stable when the atom list is reshuffled or when new rows only have **later** **`date_added`** (regressions in [`milestones.spec.ts`](../../src/utils/milestones.spec.ts)). Cards render in a horizontal zig-zag timeline via **`sortMilestonesChronologically`**. **Oldest Release** (lowest pressing **`year`**) and **Most Active Year** (most adds by calendar year) still recompute from the full shelf. **`DashboardClient`** keeps milestones behind **`useNeedsCollectionLoad`** so ordinals are not shown while collection pages are still streaming. **On repeat** ([`TopTracks`](../../src/components/Dashboard/TopTracks.component.tsx)) uses **`story.sections.playback`** (**`title`** / **`lede`**) from [`buildDashboardStory`](../../src/utils/dashboardStory.ts); the block is two columns on desktop (**Most played** / **Most listened**) with short meta hints, a dashed rule under each column intro, and scrollable **`trackList`** rows (**`TopTracks.module.css`**) when lists exceed **`max-height`**. **[`StyleEvolution`](../../src/components/Dashboard/StyleEvolution.component.tsx)** uses a responsive period grid with compact bar rows (top styles per quarter), not pie charts — **`useScrollRevealInView`** triggers staggered **`ScrollRevealBar`** fills and **`TickerNumber`** stats on release counts and style percentages when the grid enters view (same in-view bar/ticker pattern as **genre drift** in **`CollectionRhythm`**). **Dashboard narrative blocks render immediately** — do not hide sections, cards, or stats behind scroll-reveal wrappers; motion on **`/dashboard`** is limited to **charts** (**`TanstackChart`** **`animateOnView`**), **rhythm** + **taste-over-time** tickers and bar fills (**[`CollectionRhythm`](../../src/components/Dashboard/CollectionRhythm.component.tsx)**, **`StyleEvolution`**), and the hero **record count** ticker on load.
