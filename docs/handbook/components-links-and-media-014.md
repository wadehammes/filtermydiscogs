## Links and media

- Internal routes: **`next/link`** or **`useRouter`** from `next/navigation`.
- Discogs release/artist/label URLs: **`getResourceUrl({ resourceUrl, type, id? })`** from [`src/utils/helpers.ts`](../../src/utils/helpers.ts) — parses **`resource_url`**, or falls back to a numeric **`id`** when the collection payload omits URLs.
- **View on Discogs** actions: **[`DiscogsExternalLink`](../../src/components/DiscogsExternalLink/DiscogsExternalLink.component.tsx)** / **[`DiscogsReleaseExternalLink`](../../src/components/DiscogsExternalLink/DiscogsExternalLink.component.tsx)** — **`variant="toolbar"`** (modal toolbar icon), **`variant="icon"`** (segmented overlay), **`variant="text"`** (underlined label). Uses **`getDiscogsReleaseUrl(release)`** internally; do not duplicate icon + URL wiring in feature TSX. Community video upload URLs use **`getDiscogsReleaseVideosUpdateUrl(releaseId)`** in [`discogsReleaseUrls.ts`](../../src/utils/discogsReleaseUrls.ts) (**`…/release/{id}/videos/update`**, covered by [`discogsReleaseUrls.spec.ts`](../../src/utils/discogsReleaseUrls.spec.ts) — not **`DiscogsExternalLink.spec.tsx`**). Used in **`TrackYoutubeOverrideDialog`**; keep pure URL helpers out of **`"use client"`** Discogs link components. Inline artist/label/title metadata links stay on **[`ReleaseHeaderLinks`](../../src/components/ReleaseCard/ReleaseHeaderLinks.component.tsx)** (**`stopPropagation`** on click so nested modals do not swallow navigation).
- **Text actions** (underlined cancel/clear/edit links): import [`text-action.module.css`](../../src/styles/modules/text-action.module.css) in TSX (**`textActionStyles.meta`**, **`.primary`**, **`.muted`**, **`.xsmuted`**, **`.subtlelink`**) for **`<button>`** / **`<a>`** triggers — same pattern as [`DiscogsExternalLink`](../../src/components/DiscogsExternalLink/DiscogsExternalLink.component.tsx). Do **not** **`composes`** from feature CSS: Turbopack does not merge the shared class names onto the export, so native grey **`<button>`** chrome shows through. Keep feature-module classes only for layout/context overrides nested under a local hook class.
- Cover art: **`next/image`** with Discogs CDN URLs (`i.discogs.com`).
