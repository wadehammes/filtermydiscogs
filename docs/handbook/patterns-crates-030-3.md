On mobile, [`ReleasesClient`](../../src/components/ReleasesClient/ReleasesClient.component.tsx) wraps the drawer in **`.sidebar`** with **`display: contents`** so the bottom drawer is not suppressed by **`display: none`**. **`CrateDrawerProvider`** ([`CrateDrawer.context.tsx`](../../src/components/CrateDrawer/CrateDrawer.context.tsx)) wraps the drawer shell and calls **`useCrateDrawerState`** once; the same provider/context also powers owner pages (detail actions menu, set-notes scratchpad, packing toolbar). **Open/closed state** lives in [`useCrateDrawer`](../../src/hooks/useCrateDrawer.hook.ts): `isDrawerOpen = userToggled ?? isDesktop`. Use **`openDrawer()`** / **`closeDrawer()`** for explicit user actions; **`resetDrawer()`** clears `userToggled` back to viewport default; crossing **`DESKTOP_LAYOUT_MEDIA_QUERY`** also clears **`userToggled`** so mobile open/closed state does not stick on desktop. Mobile **[`FiltersDrawer`](../../src/components/FiltersDrawer/FiltersDrawer.component.tsx)** (from **[`FiltersBar`](../../src/components/StickyHeaderBar/FiltersBar.tsx)** and **[`MobileMenu`](../../src/components/StickyHeaderBar/MobileMenu.tsx)**) and the nav **[`MobileMenu`](../../src/components/StickyHeaderBar/MobileMenu.tsx)** bottom sheet call **[`useCloseMobileDrawerOnDesktop`](../../src/hooks/useCloseMobileDrawerOnDesktop.hook.ts)** to close when the desktop layout applies. **`addToCrate`** opens the drawer only when **`isDesktop`**. After OAuth login, **`CrateProvider`** calls **`resetDrawer()`**; logout/user switch calls **`closeDrawer()`**. Mobile crate FAB on **`/collection`** sits in **`PlaybackPageShell`** **`.workspaceOverlays`** (above the dock spacer; bottom inset from **`--workspace-fab-bottom`** in [`base.css`](../../src/styles/themes/base.css) — default **`space-6`**, **`space-2`** when the dock is visible via [`playback-dock.module.css`](../../src/styles/modules/playback-dock.module.css) — shared with **`BackToTop`**; border and shadow from **[`workspace-fab-chrome.module.css`](../../src/styles/modules/workspace-fab-chrome.module.css)** **`.fabchrome`**) and hides while the mobile menu, filters drawer, or playback queue (**`data-playback-queue-open`**) is open.
