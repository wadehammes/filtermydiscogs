## Icon buttons

Use **[`IconButton`](../../src/components/IconButton/IconButton.component.tsx)** / **[`IconButtonLink`](../../src/components/IconButton/IconButtonLink.component.tsx)** for icon controls (queue, close, crate +/-, segmented toggles, nav links, menu triggers, playback transport, …). Hover motion comes from **[`icon-button.module.css`](../../src/styles/modules/icon-button.module.css)** via **`iconButtonClasses()`** inside the component — do not **`composes`** **`icon-button`** in feature CSS or call **`iconButtonClasses()`** in feature TSX.

| Piece                                                                                   | Role                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`action-icon-hover.module.css`](../../src/styles/modules/action-icon-hover.module.css) | Low-level hover transforms — **`.iconactionmotion`** base (interaction states + **`--icon-action-transform`**) and opt-in tokens (**`.iconactionscale`**, **`.iconactionrotate`**, **`.iconactionplus`**, **`.iconactionminus`**, **`.iconactionqueuesubtle`**) plus **`.icon`**. Hover motion transforms the **`.icon`** wrapper (**`translateZ(0)`** + **`--icon-action-transform`**; direct **`> svg`** kept as a fallback) — not the inner **`svg`**, which blurs mid-scale in Firefox on high-DPI. Firefox uses a non-overshooting easing via **`@supports (-moz-appearance: none)`**. **Close** uses **`.iconactionrotate`** (**`rotate(90deg)`** only); **plus** uses **`.iconactionplus`** (**`rotate(90deg) scale(1.1)`**). **Skip** omits a motion class (no hover). |
| [`icon-button.module.css`](../../src/styles/modules/icon-button.module.css)             | Facade tokens — **`composes`** from **`action-icon-hover`**. **`variant*`** maps to motion classes; layout lives in **`.iconOnly`** (icon-only) or **`.labeled`** (icon + text/addon). Applied via **`iconButtonLayoutClass()`** inside **`IconButton`** / **`IconButtonLink`**.                                                                                                                                                                                                                                                                                                     |
| [`iconButtonClasses.ts`](../../src/components/IconButton/iconButtonClasses.ts)          | Maps **`variant`** to shared module classes and **`iconButtonLayoutClass(isLabeled)`** for layout mode — internal to **`IconButton`** / **`IconButtonLink`**.                                                                                                                                                                                                                                                                                                                                                                                                                        |
| **`variant`**                                                                           | **`default`** (scale pop), **`plus`** (quarter-turn + scale via **`.iconactionplus`**), **`minus`** (scale only — remove-from-crate), **`close`** (quarter-turn via **`.iconactionrotate`**), **`external`** (**`variantexternal`** composes **`.iconactionscale`** — same center **`scale(1.1)`** as **`default`**; **`DiscogsExternalLink`** / View on Discogs), **`queue`** (subtle scale only), **`skip`** (no hover — drag handles).                                                                                                                                            |

**Implementation rules:**
- **Refs** — **`IconButton`** / **`IconButtonLink`** accept a React 19 **`ref`** prop (**`Omit<…HTMLAttributes, "ref">` + `ref?: Ref<…> | undefined`**) and attach it to the native **`<button>`** / **`<a>`** / **`Link`**; do not wrap these primitives in **`forwardRef`** for new work.
- **No `cloneElement`** — wrap the SVG in **`<span className={iconButtonIconClasses(…)} aria-hidden>{children}</span>`** inside the button/link. Shared hover CSS transforms that **`.icon`** span (**`transform-origin: center`**, **`translateZ(0)`**) so rotate/scale stay centered and composite cleanly; do not transform the inner **`svg`** (Firefox high-DPI blur).
