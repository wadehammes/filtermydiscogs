## Releases grid ([`ReleasesGrid`](../../src/components/ReleasesClient/ReleasesGrid.component.tsx))

Card view renders via [`ReleasesGrid.module.css`](../../src/components/ReleasesClient/ReleasesGrid.module.css) (not the duplicate **`.releasesGrid`** block in [`ReleasesClient.module.css`](../../src/components/ReleasesClient/ReleasesClient.module.css) — keep both in sync if either changes).

| Concern           | Pattern                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Layout            | **CSS grid** — default single column; **`@container releases-main (min-width: 620px)`** on **[`ReleasesGrid.module.css`](../../src/components/ReleasesClient/ReleasesGrid.module.css)**: **`repeat(auto-fit, minmax(280px, 1fr))`** so columns follow the **main column** width (open crate drawer shrinks **`releases-main`**, not the viewport). **Sparse desktop filters (2–4 visible cards)**: [`ReleasesGrid`](../../src/components/ReleasesClient/ReleasesGrid.component.tsx) sets **`data-fixed-lanes`** and inline **`--grid-lane-count`** → **`repeat(var(--grid-lane-count), minmax(0, 20rem))`** so every filtered card stays on one row beside the open crate sidebar (cards may shrink below **`280px`**; cap **`20rem`** — do **not** stretch sparse rows with **`repeat(n, 1fr)`**). **Single card**: **`.releaseItem:only-child { max-width: 20rem }`**. **`.releaseItem`** uses **`overflow: visible`** so card hover **`outline`** / **`outline-offset`** and highlight **`box-shadow`** are not clipped — do **not** add **`content-visibility: auto`** on grid item wrappers                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
