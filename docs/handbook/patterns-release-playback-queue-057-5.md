- **Scope**: Global playback queue in **`ReleasePlaybackProvider`** — cross-release **`PlaybackQueueItem[]`** for **up next** only (the current track is **not** in the array). Each row may carry **`youtubeVideoId`**, **`artist`**, and **`releaseTitle`** (UserTrack / public-playlist fields from [`createQueueItem`](../../src/utils/playbackQueue.ts)). **`playQueueItem`** sets a **`nowPlayingQueueItem`** snapshot and resolves the embed id from the row (or explicit override) via [`playbackQueuePresentation.ts`](../../src/utils/playbackQueuePresentation.ts); the mini player reads **`activePlaybackTitle`** / **`activePlaybackArtist`** from that snapshot instead of waiting on Discogs tracklist index. Session still tracks **`release`**, **`activeTrackIndex`**, and **`activeTrackPosition`** for modal/collection UX. **`playbackHistory`** (internal state) holds tracks the listener has already played for **Previous**. Clicking a track row calls **`startPlayback`**, which plays that track and rebuilds upcoming from the remainder of the **playable album queue** (flattened tracks with embeddable YouTube matches after the clicked position via **`upcomingFromAlbumQueue`**). **Similar-release autoplay** is opt-in via **`preferences.extendQueueWithSimilarReleases`** (default **`false`**). When enabled and playback is active (not a paused start), upcoming **extends one related track at a time** when **`QUEUE_TAIL_EXTEND_THRESHOLD`** (2) or fewer rows remain—or **`MANUAL_QUEUE_TAIL_EXTEND_THRESHOLD`** (1) for manually built queues—but never more than one `fromSimilarRelease` row in up next at once (the next similar append waits until that row is played or removed): [`useReleasePlaybackSimilarQueue`](../../src/hooks/useReleasePlaybackSimilarQueue.hook.ts) loads collection matches via [`getSimilarReleases`](../../src/utils/similarReleases.ts) (up to **`SIMILAR_RELEASES_LIMIT`**), prefetches detail through React Query ([`similarReleaseQueue.ts`](../../src/utils/similarReleaseQueue.ts)), picks **one** shuffled playable track (**`SIMILAR_QUEUE_TAIL_TRACK_LIMIT`**), and appends it with **`fromSimilarRelease: true`** (deduped by **`instanceId` + `trackPosition`**). When upcoming is **empty**, the **currently playing release/track** is the similar source ([`resolveSimilarTailExtensionContext`](../../src/utils/playbackQueue.ts)). [`useReleasePlaybackPendingResolution`](../../src/hooks/useReleasePlaybackPendingResolution.hook.ts) re-invokes **`maybeExtendQueueTail`** when the loaded collection grows (**`allReleases.length`**), when **`extendQueueWithSimilarReleases`** is already enabled on mount or flips on after preferences load (short upcoming queue while transport is playing), and after pending resolution rebuilds an empty album upcoming list; **`maybeExtendQueueTail`** can enable similar tail when **`extendQueueWithSimilarReleases`** becomes available after **`startPlayback`** while album playback is already active (e.g. preferences still loading on first paint). **`addToQueue`** / **`addPreviewToQueue`** turn similar tail off until up next runs low again. **`addToQueue`** appends from the tracklist **Add to queue** control (list-plus icon; deduped by **`instanceId` + `trackPosition`**). Optional **`youtubeVideoId`** on **`AddToQueueParams`** is passed through when auto-start calls **`startPlayback`** (modal **Add to queue** for override-only rows). When the upcoming queue is empty and **`autoPlayOnQueueAdd`** is **`true`** (default), [`shouldAutoStartPlaybackOnQueueAdd`](../../src/utils/releasePlaybackQueueAutoStart.ts) calls **`startPlayback`** / **`startReleasePreview`** on the first add unless transport is already **active** on a loaded release (so **`clearQueue`** while a track keeps playing still allows silent appends); an **`inactive`** dock (release visible, transport off after e.g. missing embed) counts as not actively playing and auto-starts again. When **`autoPlayOnQueueAdd`** is **`false`**, items append silently. **Add all to queue** **`startPlayback`** on the first playable track when the mini player is hidden or transport is not **active** (**`inactive`** dock / **`!isPlaying`**) — **`startPaused: true`** when **`autoPlayOnQueueAdd`** is **`false`**, otherwise autoplay with **`rebuildAlbumQueue: false`** — then **`addToQueue`** for the rest; otherwise it appends each row to upcoming.
