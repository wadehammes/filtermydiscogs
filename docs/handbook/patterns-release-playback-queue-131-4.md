- **Playlist / public-share track position:** Public playlist payloads hydrate each row’s **`release`** with inline **`tracklist`** / **`videos`**. [`resolveQueueItemEmbedTracksVideos.ts`](../../src/utils/resolveQueueItemEmbedTracksVideos.ts) falls back to those fields via **`readReleaseEmbeddedTracklist`** / **`readReleaseEmbeddedVideos`** when React Query release detail is missing (read through **`DiscogsRelease`**’s index signature — do not add optional typed **`tracklist`** / **`videos`** on the interface). [`releasePlaybackPendingResolution.ts`](../../src/utils/releasePlaybackPendingResolution.ts) **`findQueueItemTrackResolutionIndex`** (wired from [`useReleasePlaybackQueueActions.hook.ts`](../../src/hooks/useReleasePlaybackQueueActions.hook.ts)) maps **`trackPosition`** against loaded session tracks **or** that embedded tracklist (collection-radio rows prefer inline **`tracklist`** when **`fromCollectionRadio`**) so **`RESOLVE_PENDING_TRACK`** can run before **`GET /api/release/[id]`** returns. **`playQueueItem`** keeps **`pendingTrackPosition`** until preview uri or immediate index resolution — an explicit row **`youtubeVideoId`** alone does **not** clear pending position (regression: **`when release detail is not loaded, playQueueItem with an explicit youtubeVideoId still pending the target track position`** in [`useReleasePlaybackQueueActions.hook.spec.ts`](../../src/hooks/useReleasePlaybackQueueActions.hook.spec.ts)).
- **Iframe postMessage** — [`playbackYoutubeEmbedIframeMessage.ts`](../../src/utils/playbackYoutubeEmbedIframeMessage.ts) classifies embed **`window.message`** payloads (ready → error → **infoDelivery** → state) and [`useReleasePlaybackYoutubeEmbed`](../../src/hooks/useReleasePlaybackYoutubeEmbed.hook.ts) routes them in a fixed order: dock progress **`onEmbedInfoDelivery`** always runs before confirm/transport side effects; **PLAYING** **`infoDelivery`** without **`currentTime`** / **`duration`** schedules a debounced **`syncEmbedPlaybackState`**. [`syncYoutubeEmbedPlaybackProgress`](../../src/utils/postYoutubePlayerCommand.ts) is the shared choke point for polls, tab-visible recover, and imperative-load follow-up (**`listening`** + **`getCurrentTime`** / **`getDuration`**).
