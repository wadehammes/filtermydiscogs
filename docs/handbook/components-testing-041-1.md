## Testing

- Colocate specs with the component when adding coverage (`*.spec.tsx`; optional **`*.po.tsx`**). Release-detail fixtures in specs/POs use nested factories (**`discogsVideoFactory`**, **`discogsTrackFactory`**) — enforced repo-wide by [`handbookTestRules.ts`](../../src/tests/utils/handbookTestRules.ts) (see [conventions.md → Test data and factories](conventions.md#test-data-and-factories)).
- **Promotional / account capture toasts**: [`EmailAccountCaptureToast.spec.tsx`](../../src/components/EmailAccountCaptureToast/EmailAccountCaptureToast.spec.tsx) + [`EmailAccountCaptureToast.po.tsx`](../../src/components/EmailAccountCaptureToast/EmailAccountCaptureToast.po.tsx) mount **`AppToaster`** + host with authenticated **`TestProviders`**; the PO calls **[`setupDefaultCrateApiMocks`](../../src/tests/mocks/setupDefaultCrateApiMocks.ts)** in **`setupMocks()`** ( **`CrateProvider`** still runs) plus **`mockApiResponse`** on **`checkAuth`** / **`userContact`** and seeded React Query for auth/contact. Standalone URL-driven hosts without API wiring (e.g. [`DonationSuccessToast.spec.tsx`](../../src/components/DonationSuccessToast/DonationSuccessToast.spec.tsx)) may omit a PO. Eligibility pure logic: [`userContactEmailCaptureEligibility.spec.ts`](../../src/utils/userContactEmailCaptureEligibility.spec.ts); toast helper dismiss: [`emailAccountToast.spec.tsx`](../../src/components/EmailAccountCaptureToast/emailAccountToast.spec.tsx). Support host: [`SupportProjectToast.spec.tsx`](../../src/components/SupportProjectToast/SupportProjectToast.spec.tsx) + [`SupportProjectToast.po.tsx`](../../src/components/SupportProjectToast/SupportProjectToast.po.tsx) (mocks **`supportProjectToast`** + **`api.dismissSupportProjectToast`**). ToastManager Jotai gates: [`toastManager.atoms.spec.ts`](../../src/atoms/toastManager.atoms.spec.ts), [`useToastPresentationGate.hook.spec.tsx`](../../src/components/ToastManager/useToastPresentationGate.hook.spec.tsx), [`useToastHostReadyAfterMount.hook.spec.ts`](../../src/components/ToastManager/useToastHostReadyAfterMount.hook.spec.ts), [`useShowToastOnce.hook.spec.ts`](../../src/components/ToastManager/useShowToastOnce.hook.spec.ts) — one flat **`describe`** each ([conventions.md → Hook checklist](conventions.md#hook-and-feature-spec-checklist)).
- **Watcher toasts + colocated helpers** (e.g. [`CollectionLoadingToast`](../../src/components/CollectionLoadingToast/), [`DiscogsOutageToast`](../../src/components/DiscogsOutageToast/)): put **helper** tests in **`<Folder>/<Folder>.spec.tsx`** (mocks **`src/utils/toast`**, asserts **`show*`** / dismiss / copy) and **component** tests in **`<Folder>/<Folder>.component.spec.tsx`** that import the **PO only** (see [`CollectionLoadingToast.spec.tsx`](../../src/components/CollectionLoadingToast/CollectionLoadingToast.spec.tsx) + [`CollectionLoadingToast.component.spec.tsx`](../../src/components/CollectionLoadingToast/CollectionLoadingToast.component.spec.tsx), [`DiscogsOutageToast.spec.tsx`](../../src/components/DiscogsOutageToast/DiscogsOutageToast.spec.tsx) + [`DiscogsOutageToast.component.spec.tsx`](../../src/components/DiscogsOutageToast/DiscogsOutageToast.component.spec.tsx)). **Do not** add a second spec whose name differs only by case (e.g. **`discogsOutageToast.spec.tsx`** next to **`DiscogsOutageToast.spec.tsx`**) — on case-insensitive volumes (default macOS) that is one file and will silently overwrite the other, break PO imports, and fail **`pnpm knip:ci`** (“unused” **`.po.tsx`**).
- Use **`render`** from **`test-utils`** when auth, filters, or crate context is required **without** mocking (default wrapper is **`TestProviders`**). Context-heavy component tests usually mock context in the PO and use **`render`** instead (see [conventions.md → Testing](conventions.md#testing)).
- **Page composition in POs**: When production mounts a component inside a layout plus server footer (e.g. home = `PublicAuthLayout` + `PageFooter` + `Login`), the PO **`render*`** helper should mirror that tree. Put **`jest.mock("src/components/Page/PageFooter.server")`** in the PO and render `<PageFooter />` in the layout’s `footer` prop—do not inline a partial footer that omits links the spec asserts on. [`Login.po.tsx`](../../src/components/Login/Login.po.tsx) **`renderLogin(authInitialState?)`** wraps that tree and passes **`skipInitialAuthCheck: true`** plus optional seeded **`AuthState`** (e.g. **`isCheckingAuth: true`** for the session-check landing spec)—specs still call **`renderLogin`** via the PO, not bare **`<Login />`**.
