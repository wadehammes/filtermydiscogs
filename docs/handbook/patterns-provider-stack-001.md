## Provider stack

[`src/components/Providers.tsx`](../../src/components/Providers.tsx) nests providers in this order (outer → inner):
1. **QueryClientProvider** — TanStack Query defaults (10 min stale time, limited refetch).
2. **JotaiProvider** — shared Jotai store for client UI state ([`src/atoms/JotaiProvider.tsx`](../../src/atoms/JotaiProvider.tsx)).
3. **ThemeProvider** — named palette themes from [`PALETTE_THEMES`](../../src/utils/themeAppearance.ts) (amber, aurora, codex, dark, dim, discogs, ember, forest, futuristic, high-contrast, lavender, light, midnight, ocean, prism, sepia, slate, sunset, summer, terracotta, wine) plus **`system`** (**`system`** last in pickers). **`system`** resolves to **`light`** or **`dark`** from the OS preference ([`SYSTEM_DARK_PALETTE`](../../src/utils/themeAppearance.ts)). Pre-hydration **`public/theme-init.js`** loads from the root layout via **`next/script`** with **`strategy="beforeInteractive"`** (do not use a raw **`<script>`** in **`<head>`** — React 19 will not run it on the client). Generated from the same constants via **`pnpm generate:theme-init`** ([`resolveThemeInitAttribute`](../../src/utils/themeAppearance.ts) mirrors its resolution rules; [`applyThemeFromStorage`](../../src/utils/applyThemeFromStorage.ts) uses that helper). Token files under [`src/styles/themes/`](../../src/styles/themes/). For PPR, the inner provider (media query + pathname sync) is wrapped in **`<Suspense>`** — see [platform.md](platform.md) (PPR and blocking client hooks).
4. **AuthProvider** — OAuth session state.
5. **CollectionContextProvider** — collection pagination metadata only (not the release list).
6. **FiltersProvider** — scope marker for filter hooks (state lives in [`src/atoms/filters.atoms.ts`](../../src/atoms/filters.atoms.ts)).
7. **ViewProvider** — scope marker for view hooks (state in [`src/atoms/view.atoms.ts`](../../src/atoms/view.atoms.ts)).
8. **PlaybackReleaseClickProvider** — always mounted so public crate pages can register release-click handlers without loading the authenticated shell chunk.
9. **CrateProvider** — always mounted so public pages (e.g. **`/about`** **`useClearAllUserData`**) and protected route prerender shells can call **`useCrate()`**; crate queries stay disabled until auth settles.
10. **[`CollectionCachePrepGate`](../../src/components/CollectionCachePrepGate/CollectionCachePrepGate.component.tsx)** — as soon as auth exposes a Discogs username ([`resolveCollectionCacheUsername`](../../src/utils/resolveCollectionCacheUsername.ts): active session or soft-logout **`reconnectUsername`**), validates and hydrates the IndexedDB collection cache into React Query via [`useCollectionCacheReady`](../../src/hooks/useCollectionCacheReady.hook.ts). Runs before **`CollectionDataSync`** so quick re-login can render cached releases without a “No releases found” flash.
11. **AuthenticatedCollectionSyncGate** — mounts **`CollectionDataSync`** when **`isAuthenticated`** (outside the dynamic chunk so pagination sync starts as soon as the session is active).
12. **[`AuthenticatedProvidersGate`](../../src/components/AuthenticatedProvidersGate.component.tsx)** — wraps **`AnalyticsShell`** only. **Signed-in** sessions dynamically load **[`AuthenticatedProviders`](../../src/components/AuthenticatedProviders.tsx)** (**`PlaybackProvidersShell`**) on **every** route (including public share URLs) so client navigation to **`/collection`** never unmounts **`ReleasePlaybackProvider`** between **`PublicSharePlaybackShell`** and the gate. **Logged-out** visitors on public share pages rely on page-local **`PublicSharePlaybackShell`** only; logged-out **protected** routes omit playback until sign-in. While auth is still checking, the shell loads only on **protected** routes. Route classification uses **[`useAuthenticatedGatePathname`](../../src/hooks/useAuthenticatedGatePathname.hook.ts)** ( **`PathnameContext`**, not dev-instrumented **`usePathname`**) so a lagging router pathname during client transitions (e.g. **`/collection`** → **`/playlist/[id]`** or **`/release/[id]`**) does not treat a public URL as protected when logged out. **`Suspense`** uses **`fallback={children}`**. See [Public share vs authenticated app](#public-share-vs-authenticated-app).
