Global toasts use **Base UI** [`Toast`](https://base-ui.com/react/components/toast) via [`AppToaster`](../../src/components/AppToaster/AppToaster.component.tsx) (triple viewports: bottom-right default, bottom-center for action/loading and desktop queue toasts, top-center for mobile queue toasts; **`--z-8-toast`** above modals/tooltips). The **top-center** viewport uses mobile-first CSS: default inset below **`--sticky-header-total-height`**, then **`@media (width >= 768px)`** switches to a **`1rem`** top offset; toasts anchor from the **top** (stack grows downward), not the bottom-right stack used in other viewports. Queue add toasts pick top vs bottom position in JS via **`COMPACT_LAYOUT_MEDIA_QUERY`** in [`playbackQueueToast.ts`](../../src/utils/playbackQueueToast.ts). Type-based styling and layout live in [`AppToaster.module.css`](../../src/components/AppToaster/AppToaster.module.css) (**`--font-family-mono`**, **`--background`**-based surfaces, semantic tints for success/error; success toasts include a checkmark icon). **`Toast.Description`** defaults to a **`<p>`**; when **`description`** is a React node (not a plain string), **`AppToaster`** renders it with **`render={<div />}`** so block markup (e.g. lists in the playback skip log toast) stays valid HTML. Import **`toast`** from [`src/utils/toast.ts`](../../src/utils/toast.ts) for user feedback — prefer toasts over **`alert()`** for non-blocking errors and success messages.
