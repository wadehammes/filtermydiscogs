| `/api/crates/migrate`                   | POST               | Bulk import legacy localStorage releases into the user's default crate (`{ releases }`, max **`LEGACY_CRATE_MIGRATE_MAX`**)                                                                                                                                                                                                                                                                                                                                                       |
| `/api/crates/sync`                      | POST               | Sync local crate state with server; orphan detection scans **all** crate-release rows via **`count`** + **`groupBy instance_id`** ([`crate-sync.server.ts`](../../src/lib/crate-sync.server.ts)) — no row cap; **400** responses include **`blockedReason`** (`collection_too_small` \| `deletion_cap_blocked`) when sync is refused; blocks bulk deletes above 50% unless **`force=true`** (structured **`crate_sync_force_override`** log + audit metadata)                     |
| `/api/playlists`                        | GET, POST          | List/create user playlists ([`playlist.server.ts`](../../src/lib/playlist.server.ts)); GET ordered by **`updated_at` desc** with **`trackCount`**. Optional **`?trackKey=`** (Zod in [`listPlaylistsQuerySchema`](../../src/lib/validation/playlist.schemas.ts)) adds **`containsTrack`** per row for the add-to-playlist picker ([**`useReleasePlaylistPickerController`](../../src/hooks/useReleasePlaylistPickerController.hook.ts)** → separate React Query key via **`PlaylistsQueryKeys.byUserIdAndTrackKey`**)                                                                                                                                                                                                                                                                                                                                 |
| `/api/playlists/[id]`                   | GET, PATCH, DELETE | Playlist detail (tracks joined from **`UserTrack`**) / rename / delete                                                                                                                                                                                                                                                                                                                                                                                                            |
| `/api/playlists/[id]/tracks`            | POST, DELETE, PUT  | Add track (**`addPlaylistTrackBodySchema`** = **`userTrackMetadataBodySchema`**; upserts **`UserTrack`** first), remove by **`track_key`**, reorder full **`track_keys`** list (**409** on duplicate add). Successful mutations revalidate public **`/playlist/[id]`** cache when the playlist is public (**[`revalidatePublicPlaylistShareWhenPublic`](../../src/lib/public-share-cache.server.ts)**)                                                                                                                                                                                                                                                                         |
| `/api/playlists/public/[id]`            | GET                | Public playlist payload (**`discogsHydration`** via [`publicPlaylistGetQuerySchema`](../../src/lib/validation/playlist.schemas.ts) — default **`snapshotsOnly`**; optional **`?discogsHydration=full`**). Attaches **`viewerVote`** / **`viewerIsOwner`**; **`Cache-Control: private, no-store`**. [`route.spec.ts`](../../src/app/api/playlists/public/[id]/route.spec.ts).                                                                                                                                                                |
| `/api/playlists/public/[id]/view`       | POST               | Increment **`public_view_count`** for a public playlist (IP rate-limited; optional verified session — owner skips increment but receives current **`shareStats`**)                                                                                                                                                                                                                                                                                                                                                                              |
| `/api/playlists/public/[id]/play`       | POST               | Increment **`public_play_count`** when playback starts from the public playlist page (IP rate-limited; optional verified session — owner skips increment but receives current **`shareStats`**, same as **`/view`**)                                                                                                                                                                                                                                                                                                                                 |
| `/api/tracks/record`                    | POST               | Record **`play`** or **`listen`** for a track (`userTrackRecordBodySchema`)                                                                                                                                                                                                                                                                                                                                                                                                       |
