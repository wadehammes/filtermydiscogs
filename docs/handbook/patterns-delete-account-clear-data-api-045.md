## Delete account (clear-data API)

About/Legal/Settings **Delete account** (UI; confirm phrase **`DELETE MY ACCOUNT`**) calls **`api.clearData`** in [`src/api/urls.ts`](../../src/api/urls.ts) → **`POST /api/auth/clear-data`**, which deletes the **`User`** row (cascades crates, playlists, and **`user_tracks`** playback stats; clears **`User.preferences`** including **`filterViews`**, plus **`email`** and **`marketing_emails_opt_in`**), and clears session cookies. Client reset uses **`useClearAllUserData`** ([`useClearAllUserData.hook.ts`](../../src/hooks/useClearAllUserData.hook.ts)), **`useCollectionReset`** ([`useCollectionReset.hook.ts`](../../src/hooks/useCollectionReset.hook.ts)), and **`clearClientStoredData`** ([`clearClientStoredData.ts`](../../src/utils/clearClientStoredData.ts)) to remove filter preferences, view state, theme, analytics consent, legacy crate migration data, release playback resume state, the dock video intro flag from **`localStorage`**, per-user last-played playlist ids ([`lastPlayedPlaylistStorage.ts`](../../src/utils/lastPlayedPlaylistStorage.ts)), remembered collection size, and the IndexedDB collection page cache; **`queryClient.clear()`** also wipes in-memory React Query caches. About and Legal use **`useConfirmClearAllUserData`** ([`useConfirmClearAllUserData.hook.ts`](../../src/hooks/useConfirmClearAllUserData.hook.ts)) for the shared confirm dialog copy in [`clearData.constants.ts`](../../src/constants/clearData.constants.ts). Logout clears playback only—not filter, view, analytics consent, or the IndexedDB collection cache.
