| `pnpm fallow` / `pnpm fallow:dead-code` / `pnpm fallow:health` / `pnpm fallow:health:full` / `pnpm fallow:dupes` | **Fallow** codebase intelligence ([`.fallowrc.jsonc`](../../.fallowrc.jsonc)) — cycles, dupes, complexity, unresolved imports. **`pnpm fallow:audit`** (local / **`mise run pr-prep`**) uses Fallow’s default **`gate: new-only`** (can fail on introduced findings). **`pnpm fallow:audit:ci`** matches Actions: full report with **`--worsened warn`**, always **exit 0** — worsened complexity and introduced **architecture** findings (from the audit dead-code pass: boundaries, policy, cycles) are logged for review, not merge blockers (see [`fallow-audit-ci.sh`](../../scripts/fallow-audit-ci.sh)). **`pnpm fallow:health`** prints the project **health score** (`--score`). **`pnpm fallow:health:full`** adds complexity lists and hotspot deductions. **Cursor:** [`.cursor/mcp.json`](../../.cursor/mcp.json) (MCP) + task map in [`AGENTS.md`](../../AGENTS.md) (see [Fallow vs Knip](#fallow-vs-knip)). |
