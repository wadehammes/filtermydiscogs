## Stack

- **ORM**: Prisma 7 with **`prisma-client-js`** (production). **Prisma 8** (`prisma@8` RC) is for staging/preview validation only until **`8.0.0` GA** — do not deploy RC builds to production.
- **Database**: PostgreSQL (Vercel Postgres in production)
- **Client**: [`src/lib/db.ts`](../../src/lib/db.ts) — singleton Prisma client for route handlers (lazy init on first **`prisma`** access). On **`pooled.db.prisma.io`**, the pg pool uses shorter default **`idleTimeoutMillis`** (**10s**), **`keepAlive`**, **`maxUses`**, and **`maxLifetimeSeconds`**, plus a one-shot Prisma query retry for transient **`Connection terminated unexpectedly`** failures ([`prismaConnectionRetryExtension.server.ts`](../../src/lib/prismaConnectionRetryExtension.server.ts)). Public share loaders in **[`public-crate.server.ts`](../../src/lib/public-crate.server.ts)** and **[`public-playlist.server.ts`](../../src/lib/public-playlist.server.ts)** return **`null`** when [`readRuntimeDatabaseUrlFromEnv`](../../src/lib/databaseUrlEnv.ts) is unset (e.g. local **`pnpm build`** without migrate **`POSTGRES_URL`** / **`DIRECT_URL`**) so static generation for **`/crate/[id]`** / **`/playlist/[id]`** does not throw **“DATABASE_URL … is not set”** or spam the console. Connection string from **`readRuntimeDatabaseUrlFromEnv`**: **request/runtime** — usable **`DATABASE_URL_POOLED`**, else **`DATABASE_URL`** with **`db.prisma.io` → `pooled.db.prisma.io`** (ignores **`[SENSITIVE]`** / non-URL placeholders from **`vercel env pull`**); **`next build`** (**`NEXT_PHASE=phase-production-build`**) — same URL order as migrate (**`DIRECT_URL` → `POSTGRES_URL` → `DATABASE_URL`**) so build-time SSG (e.g. public crate **`generateStaticParams`**) uses direct Prisma Postgres, not the pooler. [`sanitizePostgresConnectionStringForPg`](../../src/lib/databaseUrlEnv.ts) normalizes SSL query params; **does not** set URL or pg-pool **`statement_timeout`** on **`pooled.db.prisma.io`** (Prisma Postgres pooler rejects it — upstream connection errors). Direct hosts still get **`statement_timeout`**. Caps pg **`max`** at **1** during build.

Schema: [`prisma/schema.prisma`](../../prisma/schema.prisma). Datasource URL: [`prisma.config.ts`](../../prisma.config.ts) (Prisma 7).
