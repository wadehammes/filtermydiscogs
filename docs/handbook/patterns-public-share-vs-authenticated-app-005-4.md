**Playback state hook (cycle break):** [`useReleasePlaybackState.hook.ts`](../../src/context/useReleasePlaybackState.hook.ts) owns **`useReleasePlaybackState`**; [`releasePlayback.context.tsx`](../../src/context/releasePlayback.context.tsx) re-exports it for app code. Leaf hooks that must not pull in **`ReleasePlaybackProvider`** (e.g. [`useTrackListenRecorder.hook.ts`](../../src/hooks/useTrackListenRecorder.hook.ts)) import the defining hook module directly.

**Track–video matching (util split):** scoring and **`buildReleasePlaybackMatchIndex`** live in [`releasePlaybackTrackVideoMatching.ts`](../../src/utils/releasePlaybackTrackVideoMatching.ts) (+ [`releasePlaybackTrackVideoMatching.spec.ts`](../../src/utils/releasePlaybackTrackVideoMatching.spec.ts)). [`releasePlayback.ts`](../../src/utils/releasePlayback.ts) keeps embed URLs, queue helpers, preview rows, and re-exports **`buildReleasePlaybackMatchIndex`**, **`parseYoutubeVideoId`**, and **`ReleasePlaybackMatchIndex`** only (Knip — do not re-export symbols with no barrel consumers).

**Knip / hook barrels:** Import context objects from **`*Contexts.tsx`** (or the feature **`…EditorContext.tsx`**) inside the provider and hook module. Do **not** re-export those context instances from the hook barrel — nothing should import them from there, and **`pnpm knip:ci`** flags unused re-exports. Export **hooks**, **`XProvider`**, and **types** only.

**Breaking cycles:** (1) Move shared props/types to a **`*.types.ts`** file both sides can import. (2) Prefer **constants** modules over utils that pull in UI (e.g. **`SortValues`** from [`sortValues.ts`](../../src/constants/sortValues.ts), not filter context; **`PLAYBACK_EMBED_UNAVAILABLE_FALLBACK`** in [`playbackEmbedErrorCodes.ts`](../../src/constants/playbackEmbedErrorCodes.ts) so Sentry skip helpers do not import [`playbackEmbedUnavailableSkip.ts`](../../src/utils/playbackEmbedUnavailableSkip.ts) through [`playbackSkipSentrySource.ts`](../../src/lib/sentry/playbackSkipSentrySource.ts)). (3) Split context **`createContext`** from provider hooks and import consumer hooks from a defining module when a leaf feature (e.g. track listen recording) must not transitively import **`XProvider`**. (4) For remaining lazy in-tree chunks (charts, queue drawer), warm with **`import()`** in a leaf util — never add a **static** import from the lazy module into shared code the lazy module also imports. Use **Fallow** (`pnpm fallow:dead-code`) to find cycles before merge; **Knip** does not report them.
