Colocated hook spec: **[`usePublicReleaseListenPageState.hook.spec.tsx`](../../src/components/PublicReleasePage/usePublicReleaseListenPageState.hook.spec.tsx)**. Track rows reuse **`PublicPlaylistTrackItem`** with **`showTrackVoteControls={false}`**, **`requireYoutubeForPlayback`**, and **`playlistId={releaseId}`** (vote UI omitted; rows without a matched YouTube id omit play controls). When the tracklist has positions but none have playable videos, **[`PublicReleaseNoPlayableTracksNote`](../../src/components/PublicReleasePage/PublicReleaseNoPlayableTracksNote.component.tsx)** (**`fmdPublicReleaseNoPlayableTracksNote`**) appears before the list; **`fmdPublicReleaseNoPlayableTracksInfo`** opens a Base UI tooltip (**[`publicReleaseListen.constants.ts`](../../src/constants/publicReleaseListen.constants.ts)**) on why Discogs video matching may leave rows unplayable.
