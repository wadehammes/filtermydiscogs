# Collection command palette (v1)

Natural-language commands on **`/collection`** (v1: filter intent via AI Gateway; **Run** → preview, **Apply filters**, **Save view**, **Create crate**). When the command text mentions a crate (**`promptMentionsCollectionCrate`**), preview **Create crate** is the primary action (↵ default) ahead of **Apply filters**. Saved views and prompt-created crates are auto-named by **`buildCollectionCommandViewName`** / **`buildCollectionCommandCrateName`** (crate names allow up to **`CRATE_NAME_MAX_LENGTH`**): explicit AI **`suggestedViewName`** when the user names a view, else a compact label from preview filters (year first, styles/formats joined with **`/`**), else the trimmed prompt (**`saveViewFromFilters`**, no save dialog; rename in **Views** or **Crates** later). **Create crate** uses **`listCollectionCommandMatchedReleases`**, **`useOptionalCrateActions` → `createCrate`**, then **`addCollectionCommandReleasesToCrate`** (**`api.addReleaseToCrate`** per match; 409 skips duplicates) and crate query invalidation when the batch finishes. UI: **cmdk** command strip; primary/secondary actions use shared **[`Button`](../../src/components/Button/Button.component.tsx)** (**`Command.Item asChild`**); recent prompts use **`InlinePopoverMenu`** **`itemNeutral`** row styling; shortcut from **`User.preferences`** (default **`mod+shift+k`**).

## Routes and env

- **`POST /api/collection/interpret-prompt`** — auth required; body `{ prompt }`; returns `{ intent }`. See [platform.md → Environment variables](../platform.md#environment-variables) (`AI_GATEWAY_API_KEY`, `COLLECTION_COMMAND_AI_MODEL`). Structured output uses **`collectionCommandIntentGenerationSchema`** (every field required for the gateway); normalized with **`parseCollectionCommandIntentFromLlm`**. The system prompt includes **today’s ISO date** and **calendar year**; **`applyPromptYearBoundsToIntent`** ([`collectionCommandPromptYears.ts`](../../src/utils/collectionCommandPromptYears.ts)) deterministically maps phrases like **last N years**, **this year**, and **last year** to bounds so stale model years (e.g. 2022–2023) are overridden. Other relative ranges (e.g. “before 2019”) use LLM **`yearStartInclusive`** / **`yearEndExclusive`** (0 = unset); **`sanitizeCollectionCommandIntent`** expands bounds against **`facetOptions.availableYears`**. Year bounds with the default sort → **`AlbumYearNew`** unless the prompt requests another sort.
- Client: **`api.interpretCollectionCommand`** in [`collectionCommand.ts`](../../src/api/endpoints/collectionCommand.ts).

## Client flow

[`useCollectionCommandPalette`](../../src/hooks/useCollectionCommandPalette.hook.ts) + [`CollectionCommandPalette`](../../src/components/CollectionCommandPalette/CollectionCommandPalette.component.tsx) on [`ReleasesClient`](../../src/components/ReleasesClient/ReleasesClient.component.tsx). Desktop **[`FiltersBar`](../../src/components/StickyHeaderBar/FiltersBar.tsx)** embeds search in [`CollectionSearchCommandSegment`](../../src/components/StickyHeaderBar/CollectionSearchCommandSegment.component.tsx): bordered segment + sentence-case **`Ask`** chip ([`SparklesThinIcon`](../../src/styles/icons/SparklesThinIcon.component.tsx) + [`COLLECTION_COMMAND_CHIP_LABEL`](../../src/constants/collectionCommand.constants.ts)); palette prompt row uses the same icon beside [`Command.Input`](../../src/components/CollectionCommandPalette/CollectionCommandPalette.component.tsx). tooltip via [`buildCollectionCommandOpenTooltip`](../../src/utils/buildCollectionCommandOpenTooltip.ts) (**`COLLECTION_COMMAND_OPEN_TOOLTIP_LEDE`** + **`formatShortcutChipAbbreviation`** shortcut) → [`openCollectionCommandPalette`](../../src/utils/collectionCommandPaletteBridge.ts) (registered from the palette hook). **Filter views** bar trigger drops the default **Views** label when no saved view is selected (icon + chevron only) to balance bar width. Recent prompts: **`localStorage`** per user ([`collectionCommandPromptHistory.ts`](../../src/utils/collectionCommandPromptHistory.ts)); cleared on **Clear stored data**.

After **Run**, the hook stores the interpreted prompt as **`previewSourcePrompt`**. Editing the command input (typing, picking **Recent**, paste) clears preview state when **`query.trim()`** no longer matches that source prompt so **Apply** / **Save view** cannot target a stale interpret. While a preview is open, **`sanitizeCollectionCommandIntent`** re-runs when **`facetOptions`** grow during collection pagination ([`persistedFiltersEqual`](../../src/utils/filtersStorage.ts) skips no-op updates). The command input placeholder is [**`COLLECTION_COMMAND_INPUT_PLACEHOLDER`**](../../src/constants/collectionCommand.constants.ts) (generic plain-English commands — not keyword search). It uses **`maxLength`** [**`COLLECTION_COMMAND_PROMPT_MAX_LENGTH`**](../../src/constants/collectionCommand.constants.ts) (same cap as the route body schema). Recent prompt rows load when the palette opens (**`useMemo`** on **`open`** / **`promptHistoryRevision`**), not on every keystroke. **Panel footer** (`fmdCollectionCommandPanelFooter`): **Start over** (`COLLECTION_COMMAND_START_OVER_LABEL`, **`fmdCollectionCommandStartOver`**, left, when the command input has text, a preview is open, or interpret failed) calls **`startOver`** (**`resetPaletteState`** — clears query + preview, keeps the palette open) and refocuses **`Command.Input`**. **Clear recent** (`COLLECTION_COMMAND_CLEAR_RECENT_LABEL`, native **`button`** + **`text-action.module.css`** **`subtlelink`**, left, only while browsing past commands — empty **`query`**, history exists, no preview / **Run** / action step) and **Report command issue** (right) share **`panelFooterAction`** typography (**`--text-sm`**). **Clear recent** calls **`clearCollectionCommandPromptHistory`** and swaps back to **Examples** (no visible section eyebrow). With no history, the list shows **Examples** from [**`buildCollectionCommandExamplePrompts`**](../../src/utils/collectionCommandExamplePrompts.ts) — three short differentiated sentences (refine / save view / create crate, or explore / save / crate when nothing is filtered), capped by [**`COLLECTION_COMMAND_EXAMPLE_PROMPT_MAX_LENGTH`**](../../src/constants/collectionCommand.constants.ts); idle explore/save/crate rows use [**`sampleDistinctFacetStyles`**](../../src/utils/collectionCommandExamplePrompts.ts) (one style or format per line, seeded shuffle) and [**`refineIdleExampleSlots`**](../../src/utils/collectionCommandExamplePrompts.ts) swaps labels when [**`listCollectionCommandMatchedReleases`**](../../src/utils/collectionCommandMatchedReleases.ts) would return zero matches for the loaded **`releases`** (passed from **`useCollectionCommandPalette`**); session [`sessionFiltersAtom`](../../src/atoms/filters.atoms.ts) + facet options; **[`COLLECTION_COMMAND_EXAMPLE_PROMPTS_FALLBACK`**](../../src/constants/collectionCommand.constants.ts) when empty. Past/example rows use the same **`recentRow`** pattern; tap a row to fill the command input.

**Save view** from the palette uses [`saveViewFromFilters`](../../src/hooks/useFilterViews.hook.ts) (no **`SaveFilterViewDialog`**). Preview invalidation logic: [`shouldClearCollectionCommandPreview`](../../src/utils/collectionCommandPalettePreview.ts) (**[`useCollectionCommandPalette.hook.spec.ts`](../../src/hooks/useCollectionCommandPalette.hook.spec.ts)** — interpret, apply, facet re-sanitize). Interpret failures log via **`logSanitizedApiRouteFailure`** in [`collection-command-interpret.server.ts`](../../src/lib/collection-command-interpret.server.ts) (catch path; route returns **502** per [`interpret-prompt/route.spec.ts`](../../src/app/api/collection/interpret-prompt/route.spec.ts)).

The palette **Report command issue** footer control → closes the palette and opens the shared [`SentryUserFeedbackDialog`](../../src/components/SentryUserFeedbackDialog/SentryUserFeedbackDialog.component.tsx) via [`openCollectionCommandSentryFeedback`](../../src/lib/sentry/openCollectionCommandSentryFeedback.client.ts) (always opens the dialog; **`submitSentryUserFeedback`** / [`deliverSentryClientCapture`](../../src/lib/sentry/deliverSentryClientCapture.client.ts) gate delivery and show an error toast when Sentry is disabled). Submissions tag **`feedback_source:collection_command`**. The dialog shows the current **prompt** (and optional interpret error / preview facts) as read-only context, requires a **radio** issue category ([`collectionCommandUserReportLabels.ts`](../../src/utils/collectionCommandUserReportLabels.ts)), and leaves **Details (optional)** as an empty freeform textarea. Submit composes the Sentry message with [`buildCollectionCommandSentryFeedbackMessage`](../../src/utils/buildCollectionCommandSentryFeedbackMessage.ts).
