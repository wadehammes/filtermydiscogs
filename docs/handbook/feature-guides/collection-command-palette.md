# Collection command palette (v1)

Natural-language commands on **`/collection`** (v1: filter intent via AI Gateway; **Run** → preview, **Apply filters**, **Save view**, **Create crate**). When the command text mentions a crate (**`promptMentionsCollectionCrate`**), preview **Create crate** is the primary action (↵ default) ahead of **Apply filters**. Saved views and prompt-created crates are auto-named by **`buildCollectionCommandViewName`** / **`buildCollectionCommandCrateName`** (crate names allow up to **`CRATE_NAME_MAX_LENGTH`**): explicit AI **`suggestedViewName`** when the user names a view, else a compact label from preview filters (year first, styles/formats joined with **`/`**), else the trimmed prompt (**`saveViewFromFilters`**, no save dialog; rename in **Views** or **Crates** later). **Create crate** uses **`listCollectionCommandMatchedReleases`**, **`useOptionalCrateActions` → `createCrate`**, then **`addCollectionCommandReleasesToCrate`** (**`api.addReleaseToCrate`** per match; 409 skips duplicates) and crate query invalidation when the batch finishes. UI: **cmdk** command strip; shared **[`Button`](../../src/components/Button/Button.component.tsx)** (**`Command.Item asChild`** for **Run** and preview actions); **Examples** / past prompts use **`InlinePopoverMenu`** **`itemNeutral`** **`recentRow`** rows; after **Run**, preview primary action uses **`variant="primary"`** and secondary **Save view** / **Create crate** use ghost **`itemNeutral`** (see **Panel list layout**); shortcut from **`User.preferences`** (default **`mod+shift+k`**).

## Routes and env

- **`POST /api/collection/interpret-prompt`** — auth required; body `{ prompt }`; returns `{ intent }`. See [platform.md → Environment variables](../platform.md#environment-variables) (`AI_GATEWAY_API_KEY`, `COLLECTION_COMMAND_AI_MODEL`). Structured output uses **`collectionCommandIntentGenerationSchema`** (every field required for the gateway); normalized with **`parseCollectionCommandIntentFromLlm`**. The system prompt includes **today’s ISO date** and **calendar year**; **`applyPromptYearBoundsToIntent`** ([`collectionCommandPromptYears.ts`](../../src/utils/collectionCommandPromptYears.ts)) deterministically maps phrases like **last N years**, **this year**, and **last year** to bounds so stale model years (e.g. 2022–2023) are overridden. Other relative ranges (e.g. “before 2019”) use LLM **`yearStartInclusive`** / **`yearEndExclusive`** (0 = unset); **`sanitizeCollectionCommandIntent`** expands bounds against **`facetOptions.availableYears`**. Year bounds with the default sort → **`AlbumYearNew`** unless the prompt requests another sort.
- Client: **`api.interpretCollectionCommand`** in [`collectionCommand.ts`](../../src/api/endpoints/collectionCommand.ts).

## Client flow

[`useCollectionCommandPalette`](../../src/hooks/useCollectionCommandPalette.hook.ts) + [`CollectionCommandPalette`](../../src/components/CollectionCommandPalette/CollectionCommandPalette.component.tsx) on [`ReleasesClient`](../../src/components/ReleasesClient/ReleasesClient.component.tsx). Desktop **[`FiltersBar`](../../src/components/StickyHeaderBar/FiltersBar.tsx)** embeds search in [`CollectionSearchCommandSegment`](../../src/components/StickyHeaderBar/CollectionSearchCommandSegment.component.tsx): bordered segment + sentence-case **`Ask`** chip ([`SparklesThinIcon`](../../src/styles/icons/SparklesThinIcon.component.tsx) + [`COLLECTION_COMMAND_CHIP_LABEL`](../../src/constants/collectionCommand.constants.ts)). Mobile (below the filters bar breakpoint) uses the same sparkles icon in [`MobileMenuHeader`](../../src/components/StickyHeaderBar/MobileMenuHeader.tsx) beside filter and random when the collection filters rail is available; both call [`openCollectionCommandPalette`](../../src/utils/collectionCommandPaletteBridge.ts) with aria from [`buildCollectionCommandOpenAriaLabel`](../../src/utils/buildCollectionCommandOpenTooltip.ts) and respect **`collectionCommandPaletteEnabled`**. Palette prompt row uses the same icon beside [`Command.Input`](../../src/components/CollectionCommandPalette/CollectionCommandPalette.component.tsx). Desktop chip tooltip via [`buildCollectionCommandOpenTooltip`](../../src/utils/buildCollectionCommandOpenTooltip.ts) (**`COLLECTION_COMMAND_OPEN_TOOLTIP_LEDE`** + **`formatShortcutChipAbbreviation`** shortcut); bridge registration lives in the palette hook. **Filter views** bar trigger drops the default **Views** label when no saved view is selected (icon + chevron only) to balance bar width. Recent prompts: **`localStorage`** per user ([`collectionCommandPromptHistory.ts`](../../src/utils/collectionCommandPromptHistory.ts)); cleared on **Clear stored data**.

**Panel list layout** — [`CollectionCommandPalette.module.css`](../../src/components/CollectionCommandPalette/CollectionCommandPalette.module.css) + [components.md → Collection command palette](../components.md#collection-command-palette). **`.command`** uses **`--command-inset: var(--space-4)`** on the prompt row and on full-width list rows (**`recentRow`**, **Run**, preview actions) at all breakpoints — square **`border-radius: 0`** on **`cmdk-item`** and row buttons so selection reads edge-to-edge; **`commandList`** has no shell padding (row insets carry spacing). Footer **`panelFooter`** / **`panelFooterAction`** stay compact (**`padding: 0`** on footer actions). Below **`768px`**, **`Command.Input`** is **`16px`** (iOS no-zoom — same rule as [`modal-input.module.css`](../../src/styles/modules/modal-input.module.css)); **`768px+`** may use **`var(--text-lg)`** on the input only.

After **Run**, the hook stores the interpreted prompt as **`previewSourcePrompt`**. Editing the command input (typing, picking **Recent**, paste) clears preview state when **`query.trim()`** no longer matches that source prompt so **Apply** / **Save view** cannot target a stale interpret. While a preview is open, **`sanitizeCollectionCommandIntent`** re-runs when **`facetOptions`** grow during collection pagination ([`persistedFiltersEqual`](../../src/utils/filtersStorage.ts) skips no-op updates). The command input placeholder is [**`COLLECTION_COMMAND_INPUT_PLACEHOLDER`**](../../src/constants/collectionCommand.constants.ts) (generic plain-English commands — not keyword search). It uses **`maxLength`** [**`COLLECTION_COMMAND_PROMPT_MAX_LENGTH`**](../../src/constants/collectionCommand.constants.ts) (same cap as the route body schema). Recent prompt rows load when the palette opens (**`useMemo`** on **`open`** / **`promptHistoryRevision`**), not on every keystroke. **Panel footer** (`fmdCollectionCommandPanelFooter`): **Start over** (`COLLECTION_COMMAND_START_OVER_LABEL`, **`fmdCollectionCommandStartOver`**, left, when the command input has text, a preview is open, or interpret failed) calls **`startOver`** (**`resetPaletteState`** — clears query + preview, keeps the palette open) and refocuses **`Command.Input`**. **Clear recent** (`COLLECTION_COMMAND_CLEAR_RECENT_LABEL`, native **`button`** + **`text-action.module.css`** **`subtlelink`**, left, only while browsing past commands — empty **`query`**, history exists, no preview / **Run** / action step) and **Report command issue** (right) share **`panelFooterAction`** typography (**`--text-sm`**). **Clear recent** calls **`clearCollectionCommandPromptHistory`** and swaps back to **Examples** (no visible section eyebrow). With no history, the list shows **Examples** from [**`buildCollectionCommandExamplePrompts`**](../../src/utils/collectionCommandExamplePrompts.ts) — three short differentiated sentences (refine / save view / create crate, or explore / save / crate when nothing is filtered), capped by [**`COLLECTION_COMMAND_EXAMPLE_PROMPT_MAX_LENGTH`**](../../src/constants/collectionCommand.constants.ts); **`useCollectionCommandPalette`** bumps **`exampleShuffleSeed`** on each open so [**`buildCollectionCommandExamplePrompts`**](../../src/utils/collectionCommandExamplePrompts.ts) reshuffles facet picks and phrasing variants; idle rows use [**`assignDistinctIdleStyleSlots`**](../../src/utils/collectionCommandExamplePrompts.ts) (shuffled styles, one genre per example when facets allow) — lead example **`Show me {styleA} AND {styleB} releases from {decade}`** when two styles and a decade are available (shorter single-style fallbacks when copy would exceed **`COLLECTION_COMMAND_EXAMPLE_PROMPT_MAX_LENGTH`**); session [`sessionFiltersAtom`](../../src/atoms/filters.atoms.ts) + facet options; **[`COLLECTION_COMMAND_EXAMPLE_PROMPTS_FALLBACK`**](../../src/constants/collectionCommand.constants.ts) when empty. Past/example rows use the same **`recentRow`** pattern; tap an **example** row to **`runInterpretForPrompt`** (fills the input and **Run**s). Past commands still fill the input only.

**Save view** from the palette uses [`saveViewFromFilters`](../../src/hooks/useFilterViews.hook.ts) (no **`SaveFilterViewDialog`**). Preview invalidation logic: [`shouldClearCollectionCommandPreview`](../../src/utils/collectionCommandPalettePreview.ts) (util spec in [`collectionCommandPalettePreview.spec.ts`](../../src/utils/collectionCommandPalettePreview.spec.ts)). Hook integration: **[`useCollectionCommandPalette.hook.spec.ts`](../../src/hooks/useCollectionCommandPalette.hook.spec.ts)** — **`runInterpret`** / **`runInterpretForPrompt`**, preview clear when the query changes, **`startOver`**, idle **`examplePrompts`**; example phrasing / **`shuffleSeed`** in **[`collectionCommandExamplePrompts.spec.ts`](../../src/utils/collectionCommandExamplePrompts.spec.ts)**. Component: **[`CollectionCommandPalette.spec.tsx`](../../src/components/CollectionCommandPalette/CollectionCommandPalette.spec.tsx)** — example row invokes **`runInterpretForPrompt`** via PO hook stub. Interpret failures log via **`logSanitizedApiRouteFailure`** in [`collection-command-interpret.server.ts`](../../src/lib/collection-command-interpret.server.ts) (catch path; route returns **502** per [`interpret-prompt/route.spec.ts`](../../src/app/api/collection/interpret-prompt/route.spec.ts)).

The palette **Report command issue** footer control → closes the palette and opens the shared [`SentryUserFeedbackDialog`](../../src/components/SentryUserFeedbackDialog/SentryUserFeedbackDialog.component.tsx) via [`openCollectionCommandSentryFeedback`](../../src/lib/sentry/openCollectionCommandSentryFeedback.client.ts) (always opens the dialog; **`submitSentryUserFeedback`** / [`deliverSentryClientCapture`](../../src/lib/sentry/deliverSentryClientCapture.client.ts) gate delivery and show an error toast when Sentry is disabled). Submissions tag **`feedback_source:collection_command`**. The dialog shows the current **prompt** (and optional interpret error / preview facts) as read-only context, requires a **radio** issue category ([`collectionCommandUserReportLabels.ts`](../../src/utils/collectionCommandUserReportLabels.ts)), and leaves **Details (optional)** as an empty freeform textarea. Submit composes the Sentry message with [`buildCollectionCommandSentryFeedbackMessage`](../../src/utils/buildCollectionCommandSentryFeedbackMessage.ts).
