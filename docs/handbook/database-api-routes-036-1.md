## API routes

| Route                                   | Methods            | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/api/crates`                           | GET, POST          | List/create crates for authenticated user; GET returns crates ordered **default first**, then **name ascending** (`releaseCount` and up to three `previewThumbs` per crate via [`fetchCratePreviewThumbs`](../../src/lib/crate-preview.server.ts) — ranked **`crate_releases`** rows capped per crate at **`CRATE_HUB_PREVIEW_ROW_LIMIT`**, not full-crate scans). Pass **`?all=true`** to return up to **`CRATE_LIST_ALL_MAX`** (500) crates in one page (used by the client crate list)                                                                                                                                                                               |
| `/api/crates/[id]`                      | GET, PATCH, DELETE | Single crate CRUD; can toggle `private`, update `username`; GET returns releases ordered by **`sort_order`** plus **`markers[]`**. Pass **`?all=true`** to return up to **`CRATE_DETAIL_ALL_MAX`** (10,000) releases in one page                                                                                                                                                                                                                                                  |
| `/api/crates/[id]/layout`               | PUT                | Atomically replace crate layout (release order + set markers); revalidates public **`/crate/[id]`** when the crate is public                                                                                                                                                                                                                                                                                                                                                      |
| `/api/crates/[id]/releases`             | GET, POST, PATCH   | List/add releases; bulk clear packed (`clear_found`); new releases prepend at min **`sort_order` − 1000`**. **POST** revalidates public **`/crate/[id]`** when the crate is public (**[`revalidatePublicCrateShareWhenPublic`](../../src/lib/public-share-cache.server.ts)**)                                                                                                                                                                                                                                                                  |
| `/api/crates/[id]/releases/[releaseId]` | PATCH, DELETE      | Mark packed / remove release from crate; **DELETE** revalidates public **`/crate/[id]`** when the crate is public                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `/api/crates/membership/[instanceId]`   | GET                | Crate ids containing a collection release (`instance_id`) for the authenticated user                                                                                                                                                                                                                                                                                                                                                                                              |
| `/api/crates/membership/[instanceId]`   | PUT                | Set crate membership for a release in one request (`{ crateIds, release }`); revalidates public shares for crates added or removed                                                                                                                                                                                                                                                                                                                                                 |
| `/api/crates/public/[id]`               | GET                | Public crate payload (no auth required when not private); releases ordered by **`sort_order`** only (no markers). Pass **`?all=true`** for a single full payload (up to **`CRATE_DETAIL_ALL_MAX`**)                                                                                                                                                                                                                                                                               |
