## Feature example: ReleaseCrateMenu

[`ReleaseCrateMenu`](../../src/components/ReleaseCard/ReleaseCrateMenu.component.tsx) is the shared multi-crate add/remove popover. Shared logic lives in [`useReleaseCrateMenuController.hook.ts`](../../src/hooks/useReleaseCrateMenuController.hook.ts) (**`panelContentProps`**, membership prefetch, checkbox handlers, **`CreateCrateDialog`** — **`closeCreateDialog`** for dismiss, **`handleOpenCreateDialog`** closes the root menu before create; **`handleCreateCrate`** **`try/catch`** so create failures keep the dialog open after **`useCreateCrateMutation`** **`onError`** toasts — see [patterns.md → Crates](patterns.md#crates)). Callers pass **`actionClass`** (and optional **`slotClass`**) so the trigger matches local chrome; optional **`triggerVariant`** (**`"card"`** default — card overlay button styles; **`"custom"`** — caller classes only) and **`triggerStyle`** (**`"icon"`** default; **`"text"`** — **"+ Add to Crate"** / **"− Remove from Crate"** label on the trigger, e.g. [`ReleaseListItem`](../../src/components/ReleaseListItem/ReleaseListItem.component.tsx)). Trigger sets **`aria-pressed`** when the release is in the **active** crate. Root **`Menu.Trigger`** **`render`** sets **`onClick={handleTriggerClick}`** only (**`preventDefault`** + **`stopPropagation`** — do not forward Base UI **`props.onClick`** or the same pointer sequence opens then toggles closed); **[`ReleaseMiniPlayerAddToMenuView`](../../src/components/ReleaseMiniPlayer/ReleaseMiniPlayerAddToMenuView.component.tsx)** follows the same rule as **[`ReleaseCrateMenu`](../../src/components/ReleaseCard/ReleaseCrateMenu.component.tsx)**. Desktop / horizontal triggers default **`portaled={false}`** (popup in **`.menuHost`**); **`layout="vertical"`** (mobile list card action column, similar-release rows) defaults **`portaled`** so the menu is not clipped by card **`overflow: hidden`**. **`ReleaseMiniPlayer`** uses **[`ReleaseMiniPlayerAddToMenu`](../../src/components/ReleaseMiniPlayer/ReleaseMiniPlayerAddToMenu.component.tsx)** instead — root **Add to** (**`fmdReleaseAddToMenu`**) with **Crates** / **Playlists** submenus (**[`ReleaseCrateMenuSubmenuTrigger`](../../src/components/ReleaseCard/ReleaseCrateMenuSubmenu.component.tsx)** + **`ReleaseCrateMenuSubmenuPanel`** → **`ReleaseCrateMenuPanelContent`** with **`showTopHeading={false}`**; **[`ReleasePlaylistPickerSubmenuTrigger`](../../src/components/ReleasePlaylistPickerDialog/ReleasePlaylistPickerDialog.component.tsx)** with **`submenuLabel="Playlists"`** + **`ReleasePlaylistPickerSubmenuPanel`** for the **currently playing** track; **[`useReleasePlaylistPickerController`](../../src/hooks/useReleasePlaylistPickerController.hook.ts)** → **`submenuPanelProps`** + sibling **`CreatePlaylistDialog`** from **`createDialogProps`**). Nested submenu panels default **`useOverlayStack={false}`** (root **Add to** menu owns **`OverlayStack`**). **[`ReleaseCrateMenuSubmenuTrigger`](../../src/components/ReleaseCard/ReleaseCrateMenuSubmenu.component.tsx)** and **[`ReleasePlaylistPickerSubmenuTrigger`](../../src/components/ReleasePlaylistPickerDialog/ReleasePlaylistPickerDialog.component.tsx)** omit **`openOnHover`** unless a caller passes it (**`definedProps`**) — Base UI defaults to **`true`** (**`mouseOnly`**) so **Crates** / **Playlists** open on hover in the browser; tap/keyboard still open on touch. When the playlists flag is on, **[`ReleaseMiniPlayerAddToMenuWithPlaylist`](../../src/components/ReleaseMiniPlayer/ReleaseMiniPlayerAddToMenuWithPlaylist.component.tsx)** wraps the same view + playlist picker; optional **`submenuOpenOnHover`** on **[`ReleaseMiniPlayer`](../../src/components/ReleaseMiniPlayer/ReleaseMiniPlayer.component.tsx)** / **[`ReleaseMiniPlayerAddToMenu`](../../src/components/ReleaseMiniPlayer/ReleaseMiniPlayerAddToMenu.component.tsx)** forwards to **[`ReleaseMiniPlayerAddToMenuView`](../../src/components/ReleaseMiniPlayer/ReleaseMiniPlayerAddToMenuView.component.tsx)** and both submenu triggers (JSDOM crate tests use **`ReleaseMiniPlayer.po.tsx`** **`createWrapper(undefined, { submenuOpenOnHover: false })`** — see [conventions.md → Testing → Playlist picker / selector specs](conventions.md#testing)). See [patterns.md → Playlists](patterns.md#playlists).
