- **Release modal & playback**: Dashboard release rows (On this day, milestones, most crated, duplicate list items) and **On repeat** track rows (cover + title on [`DashboardTrackItem`](../../src/components/Dashboard/DashboardTrackItem.component.tsx)) open **[`ReleaseModal`](../../src/components/ReleaseModal/ReleaseModal.component.tsx)** via **`useLocalSelectedReleaseModal({ collectionUsername, fallbackReleases })`** + **`ReleaseModalLazyOverlay`** + **`useRegisterPlaybackReleaseClick`** (local state only — **no** **`?instance=`** updates; avoids **`useSearchParams`** suspending [`dashboard/page.tsx`](../../src/app/dashboard/page.tsx) during **`router.push`** and flashing chart content above the modal). **`DashboardClient`** relies on row hover **`prefetchReleaseOpenData`** for release-detail query warm. **[`/collection`](../../src/app/collection/page.tsx)** and owner crate detail still use **`useSelectedReleaseModal`** for URL-backed modal history. **[`/mosaic`](../../src/app/mosaic/page.tsx)** uses the same local hook. Owner crate detail passes crate-scoped **`fallbackReleases`**; mosaic passes **`useSortedFilteredReleases()`**; public crates use **`PublicReleaseModal`** with **`usePublicSelectedReleaseModal`** (crate payload + **`/api/release/[id]`** query — not collection IndexedDB). URL-backed pages sync modal state to **`?instance=`** — **`useSelectedReleaseModal`** keeps the overlay mounted until the param clears; **`optimisticId ?? urlInstanceId`** resolves the open release while the router is catching up (see [components.md](components.md) → ReleaseModal). **[`CollectionPlaybackPageShell`](../../src/components/PlaybackPageShell/CollectionPlaybackPageShell.component.tsx)** owns scroll layout; **[`GlobalPlaybackDock`](../../src/components/GlobalPlaybackDock/GlobalPlaybackDock.component.tsx)** (authenticated shell only) portals the mini player to **`document.body`** so playback survives client navigations between collection routes; **[`CollectionPlaybackPageShell`](../../src/components/PlaybackPageShell/CollectionPlaybackPageShell.component.tsx)** reserves space with **`[data-playback-dock-spacer]`** — not an in-flow dock. Signed-in visitors on public pages (e.g. **`/crate/[id]`**) get the same dock plus **[`PlaybackScrollSpacer`](../../src/components/PlaybackScrollSpacer/PlaybackScrollSpacer.component.tsx)** in document flow. **[`CollectionHealth`](../../src/components/Dashboard/CollectionHealth.component.tsx)** tiles are **`<fieldset aria-label="…">`** health cards (same borderless fieldset reset as hero metrics). **Show details** opens **[`DuplicatesDetailModal`](../../src/components/Dashboard/DuplicatesDetailModal.component.tsx)** (**[`ScrollModal`](../../src/components/ScrollModal/ScrollModal.component.tsx)** + **[`ModalToolbar`](../../src/components/ModalToolbar/ModalToolbar.component.tsx)** with **`title`** in the toolbar and description below) instead of expanding inline.
- **Data**: **`useAllReleases()`** from Jotai + **`useCollectionAnalytics`** for computed stats; **`useCollectionValueQuery`** for Discogs collection dollar value; **TanStack Charts** for dashboard charts. Rolling-window insights (**collection recap**, **acquisition streaks** — busiest/quietest quarter, busiest day/month, longest dry spell) live in [`collectionRhythm.ts`](../../src/utils/collectionRhythm.ts) and render via [`CollectionRhythm`](../../src/components/Dashboard/CollectionRhythm.component.tsx) in the **How it grew** section — **`useScrollRevealInView`** triggers compare/drift bar width transitions (**`ScrollRevealBar`**, **`--bar-width`**, staggered **`--bar-delay`**) and per-digit **ticker** stats via **`TickerNumber`** when the rhythm block enters view. **Collection recap** recomputes from **`useAllReleases()`** inside **`CollectionRhythm`** with a **Time frame** **`Select`** (last week / month / quarter / year presets); each preset compares the recent window to the immediately prior window of equal length.
