**User lookup** — **[`AdminUserLookupPanel`](../../src/components/AdminDashboard/AdminUserLookupPanel.component.tsx)** wraps the form and results in its module **`.panel`** card. The username field uses **React Hook Form** + **`adminUserLookupFormSchema`** ([`adminUserLookup.schemas.ts`](../../src/lib/validation/adminUserLookup.schemas.ts)). Submit loads per-account stats via **`fetchAdminUserLookup`** → **`GET /api/admin/users/[username]`** → **`useAdminUserLookupQuery`** ([`getAdminUserLookup`](../../src/lib/admin-user-lookup.server.ts)): signup/update timestamps, **`lastSeenAt`**, **`loginCount`**, **`contact`** (**`email`**, **`marketingEmailsOptIn`**, **`welcomeEmailSent`**), parsed preferences (including **`defaultCollectionSidePanel`**, playback toggles, and **`savedViewsCount`**), crate/release/playlist totals, recent activity (including last playlist update), **`playback`** totals (track rows, plays, listens, overrides, last play/listen), up to 25 crates sorted by last update, and up to 25 playlists (visibility, track count, public views/plays). The per-user crates and playlists lists use the multi-column table in **`AdminUserLookupPanel.module.css`** — not **[`AdminMetricTable`](../../src/components/AdminDashboard/AdminMetricTable.component.tsx)** (that component is two-column leaderboards only).
