## `next.config.ts` highlights

- **Images**: **`localPatterns`** for **`/api/image-proxy`** (query strings — mosaic canvas) plus **`/**`** without search (public assets); remote patterns for **`i.discogs.com`**, **`img.discogs.com`** (collection **`cover_image`**), **`i.ytimg.com`** (**`/vi/**`** — YouTube override dialog previews), and placeholders. Collection grid cards use direct CDN **`next/image`** URLs (not per-tile proxy). Header avatars use plain **`<img>`** via the proxy (see [conventions.md](conventions.md)).
- **`serverExternalPackages: ["sharp"]`**: keeps the image-proxy native module out of the bundler so Vercel can include **`@img/sharp-linux-*`** binaries.
- **Security headers**: CSP (tighter in production), HSTS, frame options, etc. on `/`, `/api/*`, and static paths. Production CSP restricts **`connect-src`**, **`frame-src`**, and **`img-src`**; development keeps broader directives for local debugging. Production **`script-src`** omits **`'unsafe-eval'`**. [`configureBrowserZod`](../../src/lib/validation/configureBrowserZod.client.ts) sets Zod **`jitless`** in the browser so schema compilation never calls **`Function("")`** (the JIT probe Firefox logs as a CSP eval violation). Server parses keep JIT. **`connect-src`** includes **`*.ingest.sentry.io`** / regional **`*.ingest.{us,eu}.sentry.io`** as a fallback if the browser SDK ever posts outside the **`/monitoring`** tunnel; primary client ingest stays **`'self'`** via [`buildBrowserSentryInitOptions`](../../src/lib/sentry/sentryInitOptions.ts). Production **`worker-src`** includes **`blob:`** for Sentry Session Replay ([`sentryReplay.client.ts`](../../src/lib/sentry/sentryReplay.client.ts)). **`img-src`** includes **`https://i.ytimg.com`** for YouTube thumbnail previews in **`TrackYoutubeOverrideDialog`**. Playback embeds use **`youtube-nocookie.com`** — both **`*.youtube.com`** and **`*.youtube-nocookie.com`** must stay in **`frame-src`** / **`child-src`**. Landing **`LoginPreviewDemo`** (**`youtube-video-element`**) loads **`youtube.com/iframe_api`** on the page — keep **`*.youtube.com`** in **`script-src`** and **`connect-src`** (see [`next.config.ts`](../../next.config.ts)). Vercel preview **`script-src`** and **`frame-src`** also allow **`vercel.live`** for the Live feedback widget (iframe).
- **`productionBrowserSourceMaps`**: enabled only when **`SENTRY_AUTH_TOKEN`** is set (Turbopack emits **`.map`** files for Sentry upload); **`withSentryConfig`** sets **`sourcemaps.deleteSourcemapsAfterUpload: true`** so maps are not left in the deployed bundle.
- **`transpilePackages`**: **`@faker-js/faker`** (ESM-only), **`@tanstack/react-table`** / **`@tanstack/table-core`**, and **`@tanstack/charts`** (ESM dashboard charts — scales and React adapter via **`@tanstack/charts/scales/*`**, **`@tanstack/charts/react/*`** subpaths), plus **`d3-shape`** for pie layouts, and **`msw`** / **`@msw/url`** (MSW 3) / **`@mswjs/interceptors`** / **`rettime`** / **`until-async`** / **`@open-draft/deferred-promise`** / **`@open-draft/until`** for Jest endpoint mocking — required so Next/Jest can transpile them.
- **PostCSS**: [`postcss.config.cjs`](../../postcss.config.cjs) (not `.js`) — Turbopack 16.3 treats `postcss.config.js` as an async module and can fail with `__turbopack_context__.a is not a function` on large CSS builds; `.cjs` avoids the broken loader path.
- **SVGR**: [`turbopack.rules`](../../next.config.ts) for SVG-as-React components in dev/build (Turbopack is the default; no **`webpack()`** hook). Type declarations for `*.svg` imports live in root [`cssprops.d.ts`](../../cssprops.d.ts) (included by [`tsconfig.json`](../../tsconfig.json)).
- **`experimental.optimizePackageImports`**: tree-shaking for TanStack (**`@tanstack/charts`** on dashboard) and **`@dnd-kit/*`**.
- **Cache Components** (`cacheComponents: true`): enables Partial Prerendering (PPR) and the `"use cache"` directive. Required for Instant Navigations prefetching.
- **Partial Prefetching** (`partialPrefetching: true`): prefetches only the static shell for linked routes so navigations can feel instant before dynamic data resolves.
- **TypeScript**: **`typescript@^7`** with Next.js 16.3+ (native TS 7 support in `next build`). TS 7 is a Go-native **`tsc`** — the npm package no longer ships **`lib/tsserver.js`**, so editors cannot use workspace **`node_modules/typescript/lib`** for the language service and fall back to a bundled TS 6 with a warning. **`pnpm tsc:ci`** / CI still use TS 7. For IDE type-checking that matches the repo, the devDependency **`typescript-langservice`** (pnpm alias to **`typescript@6.0.3`**) ships a TS 6 **`tsserver.js`** — do not point editors at workspace **`typescript`** (**TS 7** has no **`tsserver.js`**). **Zed** (team editor): [`.zed/settings.json`](../../.zed/settings.json) points **`vtsls`** at **`typescript-langservice/lib`**, disables **`typescript-language-server`**, and sets CSS **`customData`** for [`css-modules-custom-data.json`](../../src/styles/css-modules-custom-data.json). Reload the window after **`pnpm install`**. Confirm in **LSP → vtsls** logs: **`Using tsserver from: …/typescript-langservice/lib/tsserver.js`**. Optional **Cursor / VS Code** (agents): [`.vscode/settings.json`](../../.vscode/settings.json). Until editors ship native TS 7 LSP support, that split (TS 7 build + TS 6 editor) is expected; a one-time “workspace TS 7 has no tsserver” fallback warning can still appear until **vtsls** picks up the configured tsdk.
