## StickyHeaderBar mobile menu

Authenticated **[`StickyHeaderBar`](../../src/components/StickyHeaderBar/StickyHeaderBar.component.tsx)** below **`1024px`**: **[`MobileMenu`](../../src/components/StickyHeaderBar/MobileMenu.tsx)** (**[`MobileMenuHeader`](../../src/components/StickyHeaderBar/MobileMenuHeader.tsx)** — optional filters/random + hamburger) opens a chrome **[`BottomDrawer`](../../src/components/BottomDrawer/BottomDrawer.component.tsx)** (`aboveMiniPlayer` when the dock is visible). **Main routes:** **[`MobileMenuNav`](../../src/components/StickyHeaderBar/MobileMenuNav.tsx)** renders **[`MobileMenuNavLink`](../../src/components/StickyHeaderBar/MobileMenuNavLink.component.tsx)** rows (thin icon + label, **`aria-current="page"`** when active). **Shared nav config:** **[`mobileMainNavItems.ts`](../../src/components/StickyHeaderBar/mobileMainNavItems.ts)** — **`MOBILE_MAIN_NAV_ITEMS`**, **`MOBILE_MAIN_NAV_VISIBILITY`**, **`getVisibleMobileMainNavItems`** — also drives desktop **[`PageNavigation`](../../src/components/StickyHeaderBar/PageNavigation.tsx)** (`IconButtonLink` at **`1024px+`**). **Account footer:** **[`MobileMenuDrawerFooter`](../../src/components/StickyHeaderBar/MobileMenuDrawerFooter.tsx)** + **[`MobileMenuDrawerFooter.module.css`](../../src/components/StickyHeaderBar/MobileMenuDrawerFooter.module.css)** — one **[`SegmentedControl`](../../src/components/SegmentedControl/SegmentedControl.component.tsx)** (**Settings** | **More** | **Logout**, crate-drawer-style **`footerSegment`** classes). **[`MobileMenuFooterMoreMenu`](../../src/components/StickyHeaderBar/MobileMenuFooterMoreMenu.component.tsx)** is a thin wrapper on **[`DrawerFooterMoreMenu`](../../src/components/DrawerFooterMoreMenu/DrawerFooterMoreMenu.component.tsx)** (About + Donate via **[`SupportProjectNavLink`](../../src/components/SupportProjectNavLink/SupportProjectNavLink.component.tsx)**). Parent passes a single **`onNavigate`** to close the menu drawer after any account link. **[`MobileMenu`](../../src/components/StickyHeaderBar/MobileMenu.tsx)** wires **[`useListenBottomDrawerDismiss`](../../src/hooks/useListenBottomDrawerDismiss.hook.ts)** with the filters drawer (playback dock release tap — see [patterns.md → Crates](patterns.md)). Desktop account links stay in **[`UserActions`](../../src/components/StickyHeaderBar/UserActions.tsx)** — [patterns.md → Settings](patterns.md#settings).
