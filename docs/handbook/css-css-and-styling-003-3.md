- **Mobile filter controls** ([`SearchBar`](../../src/components/SearchBar/SearchBar.module.css), [`Select`](../../src/components/Select/Select.module.css), [`AutocompleteSelect`](../../src/components/AutocompleteSelect/AutocompleteSelect.module.css)): below **`768px`**, align tap targets with **`min-height: var(--touch-target-min)`**, **`1rem`** type, and **`var(--space-3) var(--space-4)`** padding; at **`768px+`** use fixed **`height: var(--input-height)`** (with matching **`min-height`** / **`max-height`**) and compact padding so search, select, and multi-select triggers stay one row tall — including pill **`triggerShell`** rows in **`FiltersBar`**. Portaled dropdown **`.option`** rows use **`min-height: calc(var(--touch-target-min) + var(--space-3))`** and **`var(--space-4)`** padding below **`1024px`** (including mobile **`FiltersDrawer`**); compact rows at **`1024px+`** when desktop **`FiltersBar`** is shown. **[`Select`](../../src/components/Select/Select.component.tsx)** uses **Base UI** [`@base-ui/react/select`](https://base-ui.com/react/components/select) (`Select.Root` / `Trigger` / `Portal` / `Positioner` / `Popup` / `List` / `Item`) with existing CSS Modules; trigger role is **`combobox`** (not **`button`**). **[`AutocompleteSelect`](../../src/components/AutocompleteSelect/AutocompleteSelect.component.tsx)** uses **Base UI** [`@base-ui/react/combobox`](https://base-ui.com/react/components/combobox) with the **input inside popup** pattern (`Combobox.Input` in `Popup` for search). Single-select: full **`Combobox.Trigger`** shows the value + chevron. Multi-select: **`Combobox.Trigger`** with **`nativeButton={false}`** and **`render={<div />}`** wraps the full **`triggerShell`** (pills + chevron) so the pill row is part of the combobox reference for outside-dismiss and single-click open/toggle. Do not nest **`Combobox.Chips`** inside the same trigger — **`Chips`** **`handleInputPress`** opens on **`mousedown`** and races the trigger toggle (double-click to open). Pills use **`pointer-events: none`** on descendants except **`.pillsContainer`** (horizontal chip scroll) and **`.pillClear`**. Placeholder or selection pills live in **`.valueContainer`**; chevron in **`.icon`**. Never nest remove buttons inside a native **`<button>`** trigger. Both filter controls share [`getFilterControlledValue`](../../src/utils/filterControlValue.ts) / [`applyFilterValueChange`](../../src/utils/filterControlValue.ts) and **[`OverlayStack`](../../src/components/OverlayStack/OverlayStack.component.tsx)** / **`usePortaledOverlayContainer`** so **`Select`**, **`AutocompleteSelect`**, and **`FilterViewsMenu`** portal popups into the nearest stack — **[`FiltersBar`](../../src/components/StickyHeaderBar/FiltersBar.tsx)** and **[`BottomDrawer`](../../src/components/BottomDrawer/BottomDrawer.component.tsx)** both set **`escapeStackingContext`** so dropdowns mount on **`document.body`** above **`GlobalPlaybackDock`** (drawer shell **`transform`** / page-shell stacking would otherwise trap in-tree popups); **[`AppDialog`](../../src/components/AppDialog/AppDialog.component.tsx)** keeps in-tree portals. **`FiltersBar`** **`OverlayStack`** passes **`popoverZIndex="calc(var(--z-9-playback-dock) + 1)"`**. Selected pills wrap in **`HorizontalScrollRow`** (**`.pillsContainer`**, **`data-testid="fmdFilterPillsScroll"`**) for horizontal scroll with hidden scrollbars and an end fade (same component as release-card pills; vertical wheel maps to horizontal scroll; **`.pillsContainer`** uses **`touch-action: pan-x`**). **`controlRow`** wraps the trigger whenever **`clearable`** is set (Clear button mounts inside the row only after selections exist; do not wrap/unwrapping the trigger).
