## Production deploy notifications

[`DeploymentUpdateToast`](../../src/components/DeploymentUpdateToast/DeploymentUpdateToast.component.tsx) mounts in global **`Providers`**, uses **[`useBuildVersionQuery`](../../src/hooks/queries/useBuildVersionQuery.ts)** with **[`deploymentBuildVersionPolling`](../../src/utils/deploymentBuildVersionPolling.ts)** (**one minute** while the tab is visible; paused when hidden), **`refetchOnWindowFocus`**, **`refetchOnReconnect`**, and **`useDeploymentBuildVersionEagerRefetch`** (`visibilitychange` when visible, **`pageshow`** after bfcache). Shows a toast via [`src/utils/toast.ts`](../../src/utils/toast.ts) when the live version differs from **`NEXT_PUBLIC_APP_BUILD_VERSION`**. Polling disables after the toast fires once. Production only; local dev and Preview skip the query via **`enabled`**. Version strings come from **`VERCEL_GIT_COMMIT_SHA`** (preferred) or **`VERCEL_DEPLOYMENT_ID`**, exposed in [`next.config.ts`](../../next.config.ts).
