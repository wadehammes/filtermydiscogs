- Dynamic OG routes: [`src/app/api/og/crate/[id]/route.tsx`](../../src/app/api/og/crate/[id]/route.tsx) and [`src/app/api/og/playlist/[id]/route.tsx`](../../src/app/api/og/playlist/[id]/route.tsx) for public shares — both use [`PublicShareOgImage`](../../src/lib/og/publicShareOgImage.tsx) via [`createPublicShareOgImageResponse`](../../src/lib/og/createPublicShareOgImageResponse.server.tsx) (**2×2** cover collage from the first **`PLAYLIST_HERO_MOSAIC_MAX_TILES`** release thumbs via **`getPublicCrateForOg`** / **`fetchPublicCrateCoverThumbUrls`** or **`getPublicPlaylistForOg`**, then a black right panel; text-only fallback is that same panel when no art). The panel is **DM Sans**: a **`Playlist`** or **`Crate`** label beside **`SITE_DOMAIN_LABEL`** (**`FilterMyDisco.gs`**), title, optional **`by {username}`**, and meta chips for the count (**`N tracks`** / **`N releases`**) and **`Updated {formatDate}`** ([`buildPublicShareOgCountLabel`](../../src/lib/og/publicShareOgImage.tsx) / [`buildPublicShareOgUpdatedLabel`](../../src/lib/og/publicShareOgImage.tsx)). Satori does not use **`next/font`**, so the response passes the vendored Regular/Bold TTFs from [`loadDmSansOgFonts`](../../src/lib/og/loadDmSansOgFonts.server.ts) ([`src/lib/og/fonts/`](../../src/lib/og/fonts/)). Satori rejects a **`<div>`** that wraps an element (the cover **`<img>`**) unless that div sets **`display: flex`** — collage cells include it, or **`ImageResponse`** throws while the body is piped and the route returns **500** ([JAVASCRIPT-NEXTJS-10](https://filtermydiscogs.sentry.io/issues/JAVASCRIPT-NEXTJS-10)).
- **Sitemap**: [`src/app/sitemap.ts`](../../src/app/sitemap.ts) lists `/`, `/about`, `/legal`, plus recent public **`/crate/[id]`** and **`/playlist/[id]`** URLs from **`getPublicCrateIdsForStaticGeneration`** / **`getPublicPlaylistIdsForStaticGeneration`** (build placeholder playlist id excluded).
- **Robots**: [`src/app/robots.ts`](../../src/app/robots.ts) allows `/` and explicitly **`/api/og/`** (so crawlers can fetch dynamic Open Graph images for **`/crate/[id]`** / **`/playlist/[id]`**), disallows `/admin` and the rest of `/api/`, and references the sitemap URL from **`getMetadataSiteUrl()`**.
- **Canonical URL**: **`DEFAULT_SITE_URL`** and sitemap entries use **`https://www.filtermydisco.gs`**. Apex → `www` redirect is handled by **Vercel domain settings**, not app code.
- **Home JSON-LD**: [`HomeJsonLd`](../../src/components/Login/HomeJsonLd.component.tsx) on [`page.tsx`](../../src/app/page.tsx).

Do not add a dynamic `opengraph-image.tsx` alongside the PNG; the code route overrides the static file and replaces the app preview art.
