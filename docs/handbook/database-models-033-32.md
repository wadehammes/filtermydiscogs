Client writes via **`POST /api/tracks/record`** (`event`: **`play`** \| **`listen`**) and **`PATCH /api/tracks/youtube`** (explicit embed override — upserts row metadata + **`youtube_id`** without incrementing counters; send **`youtube_id: null`** to clear an override; Zod in [`userTrack.schemas.ts`](../../src/lib/validation/userTrack.schemas.ts)); reads via **`GET /api/tracks/stats?keys=`** (comma-separated **`track_key`** list, max 100; each row includes **`play_count`**, **`listen_count`**, **`youtube_id`**) — release modal via **`useTrackStatsQuery`** in [`useReleaseModalPlayback.hook.ts`](../../src/components/ReleaseModal/useReleaseModalPlayback.hook.ts); global queue embed resolution via **`usePlaybackTrackYoutubeOverrides`** (stats keys = **upcoming queue** rows plus the **currently playing** track — the active row is not stored in **`session.queue`**) + [`useTrackStatsQuery`](../../src/hooks/queries/useTrackStatsQuery.ts). Override saves use **`useSaveTrackYoutubeOverrideMutation`** ([`useTrackStatsMutations.ts`](../../src/hooks/mutations/useTrackStatsMutations.ts)) with **`meta.invalidates`** → **`TrackStatsQueryKeys`**. Dashboard leaderboards: **`GET /api/dashboard/top-tracks?limit=`** ( **`fetchTopUserTracks`** in [`user-track.server.ts`](../../src/lib/user-track.server.ts) — parallel **`play_count`** / **`listen_count`** queries; each row includes optional **`release_thumb`** from a single batched **`crate_releases`** lookup for all distinct **`instance_id`** values on both leaderboards). Admin platform playback aggregates: [`fetchAdminUserTrackStats`](../../src/lib/admin-user-track-stats.server.ts) (see [patterns.md → Admin dashboard](patterns.md#admin-dashboard)). UI may still prefer live collection art via **`useAllReleases()`**. Playback wiring: [`userTrackRecording.ts`](../../src/utils/userTrackRecording.ts) + [`TrackStatsRecorder`](../../src/components/TrackStatsRecorder/TrackStatsRecorder.component.tsx) (binds **`useRecordTrackEventMutation`**). Constants **`TRACK_LISTEN_MIN_MS`** (30_000) and **`USER_TRACK_STATS_KEYS_MAX`** (100) in [`userTrack.ts`](../../src/utils/userTrack.ts); client requests cap via **`normalizeTrackStatsKeys`** (optional **`prioritizeKeys`** when capping) in [`useTrackStatsQuery`](../../src/hooks/queries/useTrackStatsQuery.ts). Cache helpers: [`trackStatsQueryCache.ts`](../../src/utils/trackStatsQueryCache.ts). Rows delete with **Clear stored data** (**`User`** cascade). Override-only upserts (no prior play/listen) are covered by [`user-track.server.spec.ts`](../../src/lib/user-track.server.spec.ts) and [`src/app/api/tracks/youtube/route.spec.ts`](../../src/app/api/tracks/youtube/route.spec.ts); modal **`track_key`** wiring by [`useReleaseModalPlayback.hook.spec.tsx`](../../src/components/ReleaseModal/useReleaseModalPlayback.hook.spec.tsx).

### Playlists

**Status:** **`Playlist`** / **`PlaylistTrack`** in schema; **`/api/playlists`** CRUD + track routes (404 when Vercel flag **`playlists`** is off — [platform.md → Feature flags](platform.md#feature-flags-vercel)); **`api.*`** + React Query hooks; **Release track row menu** “Add to playlist”; **[`PlaylistDrawer`](../../src/components/PlaylistDrawer/PlaylistDrawer.component.tsx)** on **`/collection`** (paired with **`CrateDrawer`** via **[`CollectionSidePanelToggle`](../../src/components/CollectionSidePanelToggle/CollectionSidePanelToggle.component.tsx)**) — create/select playlists, DnD reorder, remove tracks, delete playlist, play. No dedicated **`/playlists`** App Router pages for now (may return later). Optional later: **`PlaybackQueueDrawer`** “Save queue as playlist”; rename playlist in drawer; hub/detail pages.

**Goal:** Saved **track lists** distinct from **crates** (release-level) and the **session playback queue** (in-memory + **`localStorage`**). Identity matches playback everywhere: **`track_key`** = `` `${instance_id}:${track_position}` `` ([`userTrack.ts`](../../src/utils/userTrack.ts), [`PlaybackQueueItem`](../../src/types/playbackQueue.types.ts)).

**Canonical track row:** existing **`UserTrack`** ([`user_tracks`](../../prisma/schema.prisma)) — metadata (**`instance_id`**, **`track_position`**, **`track_title`**, **`artist`**, **`release_title`**, **`youtube_id`**) plus **`play_count`** / **`listen_count`**. Do **not** add a parallel **`tracks`** table. **`PlaylistTrack`** FKs **`(user_id, track_key)` → `UserTrack`**.

**Before adding to a playlist:** upsert **`UserTrack`** with metadata and **`play_count` / `listen_count` = 0** when the row does not exist yet — same pattern as [`saveUserTrackYoutubeOverride`](../../src/lib/user-track.server.ts) (playlist add can reuse that helper or a thin **`ensureUserTrackMetadata`** wrapper with the same Zod metadata fields).

**`Playlist`** — user-owned named list (same scoping pattern as **`Crate`**: composite **`@@id([user_id, id])`**, UUID **`id`**, **`name`**, timestamps, optional **`username`** on public shares). When **`private: false`**, **`public_view_count`** and **`public_play_count`** track anonymous and signed-in visitor engagement on **`/playlist/[id]`** (owner views/plays are excluded — [`playlist-engagement.server.ts`](../../src/lib/playlist-engagement.server.ts)).

**`PlaylistTrack`** — junction only (no duplicated track columns):

| Field                                 | Notes                                                                      |
| ------------------------------------- | -------------------------------------------------------------------------- |
| `user_id`, `playlist_id`, `track_key` | Composite PK; **`track_key`** FK → **`UserTrack`** **`ON DELETE CASCADE`** |
| `sort_order`                          | Order within the playlist (DnD in **`PlaylistDrawerTracks`**)              |
