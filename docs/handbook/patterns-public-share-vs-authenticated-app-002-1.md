## Public share vs authenticated app

Keep these boundaries strict so pathname, Suspense, and playback do not entangle.

| Concern | Authenticated app (`/collection`, `/crates/…`, …) | Public share (`/playlist/[id]`, `/crate/[id]`, `/release/[id]`) | Marketing (home, about, legal) |
| ------- | ----------------------------------------------- | --------------------------------------------------------------- | ------------------------------ |
| **Who mounts playback** | **[`AuthenticatedProvidersGate`](../../src/components/AuthenticatedProvidersGate.component.tsx)** → dynamic **`AuthenticatedProviders`** when signed in (any route) or auth checking on a protected route | Logged out: **[`PublicSharePlaybackShell`](../../src/components/PublicSharePlaybackShell/PublicSharePlaybackShell.component.tsx)** on the page client (always mounts **`PlaybackProvidersShell`** when no outer provider — public share hooks call **`useReleasePlayback`** immediately). Signed in: gate shell only — **`PublicSharePlaybackShell`** passes children through when a provider already exists | None (unless a page opts in) |
| **Route helpers** | [`isProtectedAppRoute`](../../src/constants/protectedRoutes.ts) | [`isPublicShareRoute`](../../src/constants/protectedRoutes.ts) (public crate, playlist, or **`/release/[id]`** listen page — see [`isPublicReleaseRoute`](../../src/constants/protectedRoutes.ts)) | Neither protected nor share |
| **Pathname hook** | [`useAuthenticatedGatePathname`](../../src/hooks/useAuthenticatedGatePathname.hook.ts) — **gate only**; do not use in public page components | Same router pathname as everywhere else; no gate pathname hook on the page | — |
| **Provider implementation** | Same **[`ReleasePlaybackProvider`](../../src/context/ReleasePlaybackProvider.component.tsx)** / **[`PlaybackProvidersShell`](../../src/components/PlaybackProvidersShell.component.tsx)**; collection, prefs, and similar-queue features stay disabled when logged out | Same provider stack via **`PublicSharePlaybackShell`** → **`PlaybackProvidersShell`** when logged out (does **not** defer on **`isCheckingAuth`** — playlist/crate playback hooks require the provider on first paint). Authenticated routes that nest share UI under the gate use **`EnsurePlaybackProvidersShell`** elsewhere to avoid double shells / **`BrowserOnly`** churn | — |

**Do not** mount **`PlaybackProvidersShell`** from the gate for **logged-out** public or marketing routes (use **`PublicSharePlaybackShell`** on share pages). **Do not** add public-only playback forks unless a future **`scope: "public"`** mode in the provider is explicitly designed and tested.

**`AppToaster`** (Base UI **Toast**) and **`DonationSuccessToast`** are siblings under **ThemeProvider**, outside the auth subtree (**`DonationSuccessToast`** reads the **`?donation=success`** query after Stripe checkout). Toast styling follows the active palette via CSS variables in [`AppToaster.module.css`](../../src/components/AppToaster/AppToaster.module.css); call **`toast.success`**, **`toast.error`**, **`toast.loading`**, etc. from [`src/utils/toast.ts`](../../src/utils/toast.ts) instead of **`alert()`** for operational feedback (crate sync, logout/clear-data failures, clipboard copy, large-collection pagination progress, mutation errors in **`useCrateMutations`**, production deploy nudges from **`DeploymentUpdateToast`**, and Discogs outages from **`DiscogsOutageToast`**). **Discogs outage toast:** [`discogsOutageToast.tsx`](../../src/components/DiscogsOutageToast/discogsOutageToast.tsx) (**`showDiscogsOutageToast`** / **`dismissDiscogsOutageToast`**, id **`discogs-outage`**) uses [`showPersistentQueueAreaErrorToast`](../../src/utils/playbackQueueToast.ts) (same queue-area positioning and persistent **`toast.error`** pattern as playback skip toasts) with a **`DiscogsExternalLink variant="text"`** to **`https://status.discogs.com`** in the description. [`DiscogsOutageToast`](../../src/components/DiscogsOutageToast/DiscogsOutageToast.component.tsx) is the **only** caller of **`showDiscogsOutageToast`**: it shows while auth **`discogsUnavailable`** or collection context **`discogsUpstreamOutage`** is true and dismisses only when both clear (not on initial mount). [`useCollectionData`](../../src/hooks/useCollectionData.hook.ts) sets **`discogsUpstreamOutage`** when collection pagination exhausts retries on **502** ([`isDiscogsUpstreamOutageApiError`](../../src/api/apiFetchError.ts)); it clears the flag on successful fetch or when the hook disables. Trigger from our own **502** signal, not the status page — Discogs' Instatus page has no API component. **`AnalyticsShell`** also mounts **`CookieConsentBanner`**, GTM loaders, and **`UserPreferencesSync`**.

**Jotai** backs **filters** and **view** preference state. Atoms and derived selectors live under [`src/atoms/`](../../src/atoms/); [`src/context/filters.context.tsx`](../../src/context/filters.context.tsx) and [`view.context.tsx`](../../src/context/view.context.tsx) expose scope markers and legacy **`useFilters()`** / **`useView()`** for tests and context modules only. App code reads and writes through [`useFilterAtoms.hook.ts`](../../src/hooks/useFilterAtoms.hook.ts) and [`useViewAtoms.hook.ts`](../../src/hooks/useViewAtoms.hook.ts) (for example **`useSelectedStyles()`**, **`useFacetOptions()`**, **`useFilteredReleases()`**, **`useSortedFilteredReleases()`**, **`useCurrentView()`**). Import **`FiltersActionTypes`** and **`SortValues`** from [`filters.atoms.ts`](../../src/atoms/filters.atoms.ts) or [`sortValues.ts`](../../src/constants/sortValues.ts) in new code — not from **`filters.context`** re-exports when avoiding import cycles (see [Large context providers](#large-context-providers-playback-crates-notes-editor)).
