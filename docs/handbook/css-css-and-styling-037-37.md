| **Sans (DM Sans)**        | `--font-family-body` / `--font-family-heading` | Body copy, headings, buttons, form controls, descriptions         |
| **Mono (JetBrains Mono)** | `--font-family-meta`                           | Eyebrows, stats, metadata, pills, loading/status text, fine print |

Mono text uses **`--text-meta-*`** size tokens (2px smaller than the matching **`--text-*`** scale, with **`--font-size-sans-adjust`** cancelled so DM Sans body scaling does not shrink mono). Example: **`--text-meta-sm`** for release-card artist/label lines and modal hero artist; **`--text-meta-xs`** on mobile release rows; **`--text-meta-xxs`** for uppercase field-label eyebrows (e.g. crate menu headings, form labels). Numeric pills and badges use **`--font-family-meta`** with **`font-variant-numeric: tabular-nums`** where alignment matters (e.g. playback dock elapsed/duration, mini-player **`.queueCount`** queue-length pill, tracklist **`.trackPosition`**, mobile crate **`ReleasesClient`** **`.fabCount`**, similar-sidebar count segments).
- **Default**: `html` / `body` set `--font-family-body`. Headings inherit `--font-family-heading` (same sans stack). Buttons and inputs use **`font-family: inherit`**.
- **Shared classes**: [`src/styles/modules/typography.module.css`](../../src/styles/modules/typography.module.css) — `siteWordmark`, `brandEyebrow`, `sectionEyebrow`, `displayHeading`, `lead`, `sectionHeading`, `subsectionHeading`, `bodyText`, `metaCaption`. **`siteWordmark`** — small-caps header/nav label (`font-variant-caps: all-small-caps`, `--letter-spacing-eyebrow`); pair with **`SITE_WORDMARK`** from [`siteMetadata.ts`](../../src/constants/siteMetadata.ts) in logged-out [`PublicPageHeader`](../../src/components/PublicPageHeader/PublicPageHeader.component.tsx) (**`fmd-icon.svg`** + wordmark text; link **`aria-label`** stays **`SITE_NAME`**). Authenticated [`HeaderTitle`](../../src/components/StickyHeaderBar/HeaderTitle.tsx) shows the icon only (**`aria-label`** **`SITE_NAME`**). Compose with local layout classes (width, alignment) in component modules. Screen-reader-only text uses [`src/styles/modules/accessibility.module.css`](../../src/styles/modules/accessibility.module.css) (`.visuallyHidden`).
- **Form field labels** (`<label htmlFor=…>`, filter control labels, dialog field names): compose **[`.label`](../../src/styles/modules/field-label.module.css)** — uppercase muted mono eyebrow (`--font-family-meta`, `--text-meta-xxs`, `--letter-spacing-eyebrow`). Same chrome as **[`ReleaseCrateMenu`](../../src/components/ReleaseCard/ReleaseCrateMenu.module.css)** **`.menuHeading`** (layout padding stays local). Checkbox / toggle copy and button text are not field labels—keep body styles. **`composes`** for field labels must live on a **top-level** class (Turbopack rejects nested selectors like `.dialog .label { composes: … }`).
- **Do not** set `var(--font-dm-sans)` or `var(--font-mono)` directly in component CSS—use the semantic tokens above or shared typography classes.
- **Nav and segmented controls** (ViewToggle, Settings theme dropdown) use **`--nav-link-font-family`** / **`--nav-link-font-size`**, which map to the sans stack. [`segmented-control.module.css`](../../src/styles/modules/segmented-control.module.css) **`.segment`** sets the same nav tokens on every **`segmentedStyles.segment`** child — a feature class with only **`--font-family-meta`** / **`--text-meta-*`** on the same element can lose to **`.segment`** when specificity ties. Scope meta typography under a toolbar block (e.g. **`ReleaseSimilarSidebar`** **`.sidebarActions :is(.similarCountSegment, .similarPageSegment)`**) so count/page labels stay compact mono. Pagination prev/next on **`ReleaseSimilarSidebar`** are **`IconButton`** + **`segmentedStyles.segment`** + **`chevron-*-thin.svg`** (no CSS-flip). Inline below **`768px`**, **`.sidebarInline .sidebarActions .pageNavSegment`** centers chevrons with **`display: grid`**, **`place-items: center`**, **`padding: 0`**, touch-target **`min-height`** / **`min-width`**, fixed **`1.125rem`** SVG on **`.segmentIcon`**, and **`transform: none`** on the wrapper so shared **`IconButton`** **`.icon`** **`translateZ(0)`** and **`.segment`** **`line-height`** do not misalign on iOS; aside/desktop **`.pageNavSegment`** uses **`appearance: none`**, **`display: grid`**, **`place-items: center`**, **`line-height: 0`**, compact **`padding: var(--space-2)`**, and **`transform: none`** plus a fixed **`1rem`** SVG on **`.segmentIcon`** so the chevron meets the mono page label (native button metrics and **`IconButton`** **`.icon`** **`translateZ(0)`** sit the glyph low).
- **Exceptions**: Some dense UI keeps **`--text-xxs`** (not `--text-meta-*`) on mono lines—e.g. catalog pills in [`pills.css`](../../src/styles/global/pills.css). Prefer meta size tokens for new mono lines unless the design needs the extra-small sans-scale size.
