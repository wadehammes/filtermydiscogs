## Directory map

### [`src/app/`](../../src/app/)

Next.js routes, layouts, and **Route Handlers** under `app/api/`.
- **Pages**: [`page.tsx`](../../src/app/page.tsx) (login/home), [`collection/`](../../src/app/collection/) (permanent redirect from `/releases`), [`crates/`](../../src/app/crates/) (hub + [`[id]/`](../../src/app/crates/[id]/page.tsx) owner workspace), [`dashboard/`](../../src/app/dashboard/), [`mosaic/`](../../src/app/mosaic/), [`settings/`](../../src/app/settings/), [`crate/[id]/`](../../src/app/crate/[id]/) (public share), [`about/`](../../src/app/about/), [`legal/`](../../src/app/legal/), [`admin/`](../../src/app/admin/).
- **API**: Discogs proxy (`collection`, `collection/fields`, `collection/value`, `collection/instances/...`, `search`, `release/[id]`, **`release/batch`**), auth (`auth/discogs`, `auth/callback`, `auth/check`, `auth/logout`, `auth/clear-data`), crate CRUD under `crates/` (including **`crates/migrate`**), `user/preferences`, `tracks/record`, `tracks/stats`, `build-version`, `image-proxy`, `dashboard/most-crated`, `dashboard/top-tracks`, admin stats + admin user lookup, dynamic OG (`og/crate/[id]`).
- **Root layout**: [`layout.tsx`](../../src/app/layout.tsx) — fonts, metadata defaults, `Providers`, Google Tag Manager.
- **Not found**: [`not-found.tsx`](../../src/app/not-found.tsx) — root 404 for unmatched routes (themed card via [`error-boundary.module.css`](../../src/styles/modules/error-boundary.module.css), **`Go home`** **`Link`**). Single root layout — no experimental **`global-not-found`**.
- **Root error UI**: [`error.tsx`](../../src/app/error.tsx) (under Providers) and segment **`error.tsx`** files share [`ErrorFallbackView`](../../src/app/ErrorFallbackView.tsx) + [`error-boundary.module.css`](../../src/styles/modules/error-boundary.module.css) (centered card, no **`Page`**). [`global-error.tsx`](../../src/app/global-error.tsx) replaces the root layout — own `html`/`body`, no Providers, minimal imports (**`ErrorFallbackView`** — React + **`error-boundary.module.css`** only; **`reportClientFailure`** via dynamic **`import()`** in **`useEffect`** so Turbopack error-boundary chunks do not eagerly load Sentry), theme helper, global CSS only). Dev-only details use an inline localhost hostname check in **`ErrorFallbackView`**. Theme: **`useLayoutEffect`** + [`applyThemeFromStorage()`](../../src/utils/applyThemeFromStorage.ts) on **`global-error`** (uses [`resolveThemeInitAttribute`](../../src/utils/themeAppearance.ts), same rules as generated [`public/theme-init.js`](../../public/theme-init.js); no **`<script>`** — client components cannot execute head scripts in React 19). Unhandled errors also report to Sentry when a DSN is set ([platform.md → Error monitoring](platform.md#error-monitoring-sentry)).
- **Root loading**: [`loading.tsx`](../../src/app/loading.tsx) — provider-free **`PageLoader`** only (Next also mounts it under `/_global-error`). Authenticated shells use segment [`collection/loading.tsx`](../../src/app/collection/loading.tsx) (**[`ReleasesPageLoading`](../../src/components/ReleasesClient/ReleasesPageLoading.component.tsx)**), [`dashboard/loading.tsx`](../../src/app/dashboard/loading.tsx), [`mosaic/loading.tsx`](../../src/app/mosaic/loading.tsx) (**[`AppPageLoading`](../../src/components/AppPageLoading/AppPageLoading.component.tsx)**).

Most feature pages are **client components** (`*Client.tsx`) wrapped by thin server `page.tsx` shells that set metadata and **static-import** the client module (segment **`loading.tsx`** supplies **`AppPageLoading`** during navigation — do **not** wrap `*Client` in **`next/dynamic`**; Turbopack dev breaks lazy client chunks with **“module factory is not available”**). Mosaic still uses [`MosaicClientWrapper`](../../src/components/MosaicClient/MosaicClientWrapper.component.tsx) (`ssr: false` in a client wrapper only).

### [`src/components/`](../../src/components/)

Feature UI: one folder per area (e.g. `Dashboard`, `ReleaseCard`, `StickyHeaderBar`, `PublicAuthLayout`). See [components.md](components.md).

**Public auth shell**: [`PublicAuthLayout`](../../src/components/PublicAuthLayout/PublicAuthLayout.component.tsx) wraps home, about, legal, and public crate pages.

**Authenticated shells**: [`ReleasesClient`](../../src/components/ReleasesClient/ReleasesClient.component.tsx) (primary collection UI), [`DashboardClient`](../../src/components/Dashboard/DashboardClient.component.tsx), [`MosaicClient`](../../src/components/MosaicClient/MosaicClient.component.tsx), [`SettingsClient`](../../src/components/Settings/SettingsClient.component.tsx), [`CratesClient`](../../src/components/Crates/CratesClient.component.tsx) / [`CrateDetailClient`](../../src/components/Crates/CrateDetailClient.component.tsx), [`AdminDashboardClient`](../../src/components/AdminDashboard/AdminDashboardClient.component.tsx).

[`Providers.tsx`](../../src/components/Providers.tsx) wires **QueryClient**, **JotaiProvider**, theme, auth, collection, filters, and view providers for every route. **`PlaybackReleaseClickProvider`**, **`CrateProvider`**, **`CollectionCachePrepGate`** (IndexedDB → React Query as soon as a username or soft-logout **`reconnectUsername`** is known), and **`AuthenticatedCollectionSyncGate`** (`CollectionDataSync` when signed in) are always mounted. Heavy authenticated-only providers (**`ReleasePlaybackProvider`**, **`GlobalPlaybackDock`**) load through [`AuthenticatedProvidersGate`](../../src/components/AuthenticatedProvidersGate.component.tsx) → dynamically imported [`AuthenticatedProviders`](../../src/components/AuthenticatedProviders.tsx) when the user is signed in or auth is still checking on a protected route ([`protectedRoutes.ts`](../../src/constants/protectedRoutes.ts)). **`AppToaster`** (Base UI Toast) sits under `ThemeProvider`; session toasts and **`LogoutOverlay`** render inside the gate wrapper. See [patterns.md → Provider stack](patterns.md#provider-stack).
