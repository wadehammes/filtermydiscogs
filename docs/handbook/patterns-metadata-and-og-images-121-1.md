## Metadata and OG images

- Shared site name (**`SITE_NAME`**), header wordmark (**`SITE_WORDMARK`**, domain-style caps for nav branding), share-card brand (**`SITE_DOMAIN_LABEL`**: **`FilterMyDisco.gs`**), tagline, descriptions, URL helpers, canonical URL builder (**`siteCanonicalUrl`**), collection format phrase (**`COLLECTION_FORMATS_PHRASE`**: vinyl, CDs, tapes, and any Discogs format), preview image alt (**`LOGIN_PREVIEW_ALT`**), private-route robots defaults (**`PRIVATE_PAGE_ROBOTS`**, used on `/collection`, `/dashboard`, `/settings`, `/mosaic`, `/admin`), public-share robots (**`PUBLIC_SHARE_PAGE_ROBOTS`**, index/follow on resolved **`/crate/[id]`**, **`/playlist/[id]`**, and **`/release/[id]`** metadata via [`buildPublicReleasePageMetadata`](../../src/lib/public-release-page-metadata.server.ts)), and home JSON-LD payload (**`homeStructuredData`**) in [`src/constants/siteMetadata.ts`](../../src/constants/siteMetadata.ts).
- Root metadata defaults in [`src/app/layout.tsx`](../../src/app/layout.tsx) (`metadataBase`, **`alternates.canonical`** via **`siteCanonicalUrl`**).
- Root fonts in the same [`layout.tsx`](../../src/app/layout.tsx): variable **DM Sans** and **JetBrains Mono** via **`next/font/google`** (**`variable: "--font-dm-sans"`** / **`"--font-mono"`** on **`<html>`**; semantic **`--font-family-*`** in [`base.css`](../../src/styles/themes/base.css) — [conventions.md → Typography](conventions.md#typography)). Do **not** pass multi-entry **`weight`** arrays — Turbopack dev expects one font file per family and fails with **`next/font/google queries have exactly one entry`**. Weight steps (300–700) come from CSS **`font-weight`** on the variable faces. If font modules still fail in dev, use **`pnpm dev:webpack`** ([platform.md → Package scripts](platform.md#package-scripts)).
- Per-route metadata in `page.tsx` files. Public crate and playlist shares use **[`buildPublicSharePageMetadata`](../../src/lib/public-share-metadata.server.ts)** (title, description, **`alternates.canonical`**, Open Graph / Twitter images, **`robots`**: index when the public row resolves). Public **`/release/[id]`** (Discogs catalog id) uses **`generateMetadata`** in [`page.tsx`](../../src/app/release/[id]/page.tsx): **`getPublicReleaseMetadataForPage`** → **`buildPublicReleasePageMetadata`** when **[`loadPublicReleaseDiscogsDetailForPage`](../../src/lib/public-release-discogs-detail.server.ts)** resolves; otherwise **`getPrivateReleaseNotFoundMetadata`** (**`PRIVATE_PAGE_ROBOTS`**, **`PAGE_DESCRIPTIONS.releaseListenFallback`**). Missing, invalid, or **`private: true`** shares call **`notFound()`** (404 + global **`not-found`** metadata with **`noindex`**). Playwright demo share URLs use **[`shouldNotFoundPublicSharePage`](../../src/lib/public-share-e2e.server.ts)** so **`NEXT_PUBLIC_E2E_MOCK_YOUTUBE_EMBED=1`** can render the client MSW stack without a Postgres row (see [platform.md → Playwright](platform.md#playwright-instant-navigation-tests)). Owner **`private`** toggles on **`PUT /api/crates/[id]`** / **`PATCH /api/playlists/[id]`** call **[`revalidatePublicShareSeo`](../../src/lib/public-share-cache.server.ts)** (share path, **`/sitemap.xml`**, and per-id cache tags on metadata / OG / page payload). Public playlist track mutations on **`POST` / `DELETE` / `PUT /api/playlists/[id]/tracks`** call **[`revalidatePublicPlaylistShareWhenPublic`](../../src/lib/public-share-cache.server.ts)**; public crate release membership/layout changes on **`POST /api/crates/[id]/releases`**, **`DELETE /api/crates/[id]/releases/[releaseId]`**, **`PUT /api/crates/[id]/layout`**, and **`PUT /api/crates/membership/[instanceId]`** (added/removed crate ids) call **`revalidatePublicCrateShareWhenPublic`** / **`revalidatePublicCrateSharesWhenPublic`** — so **`/crate/[id]`** / **`/playlist/[id]`** SSR, OG, and public GET cache tags refresh when the share row is **`private: false`** (private shares skip revalidation).
- Default social images: static [`opengraph-image.png`](../../src/app/opengraph-image.png) and [`twitter-image.png`](../../src/app/twitter-image.png) in `src/app/` with matching [`opengraph-image.alt.txt`](../../src/app/opengraph-image.alt.txt) / [`twitter-image.alt.txt`](../../src/app/twitter-image.alt.txt). Shared alt text and metadata objects live in [`src/constants.ts`](../../src/constants.ts) (`DEFAULT_OPEN_GRAPH_IMAGE`, `DEFAULT_TWITTER_IMAGE`). Per-route metadata references those constants with `metadataBase` from [`layout.tsx`](../../src/app/layout.tsx).
