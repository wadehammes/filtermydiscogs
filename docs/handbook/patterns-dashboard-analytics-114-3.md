- **Card chrome**: Bordered dashboard surfaces compose shared [`dashboard-card.module.css`](../../src/styles/modules/dashboard-card.module.css): **`.card`** (base elevated panel — **`--surface: var(--card)`**, **`--radius-card`**, **`theme-surface-elevated`**) and **`.releaseRow`** (composes **`.card`** + flex row padding for release lists). **Release rows** (On this day, most crated, milestones, duplicate list items, etc.) must use **[`DashboardReleaseItem`](../../src/components/Dashboard/DashboardReleaseItem.component.tsx)** inside **`.releaseRow`** — do not reimplement cover/title/meta layout or one-off card chrome in section modules. **Track rows** (**On repeat** — [`TopTracks`](../../src/components/Dashboard/TopTracks.component.tsx)) use **[`DashboardTrackItem`](../../src/components/Dashboard/DashboardTrackItem.component.tsx)** in the same **`.releaseRow`** chrome: clickable **48px** release cover (same activate pattern as **`DashboardReleaseItem`** — **`getReleaseActivateProps`**, **`getReleaseImageUrl`**) keyed by **`instance_id`**, primary line **`formatTopUserTrackHeadLabel`** in [`userTrack.ts`](../../src/utils/userTrack.ts) (**`{position} - {title}`**; enriches from release tracklists via **`buildCatalogTitleByTrackKey`** + **`useQueries`** / **`discogsReleaseQueryOptions`**), **artist · release** meta, trailing play/listen count (Most Crated-style column). Leaderboard rows come from **`useTopUserTracksQuery`** (**`GET /api/dashboard/top-tracks`**, optional **`release_thumb`** from one batched crate lookup). Covers: collection art via **`useAllReleases()`** + **`buildReleaseIndexFromList`**, then API thumb, then SVG placeholder — **`DashboardTrackItem`** always renders the cover slot. Do not reimplement row layout in **`TopTracks.module.css`** beyond the two-column grid, column intros, and list **`max-height`** scroll. Chart containers, rhythm cards, health tiles, milestone timeline cards, and grouped panels compose **`.card`** directly and add section-specific inner layout. Chart header toggles (**Monthly** / **Yearly** in [`GrowthChart`](../../src/components/Dashboard/GrowthChart.component.tsx), **Total** / **Share** in [`ComparativeGrowthCharts`](../../src/components/Dashboard/ComparativeGrowthCharts.component.tsx)) use **[`SegmentedControl`](../../src/components/SegmentedControl/SegmentedControl.component.tsx)** with **`IconButton`** segments (**`segmentedStyles.segment`**) — not one-off button pairs or **`role="group"`** on a **`div`**.
