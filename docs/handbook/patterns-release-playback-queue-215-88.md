By default the YouTube embed is hidden (audio-only) and the dock video panel stays **collapsed** when playback becomes ready or autoplay starts (desktop and mobile) — scrub/volume in the bar replace needing an open panel. A **video** control toggles a 16:9 panel ([`ReleasePlaybackVideoPanel`](../../src/components/ReleasePlaybackVideoPanel/ReleasePlaybackVideoPanel.component.tsx)). **Show video** after audio-only playback (including after hidden track switches via postMessage **`loadVideoById`**) resumes without reloading **`iframe.src`** — see [`PersistentYoutubeIframe`](../../src/components/PersistentYoutubeIframe/PersistentYoutubeIframe.component.tsx). Toggling **Show video** still marks [`playbackVideoIntroStorage.ts`](../../src/utils/playbackVideoIntroStorage.ts) (cleared on **Clear stored data**). Restore-after-refresh playback starts **paused** with the panel collapsed until the listener taps play. On **mobile**, the panel is full viewport width, stacked above the mini-player bar inside **`PlaybackPageShell`**, with a single compact chrome row (**close** on the right; no drag/resize). Opening the **filters drawer** or **crate drawer** collapses an expanded mobile video panel and blocks expand until the drawer closes ([`useFiltersDrawerOpen`](../../src/hooks/useFiltersDrawerOpen.hook.ts), [`PlaybackPageShell.module.css`](../../src/components/PlaybackPageShell/PlaybackPageShell.module.css)). On **desktop** it defaults to the **bottom-right** above the mini-player bar (**`--release-video-panel-inset-right`**) — the same inset when the **`/collection`** crate sidebar is open so the panel stays aligned with the video control on the dock. One chrome row is the drag handle (centered grip indicator, **Reset** and **Close** on the right — **[`useDraggablePanel`](../../src/hooks/useDraggablePanel.hook.ts)** **`handlePointerDown`** skips **`button`** / **`a`** so those controls do not start a drag); drag elsewhere on that bar to reposition. Four invisible resize targets (corner cursors only, no on-screen grips): **top-left** on the chrome (**`.panelChromeNwResize`**) so **`nwse-resize`** wins over the bar's **`cursor: grab`**; **top-right**, **bottom-left**, and **bottom-right** on **`.videoContent`** (**top-right** stays on the video so it does not cover **Close**). Drag a target to resize between **`DEFAULT_VIDEO_PANEL_INITIAL_SCALE`** (0.75) and the native YouTube embed width (**640px** panel width — **`getVideoPanelMaxScaleForYoutubeEmbed`** in [`videoPanelLayoutStorage.ts`](../../src/utils/videoPanelLayoutStorage.ts), matching **`YOUTUBE_EMBED_PLAYER_WIDTH`** in [`postYoutubePlayerCommand.ts`](../../src/utils/postYoutubePlayerCommand.ts); the opposite corner stays anchored — see [`videoPanelCornerResize.ts`](../../src/utils/videoPanelCornerResize.ts)). **Reset** (and double-click the drag bar) restores default dock position and **`DEFAULT_VIDEO_PANEL_INITIAL_SCALE`**. While dragging or resizing, **`.videoPanelDragging`** disables iframe **`pointer-events`** so gestures stay on the panel; opening the panel plays a short transform reveal in [`ReleasePlaybackVideoPanel.module.css`](../../src/components/ReleasePlaybackVideoPanel/ReleasePlaybackVideoPanel.module.css) (**desktop**: scale from **`transform-origin: bottom right`**; **mobile**: slight rise from **`bottom center`**) rather than animating width/height — disabled while dragging, when a float position is active (**`.videoPanelPositioned`**), or under **`prefers-reduced-motion`**. Layout persists for the browser session until the viewport crosses back from mobile to desktop or a stored position no longer fits the viewport, when position and scale reset to the default inset size. The app does not open PiP programmatically, but listeners may use the browser’s PiP on the embed; queue advance still uses **`loadVideoById`** (PiP may close when the video changes). Cover/title opens **`ReleaseModal`**. Play/pause sends YouTube iframe commands via **`togglePlayback`**. [`PersistentYoutubeIframe`](../../src/components/PersistentYoutubeIframe/PersistentYoutubeIframe.component.tsx) keeps a single embed mounted in the dock; when collapsed it stays off-screen for audio-only playback. Embeds use **`playsinline=1`** for iOS. A track row click in **`ReleaseModal`** calls **`startPlayback`**; closing the modal does not stop playback. **`startPlayback`** schedules **`playVideo`** iframe commands (with retries up to 3s). [`useReleaseMiniPlayerVideoPanelState`](../../src/components/ReleaseMiniPlayer/useReleaseMiniPlayerVideoPanelState.hook.ts) keeps manual **`videoPanelOverride`** only (no intro or autoplay auto-expand). **`ReleaseMiniPlayer`** calls **`resumePlaybackFromGesture`** when the panel expands while transport is playing so the visible embed receives **`playVideo`**. Prev/next advance within the global queue and keep the video panel open when it was already expanded.
