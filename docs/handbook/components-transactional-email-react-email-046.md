## Transactional email (React Email)

[`src/components/Email/`](../../src/components/Email/) holds **Resend** templates (same stack as **delmarva-site**: shared **`EmailLayout`**, **`EmailHeader`** / **`EmailFooter`**, **`emailTheme.ts`** + **`emailClasses.ts`**, React Email **`Tailwind`**). Import primitives from **`react-email`** in templates; keep devDependency **`@react-email/ui`** at the same version as **`react-email`** — the **`email dev`** preview server resolves it, not app runtime imports. **`RESEND_REPLY_TO`** drives Resend **`reply_to`** on every send via [`sendResendEmail`](../../src/lib/resend.server.ts) (**`resendReplyToSendFields`**) and the footer contact line when server renders pass **`getResendReplyTo()`** as **`contactEmail`** on **`EmailFooter`** — [`emailFooterContactLink`](../../src/utils/emailMailbox.ts) parses mailbox strings (e.g. `Name <addr>`) so the visible link uses the display name and **`mailto:`** uses the bare address. Future transactional mail should call **`sendResendEmail`** — not **`resend.emails.send`** directly. Production render: shared [`renderTransactionalEmail.server.tsx`](../../src/lib/renderTransactionalEmail.server.tsx) wrappers [`renderWelcomeSignupEmail.server.tsx`](../../src/lib/renderWelcomeSignupEmail.server.tsx) and [`renderUserEmailVerificationEmail.server.tsx`](../../src/lib/renderUserEmailVerificationEmail.server.tsx); senders: [`welcomeSignupEmail.server.ts`](../../src/lib/welcomeSignupEmail.server.ts), [`sendUserEmailVerification.server.ts`](../../src/lib/sendUserEmailVerification.server.ts) ([platform.md](platform.md) for env). Template asset/base URLs use [`getEmailBaseUrl`](../../src/lib/emailConstants.ts) (`getSiteUrl()` — localhost in dev when **`NEXT_PUBLIC_SITE_URL`** is unset). Verification **confirm** links use the inbound **`PATCH /api/user/contact`** request origin (`request.nextUrl.origin`) so local/staging mail matches where you saved Settings. Specs: [`resend.server.spec.ts`](../../src/lib/resend.server.spec.ts). Templates export **`PreviewProps`** for **`pnpm email:dev`**. Component specs mock **`react-email`** in the PO ([`WelcomeSignupEmailTemplate.po.tsx`](../../src/components/Email/WelcomeSignupEmailTemplate.po.tsx), [`UserEmailVerificationEmailTemplate.po.tsx`](../../src/components/Email/UserEmailVerificationEmailTemplate.po.tsx)); server render specs mock **`react-email`**’s **`render`** in the spec file ([`renderWelcomeSignupEmail.server.spec.tsx`](../../src/lib/renderWelcomeSignupEmail.server.spec.tsx), [`renderUserEmailVerificationEmail.server.spec.tsx`](../../src/lib/renderUserEmailVerificationEmail.server.spec.tsx)).
