### Fallow vs Knip

**Knip** remains the primary **dead-code CI gate** (`pnpm knip:ci`) — unused exports, deps, and files. **Fallow** still runs in CI (**`pnpm fallow:audit:ci`**) and prints complexity / duplication / cycle reports vs **`staging`**, but **does not fail** PR checks — marginal growth on inherited mega-hooks (playback provider/embed) was blocking feature work without matching product value. Treat the log as review signal; use **`pnpm fallow:audit`** locally (**`mise run pr-prep`**) when you want the stricter **new-only** gate. Agents still use Fallow for **import cycles**, duplication traces, and health scores. When Fallow reports a cycle, fix with the patterns in [patterns.md → Large context providers](patterns.md#large-context-providers-playback-crates-notes-editor) (types split, dynamic chunk prefetch, no static lazy-loader imports in shared utils). Config lives in [`.fallowrc.jsonc`](../../.fallowrc.jsonc) (Knip-equivalent ignores via **`overrides`**, intentional duplicate **type barrel** pairs via **`ignoreExports`**, Jest mock **entry** points, shared **CSS Modules** reached only via **`composes:`** (and Stylelint-only **`stylelint-custom-properties.css`**) in **`entry`**, Jest-only **ignoreDependencies**, **`health.ignore`** for specs/page objects/e2e so the health score reflects shipped code, **`.jest/**`** in **`ignorePatterns`** to silence hidden-dir warnings). Jest setup under **`.jest/`** stays reachable via explicit **entry** paths and mocks under **`src/tests/mocks/`**.

**Architecture boundaries and policy (warn):** [`.fallowrc.jsonc`](../../.fallowrc.jsonc) declares **`src/` zones** (`types`, `constants`, `styles`, `utils`, `lib`, `api`, `atoms`, `context`, `hooks`, `components`, `app`) and import rules between them — tuned for this repo (e.g. **`hooks` ↔ `components`** colocated hooks, **`lib` → `hooks`** for React Query keys, **`types` → `utils`** for shared playback/view types). **`boundary-violation`** is **`warn`** for import edges (not CI blockers). **`boundaries.calls.forbidden`** blocks **`alert` / `confirm` / `prompt`**, **`child_process.*`**, and **`fs.*`** in client-oriented zones (and browser dialogs in **`app`**); specs are not in those zones. Unzoned paths (root configs, **`src/analytics/`**, instrumentation, e2e assets) sit in **`boundaries.coverage.allowUnmatched`**. Specs disable **`boundary-violation`** via an **`overrides`** entry. Full house rules (calls + banned imports for **`next/headers`**, **`@prisma/client`**, **`src/lib/db`**, **`server-only`**) live in [`.fallow/filtermydiscogs-policy.jsonc`](../../.fallow/filtermydiscogs-policy.jsonc); wire **`"rulePacks": [".fallow/filtermydiscogs-policy.jsonc"]`** and **`policy-violation: warn`** only after that file is on **`staging`** (audit loads the current config against the base tree). Before editing a hot file, agents can run **`fallow guard <path>`** or **`fallow architecture`**. **`health.coverage`** points at **`coverage/coverage-final.json`** after **`pnpm test:coverage`** for Istanbul-backed CRAP.

Wire-up: **`pnpm exec fallow agent install --harness cursor --without hooks --without skill`** — refreshes [`.cursor/mcp.json`](../../.cursor/mcp.json) after Fallow upgrades without recreating **`.agents/skills/fallow`** or commit hooks. Agent context comes from MCP tool descriptions, **`.cursor/rules/`**, **`.cursor/skills/`**, and the task map in **`AGENTS.md`**. Optional local skill: read **`node_modules/fallow/skills/fallow/SKILL.md`** after **`pnpm install`**, or **`fallow agent install --user`** for **`~/.agents/skills/fallow`**.

**Git:** [`.fallow/.gitignore`](../../.fallow/.gitignore) ignores Fallow’s local **`*.bin`** / **`cache/`** workspace (do not commit). Only optional **`.fallow/*.jsonc`** policy files are tracked when present.
