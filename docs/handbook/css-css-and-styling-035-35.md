- **`:has()` / `:is()` / `aria-*`**: Prefer parent **`:has()`** (e.g. **`.valueContainer:has(.pillsContainer)`**, **`.inputContainer:has(.clearButton)`**, disabled checkbox labels **`:has(input:disabled)`**, owner crate **`sectionGroup:has(> .sectionBody[data-section-empty])`** for empty-section head radius in [`CrateLayoutList.module.css`](../../src/components/Crates/CrateLayoutList.module.css) — set **`data-section-empty`** from TSX when the group has no members, not **`:empty`** on the body) and toggle **`aria-pressed="true"`** / **`aria-disabled="true"`** selectors over TSX only modifier classes when the DOM already exposes state. When a control must stay **hoverable** (CSS tooltip) while logically blocked, use **`aria-disabled`** + click guard instead of native **`disabled`** — see **[`CollectionRadioPlayButton`](../../src/components/CollectionRadioPlayButton/CollectionRadioPlayButton.component.tsx)** during detail prefetch. Compose shared menu hover/disabled rules from [`menu-item-interaction.module.css`](../../src/styles/modules/menu-item-interaction.module.css). Use **`:is()`** inside **`:not()`** for multi-condition disabled lists (see **`FilterViewsMenu`** menu items).
- **Viewport height**: Prefer **`100dvh`** / **`100svh`** (and **`--available-height`**) over **`100vh`** for full-viewport shells and loaders. **`:root`** in [`playback-dock.css`](../../src/styles/global/playback-dock.css) seeds **`--available-height`** and modal inset vars; **`html:has([data-global-playback-dock])`** sets **`--release-modal-viewport-inset-bottom`** from **`--release-mini-player-bar-offset`** and recomputes **`--available-height`** / **`--release-modal-available-height`** so scroll caps subtract the dock — use in **`min()`** caps for scroll regions ([`ScrollModal.module.css`](../../src/components/ScrollModal/ScrollModal.module.css), [`ReleaseTracklist.module.css`](../../src/components/ReleaseTracklist/ReleaseTracklist.module.css), [`TopTracks.module.css`](../../src/components/Dashboard/TopTracks.module.css)). **`html`** sets **`scrollbar-gutter: stable`** in [`global.css`](../../src/styles/global.css).
- **Layout container queries**: Prefer **`container-type: inline-size`** on component roots when columns should respond to **parent** width — e.g. [`StatsGrid`](../../src/components/StatsGrid/StatsGrid.module.css) (named **`stats-grid`** on **`.container`**, grid on **`.statsGrid`** so **`@container`** rules target a descendant), [`ReleaseCard`](../../src/components/ReleaseCard/ReleaseCard.module.css) (`release-card` → title/meta in [`ReleaseCardTitle.module.css`](../../src/components/ReleaseCard/ReleaseCardTitle.module.css)), [`ReleasesClient`](../../src/components/ReleasesClient/ReleasesClient.module.css) **`.mainContent`** (**`releases-main`**) → multi-column [`ReleasesGrid.module.css`](../../src/components/ReleasesClient/ReleasesGrid.module.css) at **`620px`** inline size (crate drawer shrinks the column, not the viewport), [`DashboardHero`](../../src/components/Dashboard/DashboardHero.module.css) **`.metricsList`**, [`FiltersBar`](../../src/components/StickyHeaderBar/FiltersBar.module.css) **`.styleFilterGroup`**. Do not put **`container-type`** and the **`@container { .sameClass }`** rule on the same element — queries only match **descendants**. Style queries remain in [`theming.css`](../../src/styles/global/theming.css). **`FiltersBar`** **`.styleFilterGroup`** keeps **`overflow: hidden`** for filter control corners; **`.desktopFilters`** / **`.collectionRadioPlayEnd`** use **`overflow: visible`** so descendant tooltips (collection radio) are not clipped.
- **Scratchpad textareas**: [`scratchpad-textarea.module.css`](../../src/styles/modules/scratchpad-textarea.module.css) uses **`field-sizing: content`** inside **`@supports`** so notes grow with content; colocated modules still set **`min-height`** in **`lh`** where needed ([`CrateSetNotesScratchpad.module.css`](../../src/components/CrateSetNotesScratchpad/CrateSetNotesScratchpad.module.css)).
- **Segmented controls**: Use **[`SegmentedControl`](../../src/components/SegmentedControl/SegmentedControl.component.tsx)** — [`.container`](../../src/styles/modules/segmented-control.module.css) uses **`padding: 1px`** (inset track), **`align-items: stretch`**, and first/last **`.segment`** end caps at **`--segment-inset-radius`** (`calc(var(--radius-ui) - 2px)` — concentric inside the 1px border + inset). Default **`overflow: hidden`**; pass **`allowOverflow`** only for tooltip overflow ([`ReleaseCardOverlayActions`](../../src/components/ReleaseCard/ReleaseCardOverlayActions.component.tsx)). Desktop overlay **`.segmentSlot .tooltip`** labels in [`ReleaseCard.module.css`](../../src/components/ReleaseCard/ReleaseCard.module.css) show on **`:hover` only** (not **`:focus-within`**) and hide while a portaled menu is open (**`:has([data-popup-open])`**) so labels do not stick when the trigger keeps focus after opening **`ReleaseCrateMenu`**.
- **Horizontal scroll fade**: [`HorizontalScrollRow`](../../src/components/HorizontalScrollRow/HorizontalScrollRow.module.css) uses scroll-driven **`animation-timeline: scroll()`** when supported; legacy browsers keep the JS-toggled static **`mask-image`** fallback.
- **Color**: Use **`color-mix(in srgb, …)`** for tinted surfaces (see [`workspace-fab-chrome.module.css`](../../src/styles/modules/workspace-fab-chrome.module.css) **`.fabchrome`** — shared by mobile **`BackToTop`** and crate FAB).
- **Fluid sizing**: Use **`clamp()`** for type and spacing that scales across viewports (see [`MosaicClient.module.css`](../../src/components/MosaicClient/MosaicClient.module.css)).
