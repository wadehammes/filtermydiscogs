  - **`background-surface.css`** — **`--background-gradient`** (default **`none`**) and optional full-page wash on **`html`** via **`var(--page-background, var(--background))`**; multi-hue palettes such as **`sunset`**, **`prism`**, and **`aurora`** set distinct **`--gradientPink`** / **`--gradientTeal`** hues plus a diagonal gradient. **`sunset`** anchors to the popular [Coolors golden-hour five-stop](https://coolors.co/ffd93d-ffb75e-ff8a5b-ff3d77-7a2648) (gold → coral → burgundy dusk), not violet UI chrome.
  - Individual palette files (**`dim.css`**, **`sepia.css`**, **`ocean.css`**, **`lavender.css`**, **`ember.css`**, **`terracotta.css`**, **`sunset.css`**, **`summer.css`**, **`aurora.css`**, **`prism.css`**, etc.) — anchor **`--background`**, theme-specific gradients/pills, and exceptions only; register each palette in [`themeAppearance.ts`](../../src/utils/themeAppearance.ts) **`PALETTE_THEMES`** (and **`MULTI_HUE_PALETTE_THEMES`** when the palette uses split accent hues), run **`pnpm generate:theme-init`**, extend **`primary.css`**, **`link.css`**, and **`palette-derivations.css`**, update [`themeContrastPairs.ts`](../../src/utils/themeContrastPairs.ts), and run **`e2e/theme-contrast.spec.ts`** (see [platform.md → Playwright](platform.md#playwright-instant-navigation-tests)). **`--pattern-microdot-mix`** (and rarely **`--pattern-microdot`**) tune dot visibility on patterned surfaces.
  - **`theming.css`** — global utility classes (`.theme-surface-elevated`, `.theme-highlighted-surface`, `.theme-gradient-surface`, `.theme-on-gradient-muted`); file lives in [`global/theming.css`](../../src/styles/global/theming.css), loaded from **`themes/index.css`**.
  - **`index.css`** — imports the files above; loaded from [`global.css`](../../src/styles/global.css).
- **Theme palette changes**: [`applyThemeToDocument`](../../src/context/theme.context.tsx) sets **`data-theme`**, then toggles **`theme-transitioning`** on `<html>` for one frame so descendant **`transition`** rules snap (see [`base.css`](../../src/styles/themes/base.css)); do not ease token colors during palette swaps.
- **Theming**: Semantic colors live in [`colors.css`](../../src/styles/themes/colors.css) (`:root` defaults including **`--primary: light-dark(#06c, #06f)`** and **`--link: light-dark(#06c, #07f)`**) and resolve with **`light-dark()`** from **`color-scheme`**. Use **`--primary*`** for filled surfaces (buttons, segmented **`.active`**, badges on press); use **`--link*`** for text links, nav active state, outline-button default, menu hover copy, and **`accent-color`**. Hover/active states and shadows use **`color-mix()`**; destructive/success/warning label colors use **`contrast-color()`**. Per-theme **`--primary*`** overrides live in [`primary.css`](../../src/styles/themes/primary.css); [`link.css`](../../src/styles/themes/link.css) sets **`--link*`** to **`--primary*`** on most named palettes; default **`dark`** and **`wine`** keep a brighter **`--link*`** for AA text on **`--background`**. **`--sticky-header-background`** aliases **`--background`**; **`.layout-sticky-header`** tints from **`--background`**, not **`--card`**. **`dim`** steel blue `#2f4d63`; **`sepia`** umber `#6b4828`; **`forest`** moss `#243830`; **`amber`** bronze `#5a3d00`; **`slate`** `#173248`; **`midnight`** `#6ba3e8`; **`codex`** `#58a6ff`; **`discogs`** `#00e`; **`wine`** `#c45a7a`; **`futuristic`** `#00e8ff`; **`high-contrast`** `#6eb5ff`). Custom palettes set **`--background`**, theme-local **`--gradientPink`** / **`--gradientTeal`** (so footer/marketing gradients harmonize instead of inheriting the neon light/dark stops), pills, and gradient surfaces in [`dim.css`](../../src/styles/themes/dim.css) (light cool gray with soft surface contrast), [`sepia.css`](../../src/styles/themes/sepia.css) (warm parchment), [`forest.css`](../../src/styles/themes/forest.css) (sage green), [`amber.css`](../../src/styles/themes/amber.css) (rich honey gold), [`slate.css`](../../src/styles/themes/slate.css) (coastal blue-gray), [`midnight.css`](../../src/styles/themes/midnight.css) (deep indigo), [`codex.css`](../../src/styles/themes/codex.css) (GitHub Dark homage — `#0d1117` canvas, `#58a6ff` links, syntax-style pills), [`discogs.css`](../../src/styles/themes/discogs.css) (white collection-table canvas, classic blue links, gold rating/format accents), [`wine.css`](../../src/styles/themes/wine.css) (burgundy cellar — plum **`--gradientPink`** surfaces in [`palette-derivations.css`](../../src/styles/themes/palette-derivations.css), rose/gold pills, muted semantic accents), [`futuristic.css`](../../src/styles/themes/futuristic.css) (void black with electric cyan/magenta neon glow), and [`high-contrast.css`](../../src/styles/themes/high-contrast.css); shared surface tokens and per-palette **destructive/success/warning** tuning (for contrast on derived **`--card`** surfaces) live in [`palette-derivations.css`](../../src/styles/themes/palette-derivations.css). Derived surfaces mix **`--gradientPink`** / **`--gradientTeal`** / **`--primary`** into **`--background`** (not white lifts) so modals, cards, and sidebars stay in each palette’s hue family; **`--pill-style-*`** / **`--pill-format-*`** in each palette file follow the same harmony. The theme provider sets **`data-theme`** on `<html>` to the resolved palette; **`system`** stores the user preference but applies **`light`** or **`SYSTEM_DARK_PALETTE`** (`dark`) from the OS. Labels, cycle order, and **`themeUsesDarkAssets`** live in [`themeAppearance.ts`](../../src/utils/themeAppearance.ts).
