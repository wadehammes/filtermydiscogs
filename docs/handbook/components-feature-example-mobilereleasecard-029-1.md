## Feature example: MobileReleaseCard

[`src/components/ReleaseCard/MobileReleaseCard.component.tsx`](../../src/components/ReleaseCard/MobileReleaseCard.component.tsx) is the **mobile** release row (image | content | optional action column). Optional props **`showOverlayActions`** (default **`true`**) and **`rootTestId`** (default **`fmdMobileReleaseCard`**). **`PublicMobileReleaseCard`** is a thin wrapper with **`showOverlayActions={false}`** and **`rootTestId="fmdPublicMobileReleaseCard"`** (no crate menu / notes column; format/style pills are display-only **`<span>`**s, not filter buttons; no **`ReleaseNotesEditorProvider`** wrapper).
