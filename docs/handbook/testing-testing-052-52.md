- **Assertions**: Prefer asserting final DOM/output; avoid `expect(mockFn).toHaveBeenCalledWith(...)` when un-mocking—the output already proves wiring. Do not use **`toBeTruthy()`** / **`toBeFalsy()`**—assert the concrete shape (**`not.toBeNull()`**, **`not.toBeUndefined()`**, **`toEqual(expect.any(String))`**, **`toBeInTheDocument()`**, bitwise **`not.toBe(0)`**, …). Do not add specs whose only signal is “a CSS class name exists in a stylesheet” (no **`readFileSync`** on **`.css`** for **`toContain(".foo")`**-style checks). Deep-equal on **`DiscogsFormat`** rows: reuse the same **`formatFactory.build()`** reference in setup and **`toEqual`** ([factories.md → `releaseFactory` overrides](factories.md#releasefactory-overrides)).

- **jest-dom 8** ([`@testing-library/jest-dom`](../../node_modules/@testing-library/jest-dom/README.md)): global matchers come from **`@testing-library/jest-dom/jest-globals`** in [`.jest/setupTests.ts`](../../.jest/setupTests.ts) (types: [`.jest/jest-dom-globals.d.ts`](../../.jest/jest-dom-globals.d.ts)). - **SVG icons**: UI icons live in [`src/styles/icons/`](../../src/styles/icons/). Prefer **`*-thin.svg`** assets (16×16 viewBox, `stroke-width="1"`, stroke-based) for controls and actions.
