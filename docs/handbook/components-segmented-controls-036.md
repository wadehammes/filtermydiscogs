## Segmented controls

Use **[`SegmentedControl`](../../src/components/SegmentedControl/SegmentedControl.component.tsx)** for grouped toggle rows (view mode, chart range, crate drawer actions, release-card overlay actions, **[`MobileMenuDrawerFooter`](../../src/components/StickyHeaderBar/MobileMenuDrawerFooter.tsx)** account rows below **`1024px`**). It renders a **`<fieldset>`** with a visually hidden **`<legend>`** and applies [`segmented-control.module.css`](../../src/styles/modules/segmented-control.module.css) **`.container`**. Re-export **`segmentedStyles`** from the component for **`.segment`** / **`.active`** on child **`IconButton`** / **`IconButtonLink`** segments — do not hand-wire **`fieldset`** + **`legend`** + **`accessibilityStyles.visuallyHidden`** in feature TSX.

| Prop                | Role                                                                                                                                                                                                                     |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **`legend`**        | Accessible group label (required).                                                                                                                                                                                       |
| **`className`**     | Feature layout overrides (e.g. [`ViewToggle.module.css`](../../src/components/ViewToggle/ViewToggle.module.css), [`CrateDrawerFooter.module.css`](../../src/components/CrateDrawerFooter/CrateDrawerFooter.module.css)). |
| **`vertical`**      | Stacks segments (**`.containerVertical`**).                                                                                                                                                                              |
| **`allowOverflow`** | Keeps first/last corner radii for tooltip overflow ([`ReleaseCardOverlayActions`](../../src/components/ReleaseCard/ReleaseCardOverlayActions.component.tsx), **[`MobileMenuDrawerFooter`](../../src/components/StickyHeaderBar/MobileMenuDrawerFooter.tsx)** **More** popover).                                                            |

Consumers: [`ViewToggle`](../../src/components/ViewToggle/ViewToggle.component.tsx), [`CollectionSidePanelToggle`](../../src/components/CollectionSidePanelToggle/CollectionSidePanelToggle.component.tsx) (Crates | Playlists on **`/collection`**), [`GrowthChart`](../../src/components/Dashboard/GrowthChart.component.tsx), [`ComparativeGrowthCharts`](../../src/components/Dashboard/ComparativeGrowthCharts.component.tsx), [`CrateDrawerFooter`](../../src/components/CrateDrawerFooter/CrateDrawerFooter.component.tsx), [`PlaylistDrawerFooter`](../../src/components/PlaylistDrawerFooter/PlaylistDrawerFooter.component.tsx), [`MobileMenuDrawerFooter`](../../src/components/StickyHeaderBar/MobileMenuDrawerFooter.tsx), [`ReleaseCardOverlayActions`](../../src/components/ReleaseCard/ReleaseCardOverlayActions.component.tsx).
