| `ReleaseTrackRowMenu.component.tsx`                 | Per-track **`InlinePopoverMenu`** for queue, playlist, and YouTube override actions in **`ReleaseTracklist`** (and preview rows that reuse the tracklist). Uses default **`useOverlayStack`** so the popup mounts through **[`AppDialog`](../../src/components/AppDialog/AppDialog.component.tsx)**’s **`OverlayStack`**. **[`ReleaseModal`](../../src/components/ReleaseModal/ReleaseModal.component.tsx)** / **[`PublicReleaseModal`](../../src/components/PublicReleaseModal/PublicReleaseModal.component.tsx)** pass **`escapeStackingContext`** on **`ScrollModal`** (body portal, **`--z-7-tooltip`**) so menus are not clipped by **`overflow: hidden`** — default **`AppDialog`** keeps escape off so **`Select`** listboxes stay inside the dialog inert tree (**[`NoteEditDialog`](../../src/components/ReleaseNotes/NoteEditDialog.component.tsx)**). Do not set **`useOverlayStack={false}`** on the **root** track-row menu panel. Queue rows use **`ListPlusThinIcon`**; signed-in **Add to playlist** uses **`Menu.SubmenuRoot`** — **[`ReleasePlaylistPickerSubmenuTrigger`](../../src/components/ReleasePlaylistPickerDialog/ReleasePlaylistPickerDialog.component.tsx)** (default label **Add to playlist**) + presentational **[`ReleasePlaylistPickerSubmenuPanel`](../../src/components/ReleasePlaylistPickerDialog/ReleasePlaylistPickerDialog.component.tsx)** via **[`ReleaseTrackRowMenuPlaylistSubmenu`](../../src/components/ReleaseTrackRowMenu/ReleaseTrackRowMenuPlaylistSubmenu.component.tsx)** when **`playlistPickerMetadata`** is set — **[`ReleaseTrackRowMenu`](../../src/components/ReleaseTrackRowMenu/ReleaseTrackRowMenu.component.tsx)** routes to **[`ReleaseTrackRowMenuWithPlaylist`](../../src/components/ReleaseTrackRowMenu/ReleaseTrackRowMenuWithPlaylist.component.tsx)** (**[`ReleaseTrackRowMenuView`](../../src/components/ReleaseTrackRowMenu/ReleaseTrackRowMenuView.component.tsx)** — **`ReleaseTrackRowMenuViewProps`** omits **`playlistPickerMetadata`**; playlist chrome is **`playlistSubmenu`** + **`registerCloseMenu`**) + **[`useReleasePlaylistPickerController`](../../src/hooks/useReleasePlaylistPickerController.hook.ts)**; **`CreatePlaylistDialog`** is a sibling outside **`Menu.Root`**). Submenu hover uses Base UI **`Menu.SubmenuTrigger`** defaults (**`openOnHover`** — see [patterns.md → Playlists](patterns.md#playlists)). Controlled **`Menu.Root`** (see [patterns.md → Playlists](patterns.md#playlists)). **`releaseHasQueueActions`** enables a disabled **Add to queue** row when the release exposes queue handlers but the track cannot queue.
