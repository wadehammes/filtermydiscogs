## Accessibility

Baseline for keyboard and screen reader support.
- **Playwright contract**: Prefer **`getByRole`** / **`getByLabel`** in [`e2e/`](../../e2e/) — add roles and names in product markup first, not test-only hooks. Reuse [`accessibilityLabels.constants.ts`](../../src/constants/accessibilityLabels.constants.ts) in specs when the UI uses those strings; keep MSW numeric/copy labels in [`e2eSession.constants.ts`](../../src/tests/msw/e2eSession.constants.ts). **`data-testid`** stays for roots and portaling regressions where roles are ambiguous. Shared playback transport helpers live in [`e2e/helpers/embedTransportSync.ts`](../../e2e/helpers/embedTransportSync.ts) — mini player **Play**/**Pause** assertions query **`getByRole('region', { name: NOW_PLAYING_REGION_LABEL })`** so drawer/footer **Play** buttons are not matched; **`expectE2eNowPlayingShowsPlayControl`** waits for **Pause** to hide before **Play** (**`exact: true`**). **`simulateE2eYoutubeChromePause`** posts **`{ event: 'command', func: 'pauseVideo' }`** to **`fmdPersistentYoutubeIframe`** **`contentWindow`** via **`page.evaluate`** (same wire format as **`postYoutubePlayerCommand`**) and clicks **`#e2eSimulateYoutubePause`** in the same-origin mock document when present. It retries through **[`EMBED_TRACK_SWITCH_PAUSE_GRACE_MS`](../../src/utils/youtubeIframeEvents.ts)** so a pause during track-switch grace (auto **`playVideo`**) does not flake playlist transport sync. **`authenticated-playback-dock-controls`** ±10s skip is **`@desktop-only`** (skip cluster is hidden below 768px). **Clear all stored data** E2E ([`authenticated-logout.spec.ts`](../../e2e/authenticated-logout.spec.ts)) matches [`SettingsClient.spec.tsx`](../../src/components/Settings/SettingsClient.spec.tsx): open the confirm dialog, fill [`CLEAR_ALL_DATA_CONFIRM_PHRASE`](../../src/constants/clearData.constants.ts) in the labeled textbox, then **`getByRole('button', { name: 'Clear all data' })`** (submit stays disabled until the phrase validates).
- **Semantic HTML**: heading levels, **`<button>`** for actions, **`Link`** for navigation, lists for lists.
- **Forms**: Label inputs (`htmlFor` / `id`) or **`aria-label`** / **`aria-labelledby`** when there is no visible label.
- **Images**: Required **`alt`** on every **`Image`**; **`alt=""`** when decorative.
- **Keyboard**: Focusable controls; overlays/menus must not trap focus incorrectly.
- **Motion**: Honor **`prefers-reduced-motion`** for large or looping animations when practical.
