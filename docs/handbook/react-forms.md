- **No `cloneElement` for styling children.** Do not clone elements to attach **`className`** (e.g. icon hover on SVGs). Wrap children in a styled **`<span>`** or use a shared primitive — **[`IconButton`](../../src/components/IconButton/IconButton.component.tsx)** wraps icons in **`<span className={iconButtonIconClasses(…)} aria-hidden>`** (see [components.md → Icon buttons](components.md#icon-buttons)).

# React Hook Form + Zod typing (non-negotiable)

Client form schemas under [`src/lib/validation/`](../../src/lib/validation/) must **`pnpm tsc:ci`** clean with **`useForm<FormValues>({ resolver: zodResolver(formSchema), … })`** while **`exactOptionalPropertyTypes`** is enabled ([TypeScript](#typescript)).
1. **Form value type** — Export **`FormValues = z.infer<typeof formSchema>`** and pass that generic to **`useForm<FormValues>`** unless input and output intentionally differ (see below). **`zodResolver(formSchema)`** must assign to **`Resolver<FormValues>`** with no TS2322 on the **`resolver`** option.
2. **No `z.coerce.*` on RHF-bound fields** — **`z.coerce.boolean()`**, **`z.coerce.number()`**, and similar widen **`z.input`** (often to **`unknown`**) so **`@hookform/resolvers/zod`** no longer matches **`useForm<z.infer<…>>`**. **Do not** “fix” resolver errors by casting **`resolver`** or **`useForm`**. Fix the schema.
3. **Checkboxes** — Use **`z.boolean()`** on the field, **`defaultValues: { …: false }`**, and **`{...register("fieldName")}`**. RHF supplies a boolean; do not rely on **`z.coerce.boolean().default(false)`** for submit forms.
4. **Transforms / API bodies** — When a schema **`.transform`s** or preprocesses so **`z.input` ≠ `z.output`**, either use explicit **`useForm<z.input<typeof schema>, …, z.output<typeof schema>>`** or keep a **dedicated form schema** (plain strings/booleans) separate from the route **`parseRequestBody`** schema. API-only coercion belongs on server/query schemas, not on client RHF forms.
5. **Tests** — Colocate **`*.schemas.spec.ts`** next to form schemas ([`userTrack.schemas.spec.ts`](../../src/lib/validation/userTrack.schemas.spec.ts), [`adminYoutubeEmbed.schemas.spec.ts`](../../src/lib/validation/adminYoutubeEmbed.schemas.spec.ts), [`donate.schemas.spec.ts`](../../src/lib/validation/donate.schemas.spec.ts)). Component specs that submit forms use **`userEvent`** + **`waitFor`** / **`findBy*`** because validation is async.

**Regression reference:** [`adminYoutubeEmbedFormSchema`](../../src/lib/validation/adminYoutubeEmbed.schemas.ts) (**`autoplay: z.boolean()`** + panel **`defaultValues`**) — replacing it with **`z.coerce.boolean()`** broke **`pnpm lint:all`** / **`tsc:ci`**. [`trackYoutubeOverrideFormSchema`](../../src/lib/validation/userTrack.schemas.ts) — string **`superRefine`** only (no coerce).
