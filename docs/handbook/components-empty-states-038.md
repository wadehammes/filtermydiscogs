## Empty states

Use **[`EmptyState`](../../src/components/EmptyState/EmptyState.component.tsx)** for centered “nothing here” copy on collection pages and similar full-width placeholders. Styles live in [`empty-state.module.css`](../../src/styles/modules/empty-state.module.css).

| **`variant`** | Use                                                                                                                 |
| ------------- | ------------------------------------------------------------------------------------------------------------------- |
| **`page`**    | Full-page empty (dashboard, crates hub, mosaic, releases grid) — large title + description, **`min-height: 50vh`**. |
| **`panel`**   | Default — dashed bordered card for in-content panels.                                                               |
| **`inline`**  | Compact muted copy inside a section (compose with dashboard **`.card`** in CSS when needed).                        |

Props: **`title`** (required), optional **`description`**, optional **`children`** (CTA links/buttons), optional **`className`**. Consumers: collection page shells, dashboard sections ([`OnThisDay`](../../src/components/Dashboard/OnThisDay.component.tsx), [`MostCrated`](../../src/components/Dashboard/MostCrated.component.tsx), …), crate detail/drawer release lists. **`/collection`** chooses empty copy via [`resolveReleasesEmptyState`](../../src/utils/releasesEmptyState.ts) (empty Discogs collection vs over-filtered grid) and renders **`EmptyState`** with **`variant="page"`** in [`ReleasesClient`](../../src/components/ReleasesClient/ReleasesClient.component.tsx) — not the default **`panel`** (that variant is for in-panel lists only); full load failures render [`CollectionLoadErrorPanel`](../../src/components/ReleasesClient/CollectionLoadErrorPanel.component.tsx) with **`getCollectionLoadErrorContent`** + **Try again** (invalidates the collection query). Playback queue empty guidance uses [`playbackQueueEmptyCopy.constants.ts`](../../src/constants/playbackQueueEmptyCopy.constants.ts) with **`COMPACT_LAYOUT_MEDIA_QUERY`**. Pass **`className`** to compose dashboard **`.card`** chrome when needed; keep local CSS only for CTAs (e.g. **`.emptyStateLink`** pill buttons).
