## Filtering and sorting

1. **`useCollectionData`** auto-chains paginated Discogs pages and dispatches **`FiltersActionTypes.SetAllReleases`** whenever flattened collection pages change (via raw **`filtersDispatchAtom`**, not **`useFiltersDispatch()`**, so collection hydration never PATCHes prefs) so the releases grid fills in incrementally and in-place field updates (e.g. personal **`rating`**) survive refetch without a collection size change. **`dispatchCollection`** still skips when pagination metadata is unchanged. The first fetch is a **bootstrap** page of 50; if more remain, pagination restarts at page size 100 (see [discogs.md](discogs.md) → Client-side collection access). **`collectionFiltersActiveAtom`** stays false until pagination finishes, so persisted filter prefs do not winnow the in-progress list. When the last page arrives, **`useCollectionData`** sets **`collectionFiltersActiveAtom`** to true so in-session filter inputs can affect the grid; saved prefs are **not** auto-applied (see **Persistence** below). Collection context keeps pagination metadata (`collection`, `fetchingCollection`, `error`) only—not a duplicate release list.
2. **Filter atoms** ([`filters.atoms.ts`](../../src/atoms/filters.atoms.ts)) derive **`filteredReleases`** and facet dropdown options from filter inputs via:
   - [`computeFilterDerivedState.ts`](../../src/utils/computeFilterDerivedState.ts) — one pass over the collection for both the filtered list and facet options ([`filterReleases.ts`](../../src/utils/filterReleases.ts) and [`computeFacetOptions.ts`](../../src/utils/computeFacetOptions.ts) are thin wrappers for tests and direct callers); [`sortReleases.ts`](../../src/utils/sortReleases.ts) applies **`selectedSort`** then optional **`selectedSortSecondary`** (**`SortSecondaryValues.None`** default) on the filtered list in a separate derived atom so sort changes do not re-scan facets; sorting runs on whatever releases are loaded (including during pagination), while facet winnowing stays gated by **`collectionFiltersActiveAtom`**
   - **Facet options** — each dropdown’s choices come from releases matching the _other_ active filters; e.g. with **Rock** selected, year and format lists only show values present on Rock releases, while the genre/style list still reflects search/year/format constraints so you can add another tag. Genres and styles share the **Genre & Style** filter via [`releaseGenreStyleTags.ts`](../../src/utils/releaseGenreStyleTags.ts). **Format Type** is a multi-select **`AutocompleteSelect`** on desktop and mobile with **Match** via [`FilterMatchOperatorSelect`](../../src/components/FilterMatchOperatorSelect/FilterMatchOperatorSelect.component.tsx): **ANY** / **NONE** when one format is selected (include vs exclude that tag), **ANY** / **ALL** / **NONE** when two or more are selected (same as genre/style). **Release Year** is a multi-select with **Match** (**ANY** / **NONE** when one or more years are selected; multi-select omits **ALL** because a release has one year) using [`FILTER_ANY_NONE_OPERATOR_OPTIONS`](../../src/constants/filterMatchOperators.ts). Format tags come from media names (Vinyl, CD, …) plus Discogs `formats[].descriptions` in [`formatFilterTags.ts`](../../src/utils/formatFilterTags.ts) — all descriptions except a small denylist (**Album**, **Stereo**, **Remastered**). Known tags map to display casing via **`FORMAT_CANONICAL_TAGS`**; filter matching is case-insensitive. Genre/style and format **Match** logic share [`matchFilterOperator.ts`](../../src/utils/matchFilterOperator.ts) via [`releaseFilterMatchers.ts`](../../src/utils/releaseFilterMatchers.ts). Facet options, card pills (genre/style via [`getReleaseGenreStyleTags`](../../src/utils/releaseGenreStyleTags.ts), format via **`sortFormatTags`**), and modal format pills sort **A–Z**. Search text and genre/style/format tags are pre-indexed per release ([`releaseSearchIndex.ts`](../../src/utils/releaseSearchIndex.ts)); `SetAllReleases` calls **`syncReleaseSearchIndex`** so pagination appends and note edits reindex only changed rows instead of rebuilding the whole map. Queries match all whitespace-separated tokens against title, artist, label, catno, notes, and genre/style tags ([`releaseFilterMatchers.ts`](../../src/utils/releaseFilterMatchers.ts)). Shared filter inputs use **`ReleaseFilterCriteria`** and facet shapes use **`FacetOptions`** in [`filters.types.ts`](../../src/types/filters.types.ts).
