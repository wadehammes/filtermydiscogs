## Mosaic generator

- **Page**: [`/mosaic`](../../src/app/mosaic/page.tsx) → [`MosaicClientWrapper`](../../src/components/MosaicClient/MosaicClientWrapper.component.tsx) (client `dynamic` with `ssr: false`; [`AppPageLoading`](../../src/components/AppPageLoading/AppPageLoading.component.tsx) while the chunk loads) → [`MosaicClient`](../../src/components/MosaicClient/MosaicClient.component.tsx).
- **Hook**: [`useMosaicGenerator`](../../src/hooks/useMosaicGenerator.hook.ts) builds canvas grids from filtered releases; shared canvas/download logic lives in [`generateMosaicImage`](../../src/utils/generateMosaicImage.ts) (also used by [`useMosaicExport`](../../src/hooks/useMosaicExport.hook.ts)). Crate and playlist **More** menus expose **Generate mosaic** via [`MosaicExportMenuSubmenu`](../../src/components/MosaicExportMenu/MosaicExportMenuSubmenu.component.tsx) → [`MosaicExportMenuDrilldownPanel`](../../src/components/MosaicExportMenu/MosaicExportMenuDrilldownPanel.component.tsx): **one** flyout submenu with in-panel **format → aspect** slides and a **Back** row (not cascading `SubmenuRoot`s — Base UI **`Menu.Viewport`** only animates multi-trigger payload changes). Options from [`listMosaicImageFormats`](../../src/utils/mosaicExportOptions.ts) / [`listMosaicAspectRatioEntries`](../../src/utils/mosaicExportOptions.ts) on [`CrateDetailActionsMenu`](../../src/components/Crates/CrateDetailActionsMenu.component.tsx), [`CrateDrawerFooterActionsMenu`](../../src/components/CrateDrawerFooterActionsMenu/CrateDrawerFooterActionsMenu.component.tsx), and [`PlaylistDrawerFooterActionsMenu`](../../src/components/PlaylistDrawerFooterActionsMenu/PlaylistDrawerFooterActionsMenu.component.tsx) — playlist rows resolve unique collection releases with [`uniquePlaylistReleasesInOrder`](../../src/utils/playlistMosaic.ts).
- **Chrome translate**: [`MosaicControls`](../../src/components/MosaicClient/MosaicControls.component.tsx) sets **`translate="no"`** on the controls row. Download flips the button into a loading label and inserts a spinner; Chrome iOS wraps that label in **`<font>`**, and React’s **`insertBefore`** then throws **`NotFoundError`** into the mosaic error boundary (**JAVASCRIPT-NEXTJS-1A**).
- **Release detail**: Cover tiles open **`ReleaseModal`** via **`useLocalSelectedReleaseModal`** (**local state only** — no **`?instance=`** URL updates; **`MosaicClientWrapper`** does not wrap the page in **`ViewTransitionShell`**, so tile clicks do not crossfade-remount the grid) → **`MosaicItem`** → **`ReleaseModalLazyOverlay`** (prefetch on tile hover through **`useReleaseCardOpenHandler`**); not external Discogs links.
- **Images**: [`src/utils/imageLoader.ts`](../../src/utils/imageLoader.ts) fetches resized covers via **`GET /api/image-proxy`** (Sharp server-side). Clients pass **`cdn=i|img`** and **`path`** (via [`buildDiscogsImageProxySearchParams`](../../src/lib/discogs-image-proxy-url.ts)); legacy **`url=`** is resolved server-side to the same target. Upstream **`fetch`** uses fixed **`https://i.discogs.com`** / **`https://img.discogs.com`** origins only ([`fetchDiscogsCdnImage`](../../src/lib/discogs-image-proxy-url.ts)). Mosaic canvas generation calls **`getReleaseImageUrl({ fallbackToPlaceholder: false })`** so releases without art draw the ♪ tile instead of failing on SVG data URIs. **`IMAGE_PROXY_RATE_LIMIT_MAX`** (default 2500/min) avoids the global 120/min cap mid-export.
- **Tests**: colocated **`useMosaicExport.hook.spec.ts`**, **`MosaicExportMenu/*`**.spec.tsx + POs, util **`mosaicExport*`** / **`generateMosaicImage`** (via generator refactor) specs — see [components.md → Mosaic export menu POs](components.md#testing) and [source-layout.md](source-layout.md) (Mosaic / cover grid export row).
- **Tests**: Page export behavior stays in **`useMosaicGenerator.hook.spec.ts`** (via shared **`generateMosaicImage`**). Drawer/crate menu export: flat **`useMosaicExport.hook.spec.ts`** mocks **`generateMosaicImage`** + **`toast`**; **`MosaicExportMenuDrilldownPanel.spec.tsx`** + PO exercises format → aspect drill-down (menu mocks **`useMosaicExport`**); **`MosaicExportMenuSubmenu.spec.tsx`** asserts trigger disabled/enabled; **`CrateDetailActionsMenu.spec.tsx`** asserts **Generate mosaic** when staged releases load. Filename helpers: [`mosaicExport.spec.ts`](../../src/utils/mosaicExport.spec.ts), [`mosaicExportOptions.spec.ts`](../../src/utils/mosaicExportOptions.spec.ts).
