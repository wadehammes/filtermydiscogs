## Feature example: ReleaseModal

[`ReleaseModal/`](../../src/components/ReleaseModal/) is the release detail dialog shell on **`/collection`**, **`/dashboard`**, **`/mosaic`**, and owner **`/crates/[id]`**. Body, hero, tracklist, similar sidebar, and public variants live in sibling folders (see table). Opened when the user clicks cover art or title on a collection card (via **`onReleaseClick`** from [`useSelectedReleaseModal`](../../src/hooks/useSelectedReleaseModal.hook.ts) — [`useReleasesClient`](../../src/hooks/useReleasesClient.hook.ts) on **`/collection`**) or a dashboard row / mosaic tile (via [`useLocalSelectedReleaseModal`](../../src/hooks/useSelectedReleaseModal.hook.ts) on **`/dashboard`** and **`/mosaic`** — local state only, no **`?instance=`** param).

**URL routing:** Modal open state syncs to **`?instance=<instance_id>`** ([**`RELEASE_MODAL_INSTANCE_PARAM`**](../../src/constants.ts)) on the current page. Every open and similar-sidebar switch **`router.push`**es inside **`startTransition`** (preserving other query params) so browser **Back** walks through viewed releases; explicit close (**X**, Escape, backdrop) **`router.replace`**s to the URL captured before the first open in that session; landing on a direct link with **`?instance=`** closes via **`router.replace`** to strip the param. **`useSelectedReleaseModal`** drives optimistic open/close through a **`modalSyncReducer`** so UI does not wait on App Router **`searchParams`** updates — **`selectedReleaseId`** is **`null` when **`modalSync.dismissed`** (close unmounts before **`router.replace`** clears **`?instance=`**); otherwise **`modalSync.optimisticId ?? urlInstanceId`** so a new click wins over a stale param until **`router.push`** catches up (mosaic tile switches, similar sidebar, rapid re-open). **`useSimilarReleasesInCollection`** defers the collection list with **`useDeferredValue`** so similar-sidebar scoring does not block the first modal paint. Every release-open surface spreads **`useReleaseCardOpenHandler`** (or **`useReleaseOpenHandler`** inside an open modal) **`prefetchPointerProps`** (see **ReleaseCard → Open detail modal**) to warm the modal via [`prefetchReleaseOpenData`](../../src/utils/prefetchReleaseOpenData.ts) on **`onPointerEnter`** (**50ms** delay, **`onPointerLeave`** cancels) / **`onPointerDown`** — **`prefetchQuery`** on **`discogsReleaseQueryOptions`** when that release id is not already cached — so tracklist data is often ready before click; **`handleReleaseClick`** repeats the same helper on open (fallback when hover did not run). **[`ReleaseModalLazyOverlay`](../../src/components/ReleaseModal/ReleaseModalLazyOverlay.component.tsx)** mounts **[`ReleaseModal`](../../src/components/ReleaseModal/ReleaseModal.component.tsx)** with **`key={release.instance_id}`** so hero/tracklist state resets when the open release changes. Tracklist reads use **`useDiscogsReleaseQuery`** while the modal is open — reopening within **`staleTime`** serves cached detail without refetching. Unknown instance ids leave the modal closed. Helpers: [`releaseModalUrl.ts`](../../src/utils/releaseModalUrl.ts). Host pages that call **`useSelectedReleaseModal`** ( **`useSearchParams`** ) wrap the client in **`<Suspense>`** ([**`/collection`**](../../src/app/collection/page.tsx); crate routes already do). **`/dashboard`** and **`/mosaic`** use **`useLocalSelectedReleaseModal`** and do not need modal **`Suspense`**.

**Collection data:** Personal rating, notes, and hero metadata resolve from the **Discogs collection React Query cache**, not a separate modal copy. [`useSelectedReleaseModal`](../../src/hooks/useSelectedReleaseModal.hook.ts) / [`useLocalSelectedReleaseModal`](../../src/hooks/useSelectedReleaseModal.hook.ts) take **`collectionUsername`** on collection pages, resolve the open release from a memoized **`fallbackReleases`** index first (visible/filtered list for instant open), then [`useCollectionReleaseByInstanceId`](../../src/hooks/queries/useCollectionReleaseByInstanceId.hook.ts) — which prefers **`allReleasesAtom`** and only reads the collection React Query cache (**`enabled: false`**) so a **`?instance=`** URL never starts a parallel collection fetch before IndexedDB hydration. Owner **`/crates/[id]`** and public **`/crate/[id]`** pass crate-scoped **`fallbackReleases`**. Tracklist and community rating come from **`useDiscogsReleaseQuery`**. While the modal is open, **`useReleaseModalPlayback`** enables that query (shared cache with **`ReleaseSummaryHero`**, card queue, and the dock); tracks/videos render only from cached release detail — no dock fallback. Tracklist skeleton only when the modal is open, there is no cached **`releaseDetail`** yet, and the query is actively **`isLoading`** (first fetch in flight — not bare **`isPending`**, which stays true while idle/disabled). **`ensureQueryData`** on open (and after cache removal via query-cache subscription) guarantees a fetch when cache is empty. Rating/notes writes patch the infinite collection cache + IndexedDB ([`collectionCacheSync.ts`](../../src/utils/collectionCacheSync.ts), helpers in [`collectionReleaseLookup.ts`](../../src/utils/collectionReleaseLookup.ts)); [`useCollectionData`](../../src/hooks/useCollectionData.hook.ts) keeps **`allReleasesAtom`** in sync for filters and the grid.
