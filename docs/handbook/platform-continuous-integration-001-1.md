## Continuous integration

Pull requests targeting **`staging`** run [`.github/workflows/ci.yml`](../../.github/workflows/ci.yml) as **two parallel jobs**:

| Job            | Steps                                                                                                                                                                                                                                                                                                                                                                           |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Unit gates** | Checkout, **`pnpm install`**, **`pnpm tsc:ci`**, **`pnpm lint:ci`**, **`pnpm lint:css`**, **`bash scripts/handbook-sync-check.sh origin/staging`**, **`bash scripts/spec-pair-check.sh origin/staging`**, **`pnpm test:ci`**, **`pnpm knip:ci`**, **`pnpm fallow:audit:ci`** (**[`scripts/fallow-audit-ci.sh`](../../scripts/fallow-audit-ci.sh)** — advisory: **`fallow audit --changed-since`** plus a JSON pass that logs worsened complexity and **introduced architecture** (boundaries, policy, cycles) vs **`origin/staging`**; **does not fail** the job. Stricter gate: **`pnpm fallow:audit`** in **`mise run pr-prep`**)                                                                                                                                |
| **E2E smoke**  | Checkout, **`pnpm install`**, cached Playwright Chromium (**`~/.cache/ms-playwright`**, restore-keys on lockfile churn), **[`install-playwright-chromium-ci.sh`](../../scripts/install-playwright-chromium-ci.sh)** (**`playwright install chromium`** + **`--force`** when needed; skips **`install-deps`** unless **`PLAYWRIGHT_CI_INSTALL_DEPS=1`** when **[`ensure-playwright-chromium.mjs`](../../scripts/ensure-playwright-chromium.mjs) check** fails — on a full cache hit skips install entirely). E2E jobs use **`ubuntu-24.04`** (not **`ubuntu-latest`**) so apt is reliable when deps are opted in, cached **`.next/cache`**, **`pnpm build:e2e`**, **`pnpm test:e2e:smoke`** — **`E2E_SMOKE=1`** runs only the specs in [`e2e/smokeSpecs.constants.ts`](../../e2e/smokeSpecs.constants.ts) on **chromium** against **`next start`** with **4** parallel workers (see [Playwright](#playwright-instant-navigation-tests)) |

Pushes to **`staging`** also run [`.github/workflows/e2e-full.yml`](../../.github/workflows/e2e-full.yml): same Playwright cache + **[`install-playwright-chromium-ci.sh`](../../scripts/install-playwright-chromium-ci.sh)** (install only when the cache lacks a complete Chromium tree — same as smoke), then **`pnpm build:e2e`**, then full **`pnpm test:e2e:run`** (every spec × **chromium**, **phone**, **tablet**).

GitHub Actions are **pinned to commit SHAs** with version comments (see workflow files). Workflows set **`permissions: contents: read`** (least privilege for checkout and tests only). **[`ci.yml`](../../.github/workflows/ci.yml)** and **[`e2e-full.yml`](../../.github/workflows/e2e-full.yml)** use **`concurrency`** with **`cancel-in-progress: true`** so a newer push on the same PR (or **`staging`** for E2E full) cancels the previous run instead of stacking duplicate hosted-runner jobs — CodeQL and other repo workflows are unchanged.

Run the same locally before pushing when possible — with [mise](https://mise.jdx.dev/), prefer **`mise run ci`** (unit + smoke). Before merging playback/responsive work, run **`mise run ci-full`** or wait for **E2E full** on **`staging`**. For a lighter pre-PR pass: **`mise run pr-prep`** (**`pnpm lint:all`**, **`pnpm handbook:check`**, **`pnpm test:changed`**, **`pnpm fallow:audit`**). **`pnpm test:changed`** runs Jest for files changed vs **`origin/staging`** (including uncommitted edits): touched **`*.spec.*`** run directly; touched production **`src/**`** uses **`--findRelatedTests`**. Full unit parity with CI: **`pnpm test:ci`** (also in **`mise run ci`**).
