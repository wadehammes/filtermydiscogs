## Error monitoring (Sentry)

[`@sentry/nextjs`](../../package.json) captures unhandled client and server errors when a DSN is configured. Init is shared via [`sentryInitOptions.ts`](../../src/lib/sentry/sentryInitOptions.ts): disabled in Jest, **`build:e2e`** (**`NEXT_PUBLIC_E2E_MOCK_YOUTUBE_EMBED=1`**), and local dev unless **`SENTRY_ENABLE_DEV=1`** or **`NEXT_PUBLIC_SENTRY_ENABLE_DEV=1`** (browser needs the **`NEXT_PUBLIC_`** flag). **`sendDefaultPii`** is off; **`sentryBeforeSend`** ([`sentryInitOptions.ts`](../../src/lib/sentry/sentryInitOptions.ts) + [`sentryBeforeSendEvent.ts`](../../src/lib/sentry/sentryBeforeSendEvent.ts)) drops view-transition interruption noise and **browser scheduler termination** messages (**`callback \`timer callback\` was terminated`** — navigation / tab suspend; [`sentryThirdPartyIntegrationErrors.ts`](../../src/utils/sentryThirdPartyIntegrationErrors.ts); same filter on **`globalThis.reportError`** via [`installViewTransitionRecoverableErrorFilter`](../../src/utils/viewTransitionInterruptions.ts)), **GTM YouTube visibility** errors (**`getDuration is not a function`** from **`gtag/js`** + **`www-widgetapi`**; persistent embed sets **`GTM_YOUTUBE_IFRAME_INSPECTED_ATTR`** on [`PersistentYoutubeIframe`](../../src/components/PersistentYoutubeIframe/PersistentYoutubeIframe.component.tsx)), **DOM `error`events on`<script>`** rejected as promises (no stack — script load/parse noise, common on Mobile Safari; [`isDomErrorEventPromiseRejection`](../../src/utils/sentryThirdPartyIntegrationErrors.ts)), **unattributed document / inline errors** (Firefox iOS exponent parse via [`isUnattributedExponentParseError`](../../src/utils/sentryThirdPartyIntegrationErrors.ts); **`appendChild` + `Unexpected identifier 'as'`** via [`isUnattributedAppendChildScriptSyntaxError`](../../src/utils/sentryThirdPartyIntegrationErrors.ts); wallet / Brave **`window.ethereum.selectedAddress`** / **`__firefox__`** injects via [`isUnattributedBrowserExtensionInjectError`](../../src/utils/sentryThirdPartyIntegrationErrors.ts) — no `.js` stack frame), and normalizes **playback skip** messages (stable fingerprint **`playback-skip/{source}/{reason}`**, no minified SDK **`Module.T`** stack grouping).
