- **Placement**: **`ReleasePlaybackProvider`** and **`GlobalPlaybackDock`** mount via **[`PlaybackProvidersShell`](../../src/components/PlaybackProvidersShell.component.tsx)**. **Protected** routes with a session load it through **[`AuthenticatedProvidersGate`](../../src/components/AuthenticatedProvidersGate.component.tsx)** → dynamic **[`AuthenticatedProviders`](../../src/components/AuthenticatedProviders.tsx)** (same shell). Public **`/playlist/[id]`**, **`/crate/[id]`**, and **`/release/[id]`** mount it via **[`PublicSharePlaybackShell`](../../src/components/PublicSharePlaybackShell/PublicSharePlaybackShell.component.tsx)** on the page client. Logged-out protected routes omit playback until sign-in. See [Provider stack §12](#provider-stack). This keeps the YouTube iframe alive across client navigations without mounting playback during static prerender of logged-out protected shells. **`GlobalPlaybackDock`** always portals a single **[`PlaybackDockBar`](../../src/components/PlaybackDockBar/PlaybackDockBar.component.tsx)** to **`document.body`** — collection shells reserve footer space via **`[data-playback-dock-spacer]`** instead of mounting a second dock. Global dock layout tokens (**`--available-height`**, mini-player offsets, video panel inset) live in [`playback-dock.css`](../../src/styles/global/playback-dock.css) (imported with the dock shell); in-modal tracklists and similar scroll regions cap height with **`var(--available-height, 100dvh)`** — see [conventions.md → Viewport height](conventions.md#css-and-styling). On embed remount, **`isPlaybackEmbedMounted`** suppresses URL autoplay and the provider pauses the previous iframe before resuming via postMessage. **`PlaybackDockBar`** returns **`null`** until the provider is present (**`useHasReleasePlaybackProvider`**) so protected route shells can prerender before the authenticated chunk loads. The provider exposes split contexts — **`useReleasePlaybackState`**, **`useReleasePlaybackActions`**, **`useIsMiniPlayerVisible`**, **`useReleasePlaybackQueue`**, **`useReleasePlaybackIframeActions`**, **`useReleasePlaybackEmbedProgressState`** ([`ReleasePlaybackEmbedProgressContext`](../../src/context/releasePlaybackContexts.tsx) in [`ReleasePlaybackProvider.component.tsx`](../../src/context/ReleasePlaybackProvider.component.tsx)) — so subscribers re-render only when their slice changes; **`useReleasePlayback()`** merges state + actions for callers that need both. Throttled embed **`currentTime`** / **`duration`** for the scrubber live in [`useReleasePlaybackEmbedProgress.hook.ts`](../../src/hooks/useReleasePlaybackEmbedProgress.hook.ts); registering the iframe calls **`applyPlaybackDockVolumeToEmbed`** (**`unmuteYoutubeEmbed`** + **`setYoutubeEmbedVolume`** from saved dock volume). Similar-release tail extension batches detail fetches via [`similarReleaseQueue.ts`](../../src/utils/similarReleaseQueue.ts) (deduped React Query prefetch).
