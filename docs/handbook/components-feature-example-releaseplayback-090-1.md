## Feature example: ReleasePlayback

Persistent background playback is split across sibling component folders. **[`PlaybackProvidersShell`](../../src/components/PlaybackProvidersShell.component.tsx)** (**`ReleasePlaybackProvider`** + **`GlobalPlaybackDock`**) mounts on **protected** routes via **[`AuthenticatedProvidersGate`](../../src/components/AuthenticatedProvidersGate.component.tsx)** → dynamic **[`AuthenticatedProviders`](../../src/components/AuthenticatedProviders.tsx)** when the session is active (or auth is checking on a protected route), and on public **`/crate/[id]`** / **`/playlist/[id]`** via **[`PublicSharePlaybackShell`](../../src/components/PublicSharePlaybackShell/PublicSharePlaybackShell.component.tsx)** on the page client. Marketing routes omit playback unless a page opts in. Logged-out protected app routes pass through without playback until sign-in. Playback-enabled pages register modal open handlers with **`useRegisterPlaybackReleaseClick`** ([`playbackReleaseClick.context.tsx`](../../src/context/playbackReleaseClick.context.tsx)).
