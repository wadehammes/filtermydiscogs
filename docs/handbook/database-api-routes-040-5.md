Authenticated crate handlers return **`privateRouteJson`** / **`createErrorResponse`** ([`src/lib/private-route-response.ts`](../../src/lib/private-route-response.ts), [`src/lib/api-helpers.ts`](../../src/lib/api-helpers.ts)). **`sanitizeError`** classifies **`Prisma.PrismaClientKnownRequestError`** first via [`sanitizePrismaKnownRequestError`](../../src/lib/prismaKnownRequestError.server.ts) (**`P1001`** → **503**, **`P2025`** / **`P2002`** → **404** / **409**), then Node errno (**`ECONNRESET`**, … via [`isTransientNodeConnectionError`](../../src/lib/databaseConnectionErrorMessage.ts)) and specific connection message markers ([`isDatabaseConnectionErrorMessage`](../../src/lib/databaseConnectionErrorMessage.ts) — not bare **`connection`** / **`timeout`** substrings; e.g. pg-pool **`Connection terminated unexpectedly`**) via [`databaseConnectionErrorSanitized`](../../src/lib/databaseConnectionErrorMessage.ts). Specs: [`prismaKnownRequestError.server.spec.ts`](../../src/lib/prismaKnownRequestError.server.spec.ts), [`databaseConnectionErrorMessage.spec.ts`](../../src/lib/databaseConnectionErrorMessage.spec.ts), [`api-helpers.sanitizeError.spec.ts`](../../src/lib/api-helpers.sanitizeError.spec.ts). Routes with non-standard error JSON use **`logSanitizedApiRouteFailure`** from the same module (see [platform.md](platform.md) (**Error monitoring (Sentry)**)). With **`cacheComponents`**, do **not** add **`export const dynamic = "force-dynamic"`** — cookie/session access keeps handlers dynamic automatically. See [platform.md](platform.md) (**Private session API responses**).

**`/api/crates/health`** is admin-only ([`verifyAdminFromRequest`](../../src/lib/admin-helpers.ts), same OAuth verification as **`/api/admin/stats`**). Returns JSON diagnostics: Prisma connectivity, sanitized **`databaseHost`** (from [`readRuntimeDatabaseUrlFromEnv`](../../src/lib/databaseUrlEnv.ts) — same resolution as **`db.ts`**, not raw **`DATABASE_URL`** alone), env presence flags (**`hasDatabaseUrlEnv`**, **`hasDatabaseUrlPooledEnv`**, **`hasRuntimeDatabaseUrl`**), **`crateTableAccessible`** / **`crateCount`**, optional pool/query/audit stats when **`DB_ENABLE_DIAGNOSTICS=true`**. Use after deploy or migration issues — Production and Preview use separate Postgres instances.
