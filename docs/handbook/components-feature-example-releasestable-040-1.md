## Feature example: ReleasesTable

[`ReleasesTable`](../../src/components/ReleasesTable/ReleasesTable.component.tsx) is the desktop **list** view on **`/collection`** when view mode is list (see [architecture.md](architecture.md) → view atoms). TanStack Table renders crate menu, artist/title (cover thumb inline left of text), label, **Cat#**, **Year**, **Added** (**`date_added`**, **`formatDate`**), **Format/Styles**, and a trailing **actions** icon column (**[`ReleasesTableRowActions`](../../src/components/ReleasesTable/ReleasesTableRowActions.component.tsx)**).

| Concern              | Pattern                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Crate column         | **`ReleaseCrateMenu`** icon trigger (**`triggerVariant="custom"`**) in the first column — same multi-crate popover as release cards; row **`.inCrate`** highlights when the release is in the **active** crate only (**`useCrateState().activeCrateInstanceIds`**)                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Artist/title         | **[`ReleasesTableArtistTitleCell`](../../src/components/ReleasesTable/ReleasesTableArtistTitleCell.component.tsx)** — cover thumb + artist (**`textActionStyles.entitylinkprimary`**) + title link (**`textActionStyles.entitylinktitletruncated`**); title stays **single-line** ellipsis (same as cards); native **`title`** tooltip for the full album name. Cover thumb buttons (**`.artistTitleThumb`**, **`.imageButton`**)**`transition`** **`transform`** only; hover **`box-shadow`** snaps (same paint rule as desktop **`ReleaseCard`**)                                                                                                                                                                                                                                                                                                                                                                                                         |
| Format/Styles column | Format pills plus genre/style tags from [`getReleaseGenreStyleTags`](../../src/utils/releaseGenreStyleTags.ts), wrapped in **`HorizontalScrollRow`** inside a fixed-width cell (**`min-width: 0`**) so tags scroll horizontally instead of wrapping                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
