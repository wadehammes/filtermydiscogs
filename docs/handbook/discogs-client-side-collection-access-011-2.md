**IndexedDB collection cache:** after the collection is fully loaded, [`useCollectionData`](../../src/hooks/useCollectionData.hook.ts) persists React Query pages to IndexedDB via [`collectionCacheStorage.ts`](../../src/utils/collectionCacheStorage.ts) / [`collectionCacheSync.ts`](../../src/utils/collectionCacheSync.ts), including after a validated cache hit when fresh pages arrive. Personal rating and notes writes also patch the persisted cache immediately via [`patchPersistedCollectionReleaseRating`](../../src/utils/collectionCacheSync.ts) / [`patchPersistedCollectionReleaseNotes`](../../src/utils/collectionCacheSync.ts). [`CollectionCachePrepGate`](../../src/components/CollectionCachePrepGate/CollectionCachePrepGate.component.tsx) calls [`useCollectionCacheReady`](../../src/hooks/useCollectionCacheReady.hook.ts) as soon as auth exposes a username ([`resolveCollectionCacheUsername`](../../src/utils/resolveCollectionCacheUsername.ts) — active session or soft-logout **`reconnectUsername`**) so the login page can warm IndexedDB before OAuth completes. [`prepareCollectionQueryFromCache`](../../src/utils/collectionCacheSync.ts) hydrates the infinite query from IndexedDB **as soon as** disk data is read, then revalidates in the **background** with a page-1 **`pagination.items`** check; when validation passes, [`mergeLiveCollectionPageBasicInformationIntoPages`](../../src/utils/collectionReleaseLookup.ts) compares live page-1 releases to the cached index from [`buildCollectionReleaseIndex`](../../src/utils/collectionReleaseLookup.ts) (**`getEffectiveCollectionPages`**) and, when **`basic_information`** JSON differs, patches those rows across stored pages (e.g. format corrections on Discogs) before hydration—no IndexedDB rewrite when page-1 metadata matches. Cached pages paint immediately after disk hydration; when the background count check fails (collection size changed on Discogs), IndexedDB is cleared and **`invalidateQueries`** kicks off a live re-fetch (the grid keeps showing the last hydrated pages until fresh data arrives). When the persisted entry is older than **`COLLECTION_CACHE_STALE_MS`** (24 hours), background revalidation **invalidates** the collection query for a full refresh without blocking first paint. Releases that only appear on later pagination pages can stay stale until a full collection reload (**Clear All Data** or a future explicit refresh control). After OAuth success, **`clearUserScopedQueries`** clears in-memory collection data but a subsequent prepare call re-hydrates from IndexedDB when still valid. [`useCollectionData`](../../src/hooks/useCollectionData.hook.ts) syncs hydrated pages into **`allReleasesAtom`** with **`useLayoutEffect`** (before paint). Once any releases are on screen it clears **`fetchingCollection`** (tail pagination and background refetch no longer swap the filters bar back to skeleton). **`setCollectionFiltersActive(true)`** when the first page lands (facets may grow as later pages finish). Flow: (1) IndexedDB prep hydrates React Query when disk data exists and marks **`ready`** after the read (not after validation); (2) the collection infinite query enables — if pages are already in cache, **`refetchOnMount: false`** keeps the grid instant on refresh; otherwise Discogs pagination runs; (3) background revalidation runs the count check or 24h **`invalidateQueries`**. A validation **timeout** (**`COLLECTION_CACHE_VALIDATION_TIMEOUT_MS`**, 10s) keeps the hydrated grid; only a **count mismatch** clears IndexedDB and invalidates for a live fetch. [`useCollectionCacheReady`](../../src/hooks/useCollectionCacheReady.hook.ts) shares one ready state per username; prep always marks **`ready: true`** when its promise settles. [`useCollectionLoadState`](../../src/hooks/useCollectionData.hook.ts) reports loading while prep is in flight, the first page is fetching, or pagination continues. IndexedDB entries are kept indefinitely until that count check fails or the user runs **Clear All Data**. When validation passes after a cache hit, [`useCollectionData`](../../src/hooks/useCollectionData.hook.ts) runs an automatic **Sync collection** pass (same crate cleanup as Settings → Data) without a confirmation dialog; removals toast, zero removals stay silent. [`useDiscogsCollectionQuery`](../../src/hooks/queries/useDiscogsCollectionQuery.ts) uses **`COLLECTION_CACHE_STALE_MS` (24 hours)** for in-memory **`staleTime`** / **`gcTime`**. **Clear All Data** wipes the IndexedDB store via [`clearClientStoredData`](../../src/utils/clearClientStoredData.ts).
