**Similar in your collection:** **`getSimilarReleasesModalPage`** (modal hook) scores and dedupes the full similar pool once, then slices by **`pageIndex`** × **`RELEASE_MODAL_SIMILAR_LIMIT`**. Source tag/artist/label keys are hoisted per call. **`getSimilarReleases`** scores other collection items with weighted tag overlap — **styles** count more than **genres** — plus boosts for **shared tag count** (more overlapping genre/style tokens), shared **primary format** (`basic_information.formats[0].name`), shared **label** (by Discogs **`labels[].id`**, with name fallback), and nearby **year** (±8), and a **same-artist penalty** (by **`artists[].id`**, with name/ANV fallback) so gig-list discovery favors different artists with a similar vibe. Compound tags also match on **tokens split from non-alphanumeric characters** (e.g. **`Italo-Disco`** overlaps **`Disco`**, **`Garage House`** overlaps **`House`**) when each token is at least three characters. When the source has styles, candidates must share at least one style tag (including compound segments); genre-only overlap is not enough. Results dedupe to **one row per Discogs release id** (`basic_information.id` via **`parseReleaseId`**) and **one per `master_id`** (highest score wins). Excludes the open instance, other collection copies of the same release id, and same **`master_id`** as the source. Untagged sources return no matches. While deferred inputs lag, **`ReleaseModal`** applies **`modalWide`** via **`isSimilarUnsettled`** and **`ReleaseSimilarSidebar`** may show **`PageLoader`** only before the scored pool exists; once cached releases are in memory, partial snapshots can score immediately even if Discogs pagination continues. Returns up to **`RELEASE_MODAL_SIMILAR_LIMIT`** (50) matches per page sorted by score then title. **`ReleaseSimilarSidebar`** shows a full-width **SegmentedControl** toolbar below the subtitle: **`N similar`** count segment (Base UI tooltip on the count — ranked ordering / scoring copy) plus, when **`similarPageCount` > 1**, prev / **`1 of N`** page label (`getSimilarReleasePageDigitCh` + fixed **`ch`** digit columns — **`.similarPageNumber`** / **`.similarPageTotal`**) — prev **`chevron-left-thin.svg`**, next **`chevron-right-thin.svg`** (dedicated path geometry; **`.pageNavSegment`** touch-target / centering (inline grid; aside grid with **`appearance: none`** so the chevron meets the page label — see [conventions.md → Typography stacks → Nav and segmented controls](conventions.md#typography)) — labels from [`releaseSimilarSidebar.constants.ts`](../../src/constants/releaseSimilarSidebar.constants.ts). Per-anchor page index is remembered (in-memory map mirrored to **`sessionStorage`** **`SIMILAR_PAGE_INDEX_SESSION_KEY`**) while the tab is open — restore when returning to the same **`instance_id`** after opening a similar row or revisiting the same **`?instance=`** URL; new anchors start at page **0**; the current anchor page index clamps when **`similarPageCount`** shrinks; **`clearSimilarReleasesPageIndexByAnchor`** runs on **`handleCloseModal`** (and full client clear). **`ReleaseModalLazyOverlay`** remounts via **`key={instance_id}`** — unmount persistence lives in **`useSimilarReleasesInCollection`**.
