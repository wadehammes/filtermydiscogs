- **Owner pages**: [`/crates`](../../src/app/crates/page.tsx) lists the user's crates in a responsive card grid ([`CrateHubCard`](../../src/components/Crates/CrateHubCard.component.tsx) — cover collage from the first three releases, name, **Default** badge when **`is_default`**, and release count; hub grid is static, not **`ScrollReveal`**, so cards stay visible inside **`PlaybackPageShell`**'s nested scroll). [`/crates/[id]`](../../src/app/crates/[id]/page.tsx) is the authenticated owner workspace (`CrateDetailClient`): full-width layout with [`CrateDetailHeader`](../../src/components/Crates/CrateDetailHeader.component.tsx) ([`CrateSelector`](../../src/components/CrateSelector/CrateSelector.component.tsx) **`onNavigate`** prefetch, [`CrateDetailActionsMenu`](../../src/components/Crates/CrateDetailActionsMenu.component.tsx) — **Edit crate**, **Set as default** (hidden when already default), **Delete crate** (disabled with hint when it is the default or only crate), then [`CrateShareControls`](../../src/components/CrateShareControls/CrateShareControls.component.tsx) at the bottom (`variant="menu"` — title + toggle + inline **Copy link** on one row; helper text below); **`CrateDetailActionsMenu`** on **`detailMain`**: inline beside the selector on mobile (no sticky); on desktop **`position: sticky`**, **`grid-row: 1 / -1`**, **`place-self: start end`** so it stays top-right while the workspace scrolls. on desktop (≥1024px): release list on the left with a sticky [`CrateReleaseListToolbar`](../../src/components/CrateReleaseListToolbar/CrateReleaseListToolbar.component.tsx) for gig-packing progress (**Clear packed**, **Hide packed**), and a sticky **set-notes scratchpad** on the right ([`CrateSetNotesScratchpad`](../../src/components/CrateSetNotesScratchpad/CrateSetNotesScratchpad.component.tsx) — `variant="panel"`, debounced autosave); stacked on mobile (release list above set notes). [`CrateLayoutList`](../../src/components/Crates/CrateLayoutList.component.tsx) drives the owner list: vertical-axis drag-and-drop reorder (**`@dnd-kit`** **`restrictToVerticalAxis`**) for releases and **set markers** ([`CrateSetMarkerRow`](../../src/components/Crates/CrateSetMarkerRow.component.tsx) — inline label edit persists on blur; **Add section** inserts a local draft marker and saves layout when the label field blurs, delete); nested **groups** render as bordered **`sectionGroup`** wrappers (header row plus member releases and nested subsection groups, with optional **`accent_key`** colors; when **`packed_enabled`**, packed rows inside a group tint with **`color-mix`** on **`--crate-section-accent`**, including the packed toggle — loose rows outside groups keep the **`--primary`** tint); unsectioned rows in the same layout run render as normal list rows below the group chrome. Only releases with **`section_id`** belong in a group (drag under the header or below a member to join). Per-release collection notes remain inline scratchpads ([`ReleaseNotes`](../../src/components/ReleaseNotes/ReleaseNotes.component.tsx) **`crate`** variant). On mobile (&lt;1024px), [`CrateLayoutReleaseRowNotes`](../../src/components/CrateLayoutReleaseRowNotes/CrateLayoutReleaseRowNotes.component.tsx) wraps each row scratchpad in a **+ Add Release Notes** accordion (collapsed by default) so rows stay short for drag-and-drop until expanded; desktop keeps notes always visible. **Remove from crate** on a layout row opens **[`ConfirmDialog`](../../src/components/ConfirmDialog/ConfirmDialog.component.tsx)** before calling **`removeFromCrate`** (drawer staging list still removes immediately). Layout changes persist via **`PUT /api/crates/[id]/layout`** and **`useUpdateCrateLayoutMutation`**. **`CrateProvider`** exposes merged **`layoutItems`** (releases + markers by **`sort_order`**) alongside **`selectedReleases`**. **Hide packed** filters release rows in the UI but keeps the full layout (including hidden releases and marker positions) for saves. The [`/collection`](../../src/app/collection/page.tsx) drawer lists releases in the same **`sort_order`** as the owner layout (via **`layoutItems`**) but omits section markers ([`CrateDrawerReleases`](../../src/components/CrateDrawerReleases/CrateDrawerReleases.component.tsx)); gig-packing uses the same toolbar component when **`packed_enabled`**. Create new crates from **`/collection`** drawer or the hub (`allowCreate={false}` on detail). Release rows open [`ReleaseModal`](../../src/components/ReleaseModal/ReleaseModal.component.tsx) inside **`ReleasePlaybackProvider`**. The URL crate id is the source of truth on the detail page (`selectCrate` from route param). Header nav includes **Crates** (`currentPage="crates"`).
- **Server**: handlers scope all rows by **verified OAuth user ID** from **`getVerifiedUserFromRequestWithRateLimit`**; store optional **`username`** on public crates.
