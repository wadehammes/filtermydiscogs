## Playlists

- **Rollout**: Playlists are GA — collection UI and private **`/api/playlists`** routes are always on. Optional **`PLAYLISTS_FEATURE_OVERRIDE=0`** remains for local/CI kill-switch and admin readout via [`getPlaylistsFeatureEnabled`](../../src/lib/playlistsFeature.server.ts) ([platform.md → Playlists env override](platform.md#playlists-env-override)).
- **Client**: React Query **`usePlaylistsQuery`** / **`usePlaylistQuery`** and mutations in [`usePlaylistMutations.ts`](../../src/hooks/mutations/usePlaylistMutations.ts). The playlist drawer shares one detail subscription via **[`useActivePlaylistDetail`](../../src/hooks/useActivePlaylistDetail.hook.ts)** (**`PlaylistDrawerFooter`**, **`PlaylistDrawerTracks`**, **`PlaylistShareControls`**). The add-to-playlist picker passes **`trackKey: metadata.track_key`** so **`GET /api/playlists?trackKey=`** returns **`containsTrack`**; **[`ReleasePlaylistPickerSubmenuPanel`](../../src/components/ReleasePlaylistPickerDialog/ReleasePlaylistPickerDialog.component.tsx)** shows a check beside playlists that already include the track; on hover or keyboard highlight the row tints **`var(--destructive)`**, swaps the check for a minus icon, and **`onPickPlaylist(..., containsTrack: true)`** removes the track via **`useRemoveTrackFromPlaylistEntryMutation`** (add when **`containsTrack`** is false). **`useReorderPlaylistTracksMutation`** optimistically reorders **`playlist`** detail cache (**[`applyPlaylistTrackOrder`](../../src/utils/playlistTrackOrder.ts)** — local **`displayTracks`** + **`flushSync`** in **`handleDragEnd`** so **`@dnd-kit`** sees the new DOM order before transforms reset; **`flushSync`** local **`displayTracks`**, then **`mutate({ trackKeys, previousPlaylist, optimisticPlaylist })`**; **`onMutate`** cancels in-flight detail fetch and **`setQueryData(optimisticPlaylist)`** (single apply via **`applyPlaylistTrackOrder`** in the component); rollback uses the pre-drag snapshot; sortable rows use **`animateLayoutChanges: () => false`**; no detail refetch on success). Add tracks from release tracklists via the track row menu nested **`Menu.SubmenuRoot`** (same pattern as theme/crate menus; **`POST /api/playlists/[id]/tracks`** carries **`AddPlaylistTrackBody`** — metadata plus optional **`release_snapshot`** from **[`buildAddPlaylistTrackBody`](../../src/utils/buildAddPlaylistTrackBody.ts)** so public shares persist **`playlist_release_snapshots`** without client **`POST /api/release/batch`**). Server upserts **`UserTrack`** through **`ensureUserTrackMetadata`** and snapshot rows via **`ensurePlaylistReleaseSnapshotOnTrackAdd`** (see [database.md → Playlists](database.md#playlists)). **[`ReleasePlaylistPickerSubmenuPanel`](../../src/components/ReleasePlaylistPickerDialog/ReleasePlaylistPickerDialog.component.tsx)** is presentational (sorted playlist rows + **Create new playlist…**). Mutations, query, and dialog state live in **[`useReleasePlaylistPickerController`](../../src/hooks/useReleasePlaylistPickerController.hook.ts)** — returns **`submenuPanelProps`** + **`createDialogProps`**. **[`ReleaseTrackRowMenuWithPlaylist`](../../src/components/ReleaseTrackRowMenu/ReleaseTrackRowMenuWithPlaylist.component.tsx)** / **[`ReleaseMiniPlayerAddToMenuWithPlaylist`](../../src/components/ReleaseMiniPlayer/ReleaseMiniPlayerAddToMenuWithPlaylist.component.tsx)** mount the controller only when playlist **`metadata`** exists; **`CreatePlaylistDialog`** stays **outside** the popover (closing the menu unmounts panel content — dialog state must not live inside **`InlinePopoverMenu.Panel`**). Submenu UI: **[`ReleaseTrackRowMenuPlaylistSubmenu`](../../src/components/ReleaseTrackRowMenu/ReleaseTrackRowMenuPlaylistSubmenu.component.tsx)**. **`submenuPanelProps.onOpenCreateDialog`** calls **`onRequestCloseMenu`** (controlled root **`Menu.Root`**) before **`CreatePlaylistDialog`** opens as a **sibling outside** **`Menu.Root`** (mirrors **`useReleaseCrateMenuController`** + **`CreateCrateDialog`**). Hook spec: [`useReleasePlaylistPickerController.hook.spec.ts`](../../src/hooks/useReleasePlaylistPickerController.hook.spec.ts). Nested **`ReleasePlaylistPickerSubmenuPanel`** / **`ReleaseCrateMenuSubmenuPanel`** default **`useOverlayStack={false}`**; modal track rows pass **`useMenuOverlayStack`** on the nested panel when the parent menu uses **`OverlayStack`**.
