## Feature example: CrateDrawerReleaseItem

[`CrateDrawerReleaseItem`](../../src/components/CrateDrawerReleaseItem/CrateDrawerReleaseItem.component.tsx) + [`CrateDrawerReleaseActions`](../../src/components/CrateDrawerReleaseActions/CrateDrawerReleaseActions.component.tsx) render each release row in the **`/collection`** crate drawer (via [`CrateDrawerSortableReleaseRow`](../../src/components/CrateDrawerReleases/CrateDrawerSortableReleaseRow.component.tsx) when reorder is enabled) and share the same horizontal layout as **`MobileReleaseCard`** (cover | meta | **`4rem`** action column with grip reorder stacked above packed/remove like playlist tracks). **[`CrateDrawerReleases`](../../src/components/CrateDrawerReleases/CrateDrawerReleases.component.tsx)** wires **`DndContext`** / **`SortableContext`** and delegates sensors, visible sortable ids, and **`onDragEnd`** to **[`useCrateDrawerReleasesDnD`](../../src/components/CrateDrawerReleases/useCrateDrawerReleasesDnD.hook.ts)** (**`isPacked`** typed as **`ReturnType<typeof useCrate>["isPacked"]`** so drawer context and **`crate-layout`** stay aligned). Row shell (**.listItem`**) spreads **`prefetchPointerProps`**; the main **`button`** prefetches on **`onFocus`** when **`onReleaseClick`** is set. Styles live in [`CrateDrawerReleaseItem.module.css`](../../src/components/CrateDrawerReleaseItem/CrateDrawerReleaseItem.module.css); actions compose [`vertical-action-stack.module.css`](../../src/styles/modules/vertical-action-stack.module.css).

| Concern      | Pattern                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Shell        | **`--card`** background; **`1px`** border on **`--border`**; **`--shadow-sm`** at rest; on **`@media (hover: hover)`**, hover lightens the border via **`color-mix(..., var(--foreground))`** and snaps a foreground-tinted outer shadow (not animated — **`transition`** on **`background-color`** / **`border-color`** only) — do **not** swap the row to **`--muted`** (avoids a harsh cover vs. text split on warm palettes) |
| Layout       | Clickable main area (cover + artist/title/meta) opens **`ReleaseModal`**; action column is a full-height stack separated by **`border-left`**                                                                                                                                                                                                                                                                                    |
| Packed       | **`.listItemFound`** — primary outer border when **`packed_enabled`** and release is marked packed; gig toggle uses **[`CrateReleasePackedToggleIcon`](../../src/components/Crates/CrateReleasePackedToggleIcon.component.tsx)** — **[`RecordBagThinIcon`](../../src/styles/icons/RecordBagThinIcon.component.tsx)** (square tote, curved handle) when unpacked, **[`CheckThinIcon`](../../src/styles/icons/CheckThinIcon.component.tsx)** when packed (**`aria-pressed`**)                                                                                                                                 |
| Reorder grip | **`IconButton`** **`variant="skip"`** + grip icon; per-row **`aria-label`** (`Reorder …`); native **`title="Drag to reorder"`** (same on **[`PlaylistDrawerTrackItem`](../../src/components/PlaylistDrawerTrackItem/PlaylistDrawerTrackItem.component.tsx)**). Grip chrome and drawer list gutters live in **[`drawer-sortable-drag.module.css`](../../src/styles/modules/drawer-sortable-drag.module.css)** (**`.itemDragging`**, **`.dragHandle`**, **`.dragHandleIcon`**) and **[`drawer-sortable-list.module.css`](../../src/styles/modules/drawer-sortable-list.module.css)** (**`.list`** — **`CrateDrawerReleases`**, **`PlaylistDrawerTracks`**). Import both from TSX with **`classNames`**; playlist active-row grip tint stays on **`.listItemActive .playlistDragGrip`** in [`PlaylistDrawerTrackItem.module.css`](../../src/components/PlaylistDrawerTrackItem/PlaylistDrawerTrackItem.module.css). Do not reach them only through **`composes`** (Knip / Fallow dead-file gate).                                                                                                                                 |
| Action hover | Default stack buttons tint with **`color-mix(..., var(--card))`**; packed toggle keeps primary fill on hover; remove uses a destructive tint on **`--card`**, not **`--background`**                                                                                                                                                                                                                                             |
